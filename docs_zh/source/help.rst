.. _help:

获取帮助
============

对于可能的 bug、功能增强请求或代码问题，请在
`OpenFAST Github 仓库 <https://github.com/OpenFAST/OpenFAST>`_ 提交 Issue。

对于 OpenFAST 使用问题，用户可考虑访问 `FAST 论坛 <https://forums.nlr.gov/>`_，
该论坛提供了 10 年以上积累的 FAST 相关问答；在向 GitHub Issues 或论坛发帖之前，
应首先使用论坛的搜索功能。

如有关于 OpenFAST 开发计划或如何贡献的问题，请联系
`Jason.Jonkman@nlr.gov <mailto:jason.jonkman@nlr.gov>`_ 或
`Andy.Platt@nlr.gov <mailto:andy.platt@nlr.gov>`_。
