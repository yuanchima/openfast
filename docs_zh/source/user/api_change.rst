.. _api_change:

版本间 API 变更
================

本页面列出了不同版本之间 OpenFAST API（输入文件）的主要变更。

变更按照模块输入文件、行号和标志名称进行列表。
行号对应于实现所有变更后的最终行号。
因此，请务必按顺序实现每个变更，以确保后续行号正确。


OpenFAST v4.2.x 到 OpenFAST v5.0.0
-----------------------------------

在 AeroDyn 中为转子叶片和塔筒添加了附加质量和流体惯性载荷。
这导致 AeroDyn 叶片输入文件中新增了列，并且在 AeroDyn 主输入文件的
"塔筒影响和空气动力学"部分也新增了列。由于添加了这些载荷，浮力标志也被移除，
浮力、附加质量和惯性载荷都可以通过将相应系数设置为零来关闭，而不需要为每个载荷单独设置标志。

启用了 InflowWind 和 SeaState 之间波浪和流速的叠加，这需要在 AeroDyn 驱动输入文件中添加"海况数据"部分。

OpenFAST 输入文件的变更支持单个风机包含多个转子。第 16 行的 NRotors 用于指定风机中的转子数量。
第 50-56 行指定第二个转子的 ElastoDyn、BeamDyn 和 ServoDyn 输入文件；所有其他模块使用第一部分中指定的输入文件。
`MirrorRotor` 行设置一个标志来反转转子的旋转方向。第一个转子始终以典型方向旋转。
这些行仅在 NRotors 大于 1 时指定，并且对于后续转子需要重复这些行。
