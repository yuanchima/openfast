未来工作
========

此列表包含可能在未来版本中实现的功能：

-  开发更高效的从高保真实前驱仿真生成/处理环境风的方法，包括：

   -  使用泰勒冻结湍流假设传播环境风数据的2D平面，作为3D体积的替代方案

   -  支持TurbSim中的非均匀网格

   -  使用动态模式分解压缩低分辨率域的文件大小

   -  实现Gabor模式增强以替代高分辨率域

   -  基于简单矩形（而非通用非结构化）网格开发更高效的ABLSolver。

-  通过添加更多物理效应改进涡黏性公式。

-  探索更多尾流建模方法，包括：

   -  引入更简单的尾流亏损模型，例如Bastankhah和Porté-Agel的高斯尾流模型以及Blondel和Cathelain的超高斯模型

   -  引入更简单的尾流偏转模型，例如Jiménez模型或Qian和Ishihara模型

   -  对近尾流应用自由涡方法

   -  在偏斜流动条件下纳入肾形尾流，例如通过纳入偏斜诱导的马蹄涡产生的反向涡旋

   -  由于背景湍流（除尾流蜿蜒外）导致基础尾流亏损变形（引入不对称性）

   -  纳入尾流附加湍流

   -  改进复杂地形的处理（超出在VTK格式中将环境风数据指定为NaN的范围）

   -  包含来自机舱和支撑结构的尾流

   -  实现尾流的地面反射。

-  解决大型风电场的深层阵列效应，并考虑风电场边缘周围的气流加速——即考虑风电场阻塞效应——例如通过在LES环境风前驱仿真中使用表面粗糙度模拟风电场诱导的边界层。

-  实现一个模型来模拟从激光雷达（LIDAR）和其他遥感技术获得的测量结果。

-  集成MPI支持，通过利用内存并行化和高性能计算机（HPC）节点间的并行化来支持大型风电场建模。

-  支持更通用的模块形式，例如：

   -  支持连续状态

   -  支持输入到输出的直接馈通

   -  支持全系统线性化。

-  支持与Simulink的接口，用于单个风力机控制器。

-  实现检查点-重启功能。

-  启用二进制风数据输入输出格式和二进制时间序列结果输出格式。

-  增加在无需平行于全局惯性坐标系的*X-Y*、*Y-Z*和/或*X-Z*平面的2D切片上输出VTK格式扰动风的能力。

-  按照FAST.Farm生成的VTK格式可视化输出文件使用的命名约定重命名VTK格式的环境风数据输入文件（带前导零且不带*t*）。

-  支持风电场中超过前9台风力机的入流和尾流相关输出通道。

-  将FAST.Farm与风电厂集成系统设计与工程模型（`WISDEM <https://github.com/NatLabRockies/WISDEM>`__\ :math:`^\text{TM}`）对接，用于系统工程应用（多学科设计、分析和优化；不确定性量化等）。

-  为独立版AeroDyn（OpenFAST的空气动力学模块或等效的BEM工具）开发包装器，作为OpenFAST的替代方案，以支持仅面向性能的高级风电场分析，其计算效率远高于使用OpenFAST的FAST.Farm分析。

-  解决海上风能特有的挑战，例如：

   -  确保整个海上风电场的波浪一致性

   -  支持空气-水界面

   -  考虑共享系泊和锚定布置（用于浮式海上风电场）。

-  实现支持海底海洋涡轮机阵列的功能（可能需要支持输入到输出的直接馈通以处理附加质量效应）。
