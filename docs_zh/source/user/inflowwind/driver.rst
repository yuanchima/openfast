InflowWind驱动程序
=================
示例输入文件包含在:numref:`ifw_appendix`中。
InflowWind驱动程序的命令行语法：
::
    InflowWind_Driver <filename> [options]
          where:  <filename>     --   要使用的驱动输入文件的名称
        options:  /ifw           --   将<filename>视为InflowWind输入文件的名称（无驱动输入文件）
        以下选项将覆盖驱动输入文件中的值：
                  /DT[#]          --  时间步长
                  /TStart[#]      --  开始时间
                  /TSteps[#]      --  时间步数量
                  /xrange[#:#]    --  x范围（#为实数）
                  /yrange[#:#]    --  y范围
                  /zrange[#:#]    --  z范围（地面 = 0.0）
                  /Dx[#]          --  x方向间距
                  /Dy[#]          --  y方向间距
                  /Dz[#]          --  z方向间距
                  /points[FILE]   --  在空白分隔的FILE中指定的x,y,z坐标处计算
                  /v              --  详细输出
                  /vv             --  非常详细的输出
                  /hawc           --  将InflowWind中指定的风文件转换为HAWC格式
                  /bladed         --  将InflowWind中指定的风文件转换为Bladed格式
                  /vtk            --  将InflowWind中指定的风文件转换为VTK格式
                  /accel          --  处理点文件时输出加速度
                  /BoxExceedAllow --  设置标志以推断超出全场风箱的点的值
                  /help           --  打印此帮助菜单并退出
::
    注意：
    - 未指定的范围和分辨率默认为文件中的值。
    - 如果未指定XRange，则假定仅在X=0处。
    - 选项不区分大小写。
`InflowWind手册 <https://wind.nrel.gov/nwtc/docs/InflowWind_Manual.pdf>`__包含了它可以读取的文件格式的描述。
指定InflowWind输入文件
------------------------------------
InflowWind驱动输入文件要求在其中指定一个InflowWind输入文件。请参阅:numref:`ifw_appendix`中的InflowWind输入文件示例。
在InflowWind输入文件中，如果指定的风文件是Bladed原生格式（``WindType = 7``），请另请参阅:ref:`ifw_native_bladed`。
风文件输出格式
------------------------
InflowWind驱动程序能够将从输入风文件读取的风数据写入各种格式的风文件。
HAWC2
~~~~~
此格式生成以下文件：
- 三个二进制文件，每个分量一个：
  ``<RootName>-HAWC.u``、``<RootName>-HAWC.v``和``<RootName>-HAWC.w``
- 一个HAWC2输入文件风格的文本摘要文件：
  ``<RootName>-HAWC.sum``
在转换脚本中，u分量将在每个高度处移除（近似）平均值。被移除的平均值作为注释显示在文本摘要文件中。湍流不会被缩放，因此它将与原始文件具有相同的缩放比例。
Bladed
~~~~~~
此格式生成一个打包的二进制文件和一个文本摘要文件。
此输出格式是TurbSim生成的Bladed风格格式。这意味着**文件中包含切变**。
VTK
~~~
此格式在名为``vtk``的子目录中创建文件。全场数据结构中的每个时间点都有一个vtk文件，每个文件中打印整个Y-Z网格。此格式可用于使用ParaView等查看器可视化风场。
均匀风
~~~~~~~~~~~~
此格式生成均匀风格式的文本文件。转换为此格式通常会丢失文件中的信息，因为它仅指定一个点的风速和方向，并将切变近似为幂律指数。
将均匀风转换为全场风格式
-------------------------------------------------
从均匀风文件转换为全场风格式时，使用以下假设：- 平流速度是均匀风文件中的时间平均水平风速（不包括阵风速度）。- 输出文件中使用的恒定时间步长是轮毂高度文件中任意两个条目之间的最小差值。- 均匀风文件中的最大时间将用作FF二进制文件中的最大时间。- 网格在横向（Y）和水平（Z）方向上以5米分辨率生成。- 网格大小基于InflowWind输入文件中的``RefLength``参数。转换器会增加约10%的网格宽度，确切大小由达到所需的网格分辨率决定。网格在横向方向上居中；它在``RefHt``以上垂直延伸的距离与网格宽度相同，并在``RefHt``以下延伸至地面（或距离地面一个网格点以内）。
请注意，均匀风和全场风文件之间可能存在时间偏移，等于传播半个网格宽度距离所需的时间。使用生成的全场文件时，必须注意气动弹性代码不会将其视为周期性的。
从全场风格式转换为均匀风格式
---------------------------------------------------------------
从全场风格式转换为均匀风文件时，使用以下假设：
- 阵风速度、水平切变和垂直线性切变均为0。
- 均匀风参考高度在全场网格点上。
- 上流角使用参考点处的平均上流值计算。
- 在将速度写入均匀风文件之前，从参考网格点中移除平均风向和上流角。
- 文件中的风向是平均风向与瞬时U和V风分量之间计算的瞬时方向之和。
- 幂律指数可以是：
  1. InflowWind中指定的幂律指数（如果使用幂律风廓线来添加到原生Bladed或HAWC2文件的湍流中），或者
  2. 使用两个点的平均风速计算：参考（轮毂）高度和网格上最高高度。
accel标志
-------------------
InflowWind中添加了计算流场加速度的功能，以支持MHK水下涡轮机的分析。需要加速度来计算流体与转子相互作用的流体惯性效应。支持对均匀/稳态风和基于网格的风廓线（Turbsim、HAWC和Bladed文件）计算加速度。启用此标志会使驱动程序除了输出点文件中定义的点的速度外，还输出这些点的流场加速度。
BoxExceedAllow标志
-------------------
InflowWind中添加了一项功能，允许某些请求的点位于全场风网格之外。这允许对超出网格的值进行连续外推，趋近于平均水平。
用途
~~~~~~~
当InflowWind与OpenFAST耦合时，对应于AeroDyn 15中的自由涡尾流模块（OLAF）和LidarSim模块的风点可能在全场风数据之外。其他风数据点不得在网格之外（AeroDyn叶片必须在风箱内）。OLAF的尾流可能会随着时间的推移偏离全场风箱，在这种情况下，它应该离涡轮机足够远，以至于报告的风值的任何不准确性对涡轮机的影响很小或没有影响。此处采用的方法应允许尾流继续演变，而不会由于风网格边界的不连续性导致流动反向或其他异常情况。然而，为了限制所使用的近似的影响，在远离涡轮机之前，不应允许尾流离开风箱。
另一个用例是当LidarSim请求远离涡轮机的数据可能位于风箱之外时，例如偏航或浮式涡轮机，其中传感光束周期性地离开风箱。
方法
~~~~~~
在初始化期间，传递一个标志和相应的索引，告诉IfW允许请求的位置数组中的点从该索引开始位于全场风和塔架网格之外。然后使用全场风的数据按如下方式外推这些点的值：
   1. 在初始化期间计算并存储每个时间步每个Z高度的平均风值（在Y维度上平均）。
   2. 全场风网格上方的风在网格顶部的值与网格顶部的平均值之间进行线性插值。此线性插值区域从网格顶部延伸到网格顶部加上半个网格高度（``FFZHWid``）。超出该区域的值保持恒定。
   3. 超出+/-Y网格边缘的值在网格边缘的值与该Z高程在网格中的平均值之间进行线性插值。插值区域在网格边缘和沿Y方向再延伸半个网格宽度的``+/-2*FFYHWid``之间。
   4. 当不存在塔架数据时，网格下方的值在网格底部和地面的0之间进行线性插值。
   5. 当存在塔架数据时，网格下方的点在塔架和网格与地面之间插值（在``+/-2*FFYHWid``处为0值）。然后在网格边缘之外使用线性插值。
使用驱动程序测试
~~~~~~~~~~~~~~~~~~~
要测试此功能，驱动程序接受``BoxExceedAllow``标志，并通知InflowWind所有风网格点可以超出网格边缘。要使用此功能，请设置一个驱动输入文件，其输出风网格大于相应InflowWind输入文件中引用的风文件的全场网格。然后可以使用以下命令（Linux语法，Windows略有不同）：
.. code-block:: bash
    > inflowwind_driver -BoxExceedAllow MyDriverFile.inp
