MoorDyn 用户指南
====================

MoorDyn 的文档可在 `此处 <https://moordyn.readthedocs.io>`_ 查阅。文档内容包括
MoorDynF（OpenFAST 中的模块）和 MoorDynC（独立 C++ 代码）的使用说明。输入文件格式
在 `输入文件章节 <https://moordyn.readthedocs.io/en/latest/inputs.html>`_ 中有详细描述
（`MoorDyn 用法 <https://moordyn.readthedocs.io/en/latest/inputs.html#the-v2-input-file>`_，特别是 V2 版本章节），
以及 MoorDyn 在 FAST.Farm 层面的使用
（`MoorDyn 与 FAST.Farm <https://moordyn.readthedocs.io/en/latest/inputs.html#moordyn-with-fast-farm-inputs>`_），
并提供了相关理论的出版文献链接。


以下链接提供了 MoorDynF 和 MoorDynC 的使用示例：

`MoorDyn 使用示例 <https://github.com/FloatingArrayDesign/MoorDyn/tree/dev/example>`_
