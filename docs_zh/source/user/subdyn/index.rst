
SubDyn 用户指南和理论手册
======================================

.. only:: html

   本手册提供了 SubDyn 软件程序的快速参考指南和更深入的理论指南。
   它旨在供普通用户与 OpenFAST 和 HydroDyn 手册结合使用。
   本文档最初基于 Damiani 等人的 :cite:`subdyn:manual` 编写。
   本手册将随着新版本发布和需要而更新，以提供有关软件进步或修改的更多信息。


   作者在此感谢以下贡献者：R. Damiani、E. Branlard、J. Jonkman、A. Robertson、F. Wendt 和 B. Barahona。其他贡献者可在 GitHub 上找到。
   我们也感谢美国能源部风能和水能计划对本软件开发的支持。
