附录 B. OC4 导管架驱动程序文件
==================================

SubDyn 驱动程序输入文件
:download:`（OC4 导管架驱动程序文件）<./examples/OC4_Jacket_SD_Driver.dvr>`：

该文件包含以下信息：环境条件（重力和水深）、
数值求解参数（例如积分时间间隔、时间步数）、TP 参考点在全局参考系中的坐标、
结构几何形状绕全局 Z 轴的旋转角度（度）、TP 参考点位移、速度和加速度的输入模式（稳态或来自文件的时间序列）以及任何相关的输入
文件（如果不是稳态输入）。
