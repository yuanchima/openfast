附录 F. SubDyn 主要变更
===================================

SubDyn（v0.4）首次发布时，作为 FAST v8 的一个未文档化功能包含在内，
并以独立归档文件形式提供。自 v0.4 以来，
SubDyn 已充分集成到 FAST v8 和 OpenFAST 中，同时独立形式
也仍可使用。本附录概述了自 v0.4 以来对 SubDyn 所做的重要修改。
以下为用户可能注意到的
主要变更，更多信息请参阅正式归档文件中的 *changelog.txt* 文本文件
以及 GitHub 日志。



V1.05.00（2021 年 10 月）
-----------------------

- 版本 1.05.00 集成于 OpenFAST 版本 3.1+

- SubDyn 驱动程序支持在给定节点施加载荷

- 输出 Craig-Bampton/Guyan 和 FEM 模态为 JSON 格式以便可视化

- 精简的 yaml 文件输出，包含不同点处的刚体质量矩阵

- 修复了刚性装配体的 bug

- 修复了汇总文件中质量报告的 bug


V1.04.00（2020 年 9 月）
-------------------------

- 版本 1.04.00 集成于 OpenFAST 版本 2.4

- 杆件类型：梁、刚性连杆、预张缆索

- 节点类型：悬臂、万向节、销连接、球连接

- 支持输入集中质量的所有项

- Guyan 阻尼矩阵

- 额外力臂

- 与 SoilDyn 耦合

- 通过约束节点处的柔性固定度和一个新的输入文件实现土壤-结构相互作用（SSI），
  允许使用 6×6 刚度和质量矩阵来模拟这些节点处的边界条件。

- 可控预张缆索单元


V1.03.00a-rrd（2017 年 9 月）
------------------------------

- 版本 1.03.00a-rrd 集成于 `OpenFAST 软件 <https://github.com/OpenFAST/OpenFAST>`__。



V1.01.01a-rrd（2014 年 9 月）
------------------------------

版本 1.01.01a-rrd 集成于 `FAST v8 软件 <http://wind.nrel.gov/designcodes/simulators/fast8>`__
v8.09.00a-bjj。

-  有限元特征值 bug 修复：完整系统特征值在汇总文件中被错误报告，
   但对结果没有进一步影响。此 bug 现已修复。

-  剪切面积修正系数改进：Timoshenko 处理中的剪切面积修正
   系数现在与 Steinboeck 等人（2013）一致。

-  TP 反力的公式已重新排列，以符合理论手册，
   对输出结果没有影响。


V1.01.00a-rrd（2014 年 6 月）
------------------------------

版本 1.00.01a-rrd 集成于 `FAST v8 软件 <http://wind.nrel.gov/designcodes/simulators/fast8>`__
v8.08.00c-bjj。

新实现具有明确定义的数据交换接口
（`遵循 FAST 模块化框架 <http://wind.nrel.gov/designcodes/simulators/developers/>`__），
这将使 SubDyn 集成到其他多物理场软件包中变得更加简单。

自版本 v0.4 以来，实施了多项改进和 bug 修复，
并且模块经过了广泛的验证工作，取得了良好结果。

-  特征求解器 bug 修复：LAPACK 求解器在单精度下被证明不稳定，
   现在仅以双精度运行，无论代码其他部分使用的精度如何。

-  输入文件格式已更改。请参阅附录 A 中的示例输入文件
   以及以下说明：

   -  第一行标题行已移除。

   -  仿真控制节：

      -  **SDeltaT**："DEFAULT" 关键字（代替 0.0）现在
         用于指示 SubDyn 将使用耦合框架时间步进行时间积分。

      -  **IntMethod**：允许值现在为 1-4（代替 0-3）。

      -  **SttcSolve**：新增标志。如果设置为 TRUE，
         将使用静态改进法（SIM）。

   -  FEA 和 Craig-Bampton 参数节：

      -  在 v0.4 中，必须为所有保留的 Craig-Bampton 模态
         指定阻尼系数，或为所有模态仅指定一次（如果 **CBMod** = FALSE）。
         在此版本中，用户可以输入任意数量的阻尼系数。
         如果保留的 C-B 模态数（**NModes**）大于输入的
         阻尼系数数量（**JDampings**），最后一个
         阻尼值将复制给所有剩余模态。

   -  基座约束节点、界面节点、杆件和杆件方向余弦矩阵节：

      -  在输入文件的所有表格中，标题下方应有一行单位说明。

   -  输出：汇总和输出文件节：

      -  此节现在也包含之前分配在
         "输出：FAST/SubDyn 输出文件变量" 节下的参数

-  汇总文件中的某些量已修正。
   事实上，由于索引不匹配，某些输出矩阵输出了错误的值。
   新的汇总文件更短，不包含某些 CB 方法矩阵，除非
   设置了编译器指令 DEBUG。

-  SIM。这一新实现有助于最小化捕获某些载荷（如静态
   重力和浮力载荷或从风力机传递的高频载荷）贡献所需的模态数。
   在之前的版本中，需要大量内部模态来
   激发由静态和高频力激励的子结构模态。这些模态不再需要，
   可以在保留更少模态的同时仍获得准确结果（另见 :numref:`subdyn-theory`）。
   启用 SIM 后，所有未被 Craig-Bampton 缩减考虑的模态
   按准静态方式处理。

-  现在可以保留零个内部 C-B 模态，
   从而仅依赖 SIM，适用于子结构的第一特征频率
   远高于整个系统预期含能模态频率的情况。

-  SubDyn 与 FAST 的耦合现在包括与 HydroDyn 水动力学模块的
   完整水弹性耦合。
