附录 A. OC4 导管架输入文件
=================================

SubDyn 主输入文件
:download:`（OC4 导管架 SubDyn 输入文件）<./examples/OC4_Jacket_SD_Input.dat>`：

该文件包含以下信息：积分方法（例如 Adams-Bashforth 4 阶）、
数值求解参数（例如积分时间间隔、静力求解器标志、Craig-Bampton 缩减中保留的模态数）、
有限元分析信息（梁单元模型、每根杆件的单元数），
以及通过节点、杆件连接关系和杆件截面属性定义的梁杆件几何形状。
该文件还指定了任何 SSI 输入文件（土壤/桩的刚度和质量矩阵）。
