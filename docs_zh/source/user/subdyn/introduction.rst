简介
============

`SubDyn <https://nwtc.nrel.gov/SubDyn>`__ 是由落基山国家实验室（NLR）在美国能源部风能和水能计划支持下开发的多构件固定式基础子结构时域结构动力学模块。该模块已耦合到 FAST 气动-水动-伺服-弹性耦合计算机辅助工程（CAE）工具中。SubDyn 支持的子结构类型包括单桩、三脚架、导管架以及其他常见于浅海和过渡水深海上风电装置的非浮式格构式子结构。SubDyn 也可用于建模陆上风电机组的格构式支撑结构。

新的 SubDyn 模块遵循 FAST 模块化框架的要求，与 `OpenFAST <http://wind.nrel.gov/designcodes/simulators/fast8/>`__ 耦合，并提供了（相对于之前发布的软件版本）建模多构件子结构动态载荷的新功能。（有关不同版本之间变更的更多详细信息，请参阅附录 E 和归档文件中提供的 *changelog.txt* 文件。）SubDyn 也可以作为独立代码运行，用于计算子结构在塔筒界面指定运动下的模态振型、固有频率和时域响应，此时不需要与 FAST 耦合，也没有重力以外的外部载荷。

SubDyn 依赖于两个主要的工程模式：(1) 线性框架有限元梁模型（LFEB），以及 (2) 通过 Craig-Bampton（C-B）方法和静态改进方法（SIM）进行的动力学系统降阶，大大减少了获得精确解所需的模态数量。更多详细信息请参见第 6 节，以及 :cite:`song2013`、:cite:`damiani2013`、:cite:`damiani2013omae`、:cite:`jonkmantcf`。

在 SubDyn 中，子结构被认为是在海床处被夹紧或由弹簧支撑，并在子结构顶部节点（界面节点）处与过渡段（TP）刚性连接。弹簧常数由用户提供，用于模拟土-结构相互作用（SSI）。未来可能会实现其他约束公式。SubDyn 仅用于建模子结构的结构动力学。当与 FAST 集成时，过渡段、塔筒和转子-机舱组件（RNA）的结构动力学在 FAST 的 ElastoDyn 模块中建模，水动力学在 FAST 的 `HydroDyn <https://nwtc.nrel.gov/HydroDyn>`__ 模块中建模。然而，对于完整的格构式支撑结构或其他没有过渡段的结构，整个支撑结构直到偏航轴承都可以在 SubDyn 中建模。例如，在 SubDyn 中而不是 ElastoDyn 中建模塔筒，可以包含更多的前后和左右弯曲模态，从而考虑塔筒及其分段更普遍的柔性。但是，对于管状塔筒，ElastoDyn 中的结构模型往往更准确，因为 ElastoDyn 考虑了 SubDyn 中未处理的几何非线性。

载荷和响应通过 FAST 驱动程序（耦合框架）在 SubDyn、HydroDyn 和 ElastoDyn 之间传递，以在每个耦合时间步实现水弹性相互作用。在界面节点处，过渡段的六个自由度（DOF）位移（三个平移和三个旋转）、速度和加速度是从 ElastoDyn 输入到 SubDyn 的；而过渡段处的六个反作用力载荷（三个力和三个力矩）是从 SubDyn 输出到 ElastoDyn 的。SubDyn 还将局部子结构的位移、速度和加速度输出到 HydroDyn，以计算成为 SubDyn 输入的局部水动力载荷。此外，SubDyn 可以根据用户请求计算构件内部反作用力载荷（见图 1）。

输入文件定义了子结构几何形状、材料属性、约束和 SSI 数据文件、有限元分辨率、动力学系统降阶中保留的模态数量、模态阻尼系数以及辅助参数。几何形状由全局参考系（惯性坐标系，原点位于未偏转塔筒中心线与平均海平面（MSL）或陆基结构地面的交点）中的节点坐标定义。构件连接两个节点；多个构件可以共用一个节点。节点是将构件细分为多个（***NDiv*** 输入参数）单元的结果（节点位于每个单元的端部），由模块计算得出。

在当前版本中，构件的几何形状由其外径和壁厚定义（假设为管状几何形状），材料属性由其杨氏模量、剪切模量和质量密度定义。构件属性在节点处指定；如果属性在两个节点之间变化，它们将对内部单元进行线性插值。因此，锥形构件将被视为具有阶跃式属性变化的圆柱形构件。在未来版本中，将实现锥形有限元公式，并提供锥形构件更准确的表示。

水动力载荷（包括浮力）由 HydroDyn 计算，并由耦合框架传递到水下的那些节点（淹没节点）。此外，自重分布载荷分量（来自重力）由 SubDyn 计算并应用于所有节点。请注意，其他载荷和惯性属性可以通过 HydroDyn 模块输入文件输入，其中可以指定海洋生物附着和构件的充水/压载情况。
