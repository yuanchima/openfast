附录 D. 输出通道列表
===================================

以下是 SubDyn 模块所有可能的输出参数列表。
名称按含义分组，但用户可以根据需要
在 SubDyn 输入文件的 OUTPUT CHANNELS 节中任意排序。:math:`M \alpha N \beta`
指杆件 :math:`\alpha` 的节点 :math:`\beta`，其中 :math:`\alpha` 是 [1,99] 范围内的数字，
对应于 MEMBER OUTPUT LIST 表（参见 :numref:`SD_Member_Output`）中的第 :math:`\alpha` 行，
:math:`\beta` 是 [1,9] 范围内的数字，对应该表条目 **NodeCnt** 列表中的节点 :math:`\beta`。

部分输出位于 SS 参考坐标系（全局惯性系坐标系）中，以 `ss` 后缀结尾；
其他输出参考局部（杆件）参考系，后缀为
"Xe"、"Ye" 或 "Ze"（参见第 7 节）。
