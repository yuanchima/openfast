
.. _sd_output-files:

输出文件
============

SubDyn 生成三种类型的输出文件：回显文件、摘要文件和时间序列结果文件。以下各节详细说明这些文件的用途和内容。

回显文件
---------

如果用户在 SubDyn 驱动文件或 SubDyn 主输入文件中将 **Echo** 标志设置为 TRUE，这些文件的内容将被回显到一个文件中，
命名约定为：驱动输入文件的回显文件为 **OutRootName.dvr.ech**，SubDyn 主输入文件的回显文件为 **OutRootName.SD.ech**。
**OutRootName** 可以在驱动输入文件的 SUBDYN 部分指定，或者在 FAST 输入文件中指定。回显文件有助于调试输入文件。
如果 SubDyn 在解析输入文件时遇到错误，回显文件的内容将被截断。错误通常对应于最后成功回显行的下一行。

.. _sd_sum-file:

摘要文件
------------

如果 **SumPrint** 参数设置为 TRUE，SubDyn 将生成命名约定为 **OutRootName.SD.sum** 的摘要文件。
此文件汇总了子结构模型的关键信息，包括：

- 未变形节点几何：所有（**NNodes**）节点的列表以及全局 SS 坐标系中的 *X*、*Y*、*Z* 坐标。
  请注意，根据 **NDiv**（主输入文件参数）的不同，**NNodes** 可能大于或等于 **NJoints**。

- 单元连接性和端节点属性：所有（**NElems**）单元的列表、起始和结束节点（**Node_I**、**Node_J**）
  以及起始和结束节点的属性集 ID（**Prop_I**、**Prop_J**）。根据 **NDiv**（主输入文件参数）的不同，
  **NElems** 可能大于或等于 **NMembers**。

- 属性集。如果使用锥形构件，根据插值的直径和厚度值，可能会包含主输入文件中指定的属性集之外的附加属性集。
  标题及其含义与相关节中描述的相同。

- 反力自由度和界面自由度及其相关约束；列出了与反力和界面节点相关的自由度的实际索引（**DOF_ID**）以及（1/0）标志，
  以区分约束级别。

- 集中质量表。这是主输入文件中相应部分的回显。请参考相关节。

- 构件表，包括与节点、单元的连接及其质量。表格按标识符（**MemberID**）列出所有构件，
  包括其起始和结束节点（**Joint1_ID**、**Joint2_ID**）、相关质量（**Mass**）以及沿构件长度的节点标识符列表。

- 构件的方向余弦矩阵。每行（第 2-10 列）对应于第一列中列出标识符的构件的方向余弦矩阵条目
 （**DC(1,1)** 到 **DC(3,3)**）。方向余弦矩阵指定了每个构件从全局参考到局部坐标系的转换。

- 完整子结构系统的排序特征频率（单位：赫兹（Hz））（忽略可能通过 FAST 与 ElastoDyn 的耦合），
  假设过渡段参考点是自由端。共有 **NDOFs** 个特征频率和特征向量。

- C-B 降阶系统的排序特征频率（单位：Hz），假设过渡段参考点是固定端。共有 **Nmodes** 个 C-B 降阶特征频率和特征向量。

- 完整子结构系统特征向量。每列代表与文件前面标识的相应特征频率相关联的特征向量。

- C-B 降阶系统特征向量（**PhiM** 矩阵）。每列代表与文件前面标识的相应特征频率相关联的特征向量。

- **PhiR** 矩阵或由界面自由度的单位刚体运动引起的内部节点位移（请参见相关节）。
  矩阵的每列表示对于每个基础和界面节点，沿界面自由度的给定单位刚体运动的内部自由度位移。

- 基于 Guyan 降阶的、参考到过渡段参考点的子结构等效刚度和质量矩阵（**KBBt** 和 **MBBt**）。
  这些在为 ElastoDyn 计算塔筒特征模态时，对于计算子结构柔性的影响很有用。

- 相对于全局原点的刚体等效质量矩阵（**MRB**）；一个 6x6 的质量矩阵。

- 子结构总（干）质量。

- 全局坐标系中的子结构质心坐标。

摘要文件的各个部分和变量都是不言自明的，并且在文件中很容易识别。

结果文件
------------

当 **OutSwtch** 设置为 1 或 3 时，SubDyn 时间序列结果将写入命名约定为 **OutRootName.SD.out** 的文本文件中。
如果 SubDyn 与 FAST 耦合并且 **OutSwtch** 设置为 2 或 3，则 FAST 将生成包含 SubDyn 结果的主结果文件。
**OutRootName.SD.out** 中的结果采用表格格式，其中每列是一个数据通道（第一列始终是仿真时间），每行对应一个仿真时间步。
数据通道在输入文件的 SDOutList 部分指定。SubDyn 生成的文件的列格式使用输入文件的 **OutFmt** 和 **OutSFmt** 参数指定。
