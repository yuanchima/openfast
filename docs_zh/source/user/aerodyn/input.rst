.. _ad_input:

输入文件
=======

v4.0版本的重要变更
~~~~~~~~~~~~~~~~~~~~
从4.0版本开始引入了一些重要变更。请参考:ref:`api_change_ad4x`了解新旧输入之间的关联。
本文档已更新以包含这些变更。

介绍
~~~~
用户通过AeroDyn主输入文件以及独立的翼型和叶片数据输入文件配置气动模型参数。当以独立模式运行时，还需要额外的驱动输入文件。AeroDyn驱动和驱动输入文件的细节详见:numref:`ad_driver`。驱动文件指定了通常由OpenFAST提供给AeroDyn的初始化输入，以及AeroDyn的每时间步输入。

例如，`driver.dvr`是主驱动文件，`input.dat`是主输入文件，`blade.dat`包含叶片几何数据，`airfoil.dat`包含翼型攻角、升力、阻力、力矩系数和压力系数。示例输入文件包含在:numref:`ad_appendix`中。

除了翼型数据文件中指定行数的表格和注释行外，请勿在输入文件中添加或删除任何行。

单位
-----
AeroDyn使用国际单位制（kg, m, s, N）。除非另有说明，角度默认单位为弧度。

AeroDyn主输入文件
-------------------
AeroDyn主输入文件定义了建模选项、环境条件（来流除外）、翼型、塔筒节点离散化和属性、塔筒、轮毂和机舱属性，以及输出文件规范。

文件分为多个功能部分，每个部分对应气动模型的一个方面。AeroDyn主输入文件的示例见:numref:`ad_appendix`。

输入文件开头两行是头信息，仅供用户使用，软件不会读取。

常规选项
~~~~~~~~
如果希望AeroDyn回显AeroDyn主文件、翼型文件和叶片输入文件的内容（有助于调试输入文件错误），请将``Echo``标志设置为TRUE。回显文件的命名格式为*OutRootFile.AD.echo*。当独立运行AeroDyn时，*OutRootFile*由驱动输入文件的I/O设置部分指定；当运行耦合仿真时，由OpenFAST程序指定。

``DTAero``设置气动计算的时间步长。为了保证精度和数值稳定性，建议设置``DTAero``使得转子每转至少有200个方位角步。但当AeroDyn与OpenFAST耦合时，OpenFAST可能需要比这个经验法则小得多的时间步长。如果启用UA同时使用非常小的时间步长，可能需要使用双精度重新编译AeroDyn，以避免UA例程中的数值问题。``DTAero``使用关键字``DEFAULT``表示AeroDyn采用驱动代码（OpenFAST或独立驱动程序）指定的时间步长。

**Wake_Mod**：如果希望诱导速度为零，设置为0；设置为1则使用BEM理论模型包含诱导效应。当``Wake_Mod``设置为3时，使用自由涡尾流模型，也称为OLAF（参见:numref:`OLAF`）。在线性化分析中，``Wake_Mod``不能设置为3。

.. note::
    与旧输入的关联：旧输入`WakeMod`已移除，`WakeMod=2`过去表示DBEMT，现在由`DBEMT_Mod`控制。`Wake_Mod=2`为未来诱导计算方法预留的占位符。

**~~AFAeroMod~~**：该输入已移除，请参见下文的``UA_Mod``。
**~~FrozenWake~~**：该输入已移除，请参见下文的``DBEMT_Mod``。

设置``TwrPotent``为0以禁用塔筒对叶片局部流体流动的势流影响；设置为1启用标准势流模型；设置为2在势流模型中包含Bak修正。

设置``TwrShadow``为0以禁用塔筒阴影模型；设置为1启用Powles塔筒阴影模型；设置为2使用Eames塔筒阴影模型。这些模型基于下游塔筒阴影模型计算塔筒对叶片局部流动的影响。如果同时启用势流的塔筒影响和塔筒阴影，两种影响将叠加。

设置``TwrAero``标志为TRUE以计算塔筒上的流体阻力载荷，FALSE则禁用这些效应。

在AeroDyn与OpenFAST耦合且启用BEM（``Wake_Mod = 1``）的线性化分析中，设置``DBEMT_Mod=-1``以采用冻结尾流假设（即在线性化期间将轴向和切向诱导速度固定在其工作点值）；设置``DBEMT_Mod=3``则使用连续动态尾流模型。

设置``CavitCheck``标志为TRUE以针对MHK涡轮机执行空化检查，FALSE则禁用该计算。如果``CavitCheck``为TRUE，``UA_Mod``必须设置为0，因为空化检查不支持非定常翼型气动。如果``CavitCheck``为TRUE，AeroDyn或OpenFAST驱动输入文件中的``MHK``标志必须设置为1或2，表示正在建模MHK涡轮机。

设置``NacelleDrag``标志为TRUE以计算机舱上的阻力载荷，FALSE则禁用该计算。

设置``CompAA``标志为TRUE以运行气动声学计算。该选项仅在``Wake_Mod = 1``时可用，且不适用于MHK涡轮机。有关如何使用该功能的信息请参见:numref:`AeroAcoustics`。

``AA_InputFile``用于指定气动声学子模块的输入文件。有关如何使用该功能的信息请参见:numref:`AeroAcoustics`。

环境条件
~~~~~~~~
环境条件现在在驱动输入文件中指定，但为了旧版本兼容性，仍保留在AeroDyn主输入文件中。使用关键字``DEFAULT``将使用驱动输入文件中指定的值，否则AeroDyn主输入文件中给出的值将覆盖驱动输入文件中的值。
``AirDens``指定流体密度，必须大于零；空气（风力机）的典型值约为1.225 kg/m³，海水（MHK涡轮机）约为1025 kg/m³。
``KinVisc``指定流体的运动粘度（用于雷诺数计算）；空气的典型值约为1.460E-5 m²/s，海水约为1.004E-6 m²/s。
``SpdSound``是流体中的声速（用于非定常翼型气动计算中的马赫数计算）；空气的典型值约为340.3 m/s，海水约为1500 m/s。
该部分的最后两个参数仅在MHK涡轮机的``CavitCheck = TRUE``时使用。``Patm``是自由液面上方的大气压，典型值约为101325 Pa。``Pvap``是流体的蒸气压，海水的典型值约为2000 Pa。

叶素动量理论选项
~~~~~~~~~~~~~~~~~
**BEM_Mod**：确定使用的BEM算法类型。
- ``BEM_Mod=2``（推荐）：使用新的AeroDyn BEM实现，采用局部交错极网格坐标系，更适合大锥角情况。还包含可选的动量修正，对大偏斜情况很重要（参见``SkewMomCorr``）。该功能将在后续版本中完善文档。
- ``BEM_Mod=1``（向后兼容）：使用旧的AeroDyn BEM实现，采用无后掠变桨扭转坐标系。

.. note::
    与旧输入的关联：旧实现默认对应``BEM_Mod=1``。

.. warning::
    ``BEM_Mod``目前控制“未明确定义”输出（即没有指定坐标系的输出）使用的坐标系，例如后缀为“x”和“y”的输出。其他未明确定义的输出包括典型的BEM量，如“Axlnd”、“TnInd”、“Phi”等。这些输出的坐标系根据``BEM_Mod``的不同而不同。为了在不同``Wake_Mod``下保持一致性（即使``Wake_Mod≠1``），使用``BEM_Mod``确定未明确定义输出的坐标系。

以下该部分的输入仅在``Wake_Mod = 1``时使用。

**Skew_Mod**：确定偏斜修正模型（用于偏航和倾斜）：
- ``Skew_Mod=1``：激活Glauert偏斜模型（推荐）。该模型包含两个部分：动量修正（``SkewMomCorr``）和速度重新分布模型（``SkewRedistr_Mod``）。
- ``Skew_Mod=0``：完全不使用偏斜模型（不推荐）。
- ``Skew_Mod=-1``：丢弃非法向分量（用于线性化）。该设置确保风速始终垂直于转子，以限制转子不垂直于风时（例如塔顶倾斜或倾斜）风速的周期性变化。主要用于线性化。

目前（``Skew_Mod=0``）或（``Skew_Mod=1``且``SkewMomCorr=FALSE``且``SkewRedistr_Mod=0``）的效果相同，这两种输入都会完全关闭偏斜修正。

.. note::
    与旧输入的关联：旧实现始终启用偏斜模型。``Skew_Mod=-1``替代了旧的``SkewMod=0``选项，很少有用户使用该选项。

**SkewMomCorr**：开启或关闭偏斜动量修正（仅在``Skew_Mod=1``时使用）。该功能将在后续版本中完善文档。

.. note::
    与旧输入的关联：旧行为对应``SkewMomCorr=False``。

**SkewRedistr_Mod**：允许开启或关闭诱导速度重新分布模型，并为其他模型的选择和实现预留空间。默认值为1。
- 0：不重新分布
- 1：Glauert（Pitt-Peters）重新分布模型

**SkewRedistrFactor**：定义Glauert重新分布模型中使用的常数（``SkewRedistr_Mod=1``）。使用``"default"``采用默认值:math:`\frac{15 \pi}{32}`。

BEM算法选项
~~~~~~~~~~~
设置``TipLoss``为TRUE以包含Prandtl叶尖损失模型，FALSE则禁用。同理，设置``HubLoss``为TRUE以包含Prandtl轮毂损失模型，FALSE则禁用。

设置``TanInd``为TRUE以在BEM解中包含切向诱导（来自角动量平衡），FALSE则忽略。设置``AIDrag``为TRUE以在轴向诱导计算中包含阻力，FALSE则忽略。如果``TanInd = TRUE``，设置``TIDrag``为TRUE以在切向诱导计算中包含阻力，FALSE则忽略。即使BEM迭代中不使用阻力，在得到诱导结果后，阻力仍会用于计算节点载荷。

``IndToler``设置BEM解的迭代非线性求解的收敛阈值。非线性求解基于入流角，但``IndToler``表示无量纲残差方程的容差，无物理关联。如果使用关键字``DEFAULT``替代数值，当AeroDyn以单精度编译时，``IndToler``设置为5E-5；以双精度编译时设置为5E-10，建议使用这些默认值。``MaxIter``确定BEM求解的最大迭代步数。如果BEM求解的残差值在``MaxIter``步内仍不小于等于``IndToler``，AeroDyn将退出BEM求解器并返回错误信息。

剪切修正
~~~~~~~~
BEM算法可能需要修正以考虑剪切效应。目前实现了扇区平均修正（测试功能），以限制叶片旋转时风速变化带来的波动。

该功能将在后续版本中完善文档，目前仍处于实验阶段。

**SectAvg**：使用扇区平均（标志）。该方法使用相对于叶片当前方位角向前和向后扩展的扇区（参见``SectAvgPsiBwd``和``SectAvgPsiFwd``）。通过为扇区内不同点赋予不同权重，对扇区内的速度进行平均（参见``SectAvgWeighting``）。

**SectAvgWeighting**：扇区平均的权重函数。1表示均匀权重（开关）（仅在``SectAvg=True``时使用）。默认值为1。

**SectAvgNPoints**：每个扇区的点数（-）（仅在``SectAvg=True``时使用）。默认值为5。

**SectAvgPsiBwd**：扇区起始位置相对于叶片方位角的后向方位角（度）。必须为负值（仅在``SectAvg=True``时使用）。默认值为-60度。

**SectAvgPsiFwd**：扇区结束位置相对于叶片方位角的前向方位角（度）。必须为正值（仅在``SectAvg=True``时使用）。默认值为60度。

动态尾流/动态入流模型
~~~~~~~~~~~~~~~~~~~~~~
该部分的输入参数仅在``Wake_Mod = 1``时使用。理论详见:numref:`AD_DBEMT`。

动态尾流（也称为动态入流）模型由输入``DBEMT_Mod``控制：
- ``0``：无动态尾流，也称为准稳态尾流模型（不推荐）。
- ``-1``：冻结尾流，给定工作点的诱导速度保持恒定（仅用于简化线性化）。
- ``1``：离散时间Oye模型，使用恒定的:math:`\tau_1`。
- ``2``：离散时间Oye模型，使用变化的:math:`\tau_1`，根据入流自动调整（推荐用于时域仿真）。
- ``3``：连续时间Oye模型，使用恒定的:math:`\tau_1`（推荐用于线性化）。

对于``DBEMT_Mod=1``或``DBEMT_Mod=3``，用户有责任根据:numref:`AD_DBEMT`中给出的表达式设置:math:`\tau_1`的值（即``tau1_const``），需要预估给定仿真的平均轴向诱导(:math:`\overline{a}`)和转子上的平均相对风速(:math:`\overline{U_0}`)。

只有``DBEMT_Mod={-1,3}``选项可用于线性化。

.. note::
    与旧输入的关联：
    ``DBEMT_Mod=-1``选项的行为与旧的``FrozenWake=True``相同。
    ``DBEMT_Mod=0``的行为与旧的``WakeMod=1``选项相同。
    ``DBEMT_Mod=J``（J为1、2、3）的行为与旧的``WakeMod=2``且``DBEMT_Mod=J``相同。

OLAF - 对流拉格朗日细丝（自由涡尾迹）理论选项
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
该部分的输入参数仅在``Wake_Mod = 3``时使用。

自由涡尾迹模型的设置在OLAF输入文件中指定，详见:numref:`OLAF-Input-Files`。``OLAFInputFileName``是该输入文件的文件名。

非定常翼型空气动力学选项
~~~~~~~~~~~~~~~~~~~~~~~~~
**AoA34**：确定基准攻角是在3/4弦长位置采样还是在气动中心点采样。大多数``UA_Mod``需要将``AoA34``设置为true。但使用准稳态气动时，用户可选择将其设置为true或false。

.. warning::
    由于开发分支和不稳定分支之间的滞后，该功能目前尚未实现。

.. note::
    与旧输入的关联：``AFAeroMod=1``意味着``AoA34=False``。但为了在稳态和非定常气动模型之间进行公平比较，在使用准稳态气动时最好将``AoA34=True``。

``UA_Mod``确定使用的UA模型，可选值如下：
- ``0``：无非定常翼型气动。
- ``1``：Beddoes-Leishman（B-L）离散时间模型（**目前尚未可用**）。
- ``2``：González开发的B-L扩展模型（修改了Cn、Cc、Cm）。
- ``3``：Minnema/Pierce开发的B-L扩展模型（修改了Cc和Cm）。
- ``4``：Hansen、Gaunaa和Madsen（HGM）开发的4状态连续时间B-L模型。注意：在实现刚性积分器之前，可能需要更小的时间步长。
- ``5``：5状态连续时间B-L模型，与HGM类似，增加了涡生成状态。
- ``6``：Oye开发的1状态连续时间模型。
- ``7``：离散时间波音- Vertol（BV）模型。

``UA_Mod=4、5、6``（使用连续时间状态）支持线性化，其他模型不支持。不同模型的描述详见:numref:`AD_UA`。

.. note::
    与旧输入的关联：如果``UA_Mod>0``，则等效于旧的``AFAeroMod=2``。

**虽然本手册记录了所有UA模型，但原始B-L模型目前尚未可用。测试表明，如果针对给定翼型、雷诺数和/或马赫数适当设置UA模型参数，González和Minnema/Pierce模型能够产生合理的法向力、切向力和俯仰力矩系数滞后。然而，即使使用默认UA模型参数，结果也会与早期版本的AeroDyn（基于Minnema/Pierce对B-L的扩展）略有不同，因为版本之间的UA模型逻辑存在差异。我们建议用户使用均匀入流和固定偏航误差运行测试用例（例如通过独立的AeroDyn驱动程序），以检查法向力、切向力和俯仰力矩系数滞后的准确性，并适当调整UA模型参数。**

``FLookup``确定如何计算无量纲分离距离值*f'*。当``FLookup``设置为TRUE时，通过查询静态升力系数和阻力系数数据表来确定*f'*。**使用最佳拟合指数方程（``FLookup = FALSE``）目前尚未可用，因此在本版本的AeroDyn中``FLookup``必须为TRUE。**注意，当``UA_Mod=4``或``UA_Mod=5``时，不使用``FLookup``。

``UAStartRad``是动态失速开启的起始转子半径。输入0到1之间的数，表示转子半径的分数，用于指定非定常气动开始开启的位置。如果输入文件中省略该行，``UAStartRad``默认值为0（从叶根开始开启）。所有位于转子半径小于``UAStartRad``的叶片节点，在整个仿真过程中都会关闭非定常气动。

``UAEndRad``是动态失速开启的结束转子半径。输入0到1之间的数，表示转子半径的分数，用于指定非定常气动开启的最后位置。如果输入文件中省略该行，``UAEndRad``默认值为1（叶尖）。所有位于转子半径大于``UAEndRad``的叶片节点，在整个仿真过程中都会关闭非定常气动。

.. _airfoil_information:

翼型信息
~~~~~~~~
该部分定义翼型数据输入文件信息。翼型数据输入文件（每个翼型一个）包含升力系数、阻力系数、可选的俯仰力矩系数和最小压力系数随攻角变化的表格，以及UA模型参数，详见:numref:`airfoil_data_input_file`。

翼型信息部分的前5行与每个翼型输入文件中静态翼型系数表的格式相关。``InCol_Alfa``、``InCol_Cl``、``InCol_Cd``、``InCol_Cm``和``InCol_Cpmin``分别是表格中包含攻角、升力系数、阻力系数、俯仰力矩系数和最小压力系数的列号（通常分别为1、2、3、4、5）。如果通过``UseBlCm = FALSE``忽略俯仰力矩项，``InCol_Cm``可设置为0；如果通过``CavitCheck = FALSE``禁用空化检查，``InCol_Cpmin``可设置为0。

使用``NumAFfiles``指定要使用的翼型数据输入文件数量，随后是``NumAFfiles``行的文件名。文件名需用引号括起，可包含绝对路径或相对路径，例如“C:\\airfoils\\S809_CLN_298.dat”或“airfoils\\S809_CLN_298.dat”。如果使用相对路径，是相对于当前文件所在的位置。叶片数据输入文件将通过行号引用这些翼型数据，第一个翼型文件编号为1，最后一个为``NumAFfiles``。

转子/叶片属性
~~~~~~~~~~~~~
设置``UseBlCm``为TRUE以在叶片翼型气动中包含俯仰力矩项，FALSE则忽略；如果``UseBlCm = TRUE``，翼型数据表中必须包含俯仰力矩系数数据，且``InCol_Cm``不能为0。

叶片节点离散化、几何、扭转、弦长、翼型标识以及浮力/附加质量/流体惯性属性在每个叶片的独立输入文件中设置，详见:numref:`blade_data_input_file`。``ADBlFile(1)``是1号叶片的文件名，``ADBlFile(2)``是2号叶片的文件名，``ADBlFile(3)``是3号叶片的文件名；对于双叶片转子，后者不使用；对于单叶片转子，后两个都不使用。文件名需用引号括起，可包含绝对路径或相对路径。每个文件中的数据不必完全相同，因此可以建模气动不平衡。

轮毂属性
~~~~~~~~
该部分的输入参数与轮毂上浮力载荷的计算相关。

``VolHub``是轮毂的体积，``HubCenBx``是轮毂浮力中心在轮毂局部坐标系中相对于轮毂中心的x方向偏移；y和z方向的偏移假设为零。如果要忽略轮毂上的浮力载荷，将``VolHub``设置为0。

由于轮毂和叶片是连接部件，如果包含叶片浮力，也应该包含轮毂浮力，反之亦然。

机舱属性
~~~~~~~~
该部分的输入参数与机舱上的浮力和阻力载荷计算相关，仅在``MHK > 0``或``NacelleDrag = TRUE``时使用。

``VolNac``是机舱的体积，``NacCenB``是机舱浮力中心在机舱局部坐标系中相对于偏航轴承的位置（x、y、z矢量）。如果要忽略机舱上的浮力载荷，将``VolNac``设置为0。仅在``Buoyancy = TRUE``时使用。

``NacArea``是机舱坐标系中机舱的投影面积（Ax、Ay、Az矢量），``NacCd``是``NacArea``定义的三个机舱面积对应的阻力系数（Cdx、Cdy、Cdz矢量），``NacDragAC``是机舱气动中心在机舱局部坐标系中相对于偏航轴承的位置（x、y、z矢量）。仅在``NacelleDrag = TRUE``时使用。

尾翼空气动力学
~~~~~~~~~~~~~~
尾翼气动部分包含两行：

.. code::

    ======  TAIL FIN AERODYNAMICS ========================================================================
        true       TFinAero     - 计算尾翼空气动力学模型（标志）
      ""           TFinFile     - 尾翼气动的输入文件（仅在TFinAero=True时使用）
    ======  TOWER INFLUENCE AND AERODYNAMICS =============================================================

**TFinAero**：激活尾翼空气动力学计算的标志。

**TFinFile**：尾翼输入文件所在的路径（绝对路径或相对于AeroDyn输入文件的路径）。

尾翼输入文件的内容描述详见:numref:`TF_tf_input-file`。

塔筒影响和空气动力学
~~~~~~~~~~~~~~~~~~~~
该部分的输入参数与塔筒影响、塔筒阻力、塔筒浮力、塔筒附加质量和/或塔筒流体惯性计算相关，仅在``TwrPotent > 0``、``TwrShadow > 0``、``TwrAero = TRUE``、``MHK = 1``或``MHK = 2``时使用。

``NumTwrNds``是用户指定的塔筒分析节点数量，决定了后续表格的行数（在两个表头行之后）。``NumTwrNds``必须大于等于2；数值越高，分辨率越细，计算时间越长；建议``NumTwrNds``在10到20之间，以平衡精度和计算成本。每个节点的参数：
- ``TwrElev``：塔筒节点在地面以上的局部高程（对于海上风电和漂浮式MHK涡轮机是相对于平均海平面，对于固定式MHK涡轮机是相对于海床）。
- ``TwrDiam``：局部塔筒直径。
- ``TwrCd``：局部塔筒阻力系数。
- ``TwrTI``：Eames塔筒阴影模型（``TwrShadow = 2``）中使用的湍流强度，为风速波动的分数（而非百分比）。
- ``TwrCb``：塔筒浮力系数。
- ``TwrCp``：塔筒动压力系数。
- ``TwrCa``：塔筒附加质量系数。

``TwrElev``必须以单调递增顺序输入——从最低（塔筒底部）到最高（塔筒顶部）。对于塔筒位于平均海平面以下的漂浮式MHK涡轮机，塔筒节点应输入逐渐增加的负值，从塔筒底部（最靠近平台）到塔筒顶部（最靠近机舱）。

建议``TwrTI``的值在0.05到0.4之间。大于0.4直到1的值会触发警告，提示需要谨慎解释结果，但代码仍允许这些值用于科学研究目的。

``TwrCb``定义为每个节点的塔筒横截面积除以直径等于塔筒截面特征长度（即``TwrDiam``）的圆的面积。对于圆形截面塔筒，每个节点的``TwrCb``通常为1.0。如果要忽略塔筒上的浮力载荷，将``TwrCb``设置为0。如果要忽略塔筒上的附加质量载荷，将``TwrCa``设置为0。如果要忽略塔筒上的流体惯性载荷，将``TwrCp``设置为0。参见:numref:`ad_tower_geom`。

输出
~~~~
将``SumPrint``设置为TRUE会让AeroDyn生成摘要文件，文件名为``<OutFileRoot>.AD.sum``。``<OutFileRoot>``在独立运行AeroDyn时由驱动输入文件的I/O设置部分指定，在运行耦合仿真时由OpenFAST程序指定。摘要文件的细节详见:numref:`sec:ad_SumFile`。如果``UAMod>0``，非定常气动模块还会生成名为``<OutFileRoot>.UA.sum``的文件，列出翼型表中使用的所有UA参数。这允许用户检查代码在没有用户输入的情况下计算参数时使用的值。

AeroDyn可以输出沿塔筒最多9个节点和每个叶片最多9个节点的气动和运动学量。如需每个叶片节点的输出，参见:numref:`AD-Nodal-Outputs`。

``NBlOuts``指定需要输出的叶片节点数量（0到9），下一行的``BlOutNd``是长度为``NBlOuts``的节点编号列表，节点编号在1到``NumBlNds``之间（对应叶片数据输入文件中叶片分析节点表的行号），节点编号之间可以用逗号、分号、空格和/或制表符的任意组合分隔。所有叶片使用相同的输出节点编号。

``NTwOuts``指定需要输出的塔筒节点数量（0到9），下一行的``TwOutNd``是长度为``NTwOuts``的节点编号列表，节点编号在1到``NumTwrNds``之间（对应上方塔筒分析节点表的行号），分隔方式同上。

``OutList``部分控制AeroDyn生成的输出量。输入一行或多行包含引号的字符串，字符串中包含一个或多个输出参数名。输出参数名之间可以用逗号、分号、空格和/或制表符的任意组合分隔。如果在参数名前加上减号“-”、下划线“_”或字符“m”/“M”，AeroDyn会在写入数据前将该通道的值乘以-1。参数按照在输入文件中列出的顺序写入。AeroDyn允许多行输入，以便将列表分成有意义的组，也可以缩短行长度。可以在任何行的闭引号后添加注释。如果某行开头或该行开头的引号字符串开头为“END”，AeroDyn会停止读取更多通道名称。叶片和塔筒节点相关的量会根据上面``BlOutNd``和``TwOutNd``列表中指定的请求节点生成。如果AeroDyn遇到未知/无效的通道名称，会向用户发出警告，并从输出文件中移除该可疑通道。完整的可用输出参数列表参见附录E。

翼型数据输入文件
-----------------
翼型数据输入文件（每个翼型一个）包含升力系数、阻力系数、俯仰力矩系数随攻角变化的表格，以及UA模型参数。在这些文件中，任何第一个非空白字符为感叹号（!）的行都会被忽略（用于插入注释行）。非注释行必须按顺序出现在文件中，但为了可读性，注释行可以随意穿插。翼型数据输入文件的示例见:numref:`ad_appendix`。

``InterpOrd``是AeroDyn通过查表获取升力、阻力、可选的俯仰力矩和最小压力系数随攻角变化时，静态翼型数据的插值阶数。当``InterpOrd``为1时，使用线性插值；为3时，使用三次样条插值；如果输入关键字``DEFAULT``替代数值，``InterpOrd``设置为1。

``RelThickness``是翼型的无量纲厚度（厚度与弦长之比），表示为分数（而非百分比），通常在0.1到1之间。该参数目前在``UA_Mod=7``时使用，未来可能会有更多应用。默认值为0.2，方便使用。

``NonDimArea``是无量纲翼型面积（除以当地``BlChord``的平方），但AeroDyn目前未使用。

``NumCoords``是定义翼型外形的点数，加上一个定义气动中心的点，决定了后续表格的行数；``NumCoords``必须正好为0，或者大于等于3。表格中指定每个点的无量纲X和Y坐标：``X_Coord``和``Y_Coord``（除以当地``BlChord``归一化）。第一个点必须始终是气动中心的位置（翼型升力和阻力的参考点，可能不在翼型表面上）；其余点应定义翼型的外形。AeroDyn目前未使用翼型外形，但当AeroDyn与OpenFAST耦合时，如果启用叶片表面可视化，OpenFAST会使用翼型外形。

``BL_file``是包含翼型边界层特性的文件名。如果不使用气动声学模块，该文件会被忽略。如果不使用气动声学模块，也可以从文件中省略该参数。

通过``NumTabs``设置给定翼型的雷诺数或气动控制相关的数据表数量。翼型数据输入文件中的其余参数按每个表分别输入。

``Re``和``UserProp``是包含表的雷诺数（单位为百万）和气动控制（或用户属性）设置。只有当AeroDyn主输入文件中的``AFTabMod``参数设置为基于``Re``或``UserProp``使用二维插值时，这些值才会被使用。如果使用一维插值（仅基于攻角），则仅使用文件中的第一个表。

如果包含UA模型参数，将``InclUAdata``设置为TRUE。如果设置为FALSE，所有UA模型参数将由代码确定。该部分缺失的任何行的值都将由代码确定，要么使用默认值，要么根据翼型表中的极系数数据计算：

- ``alpha0``：零升攻角（度）。
- ``alpha1``：大于``alpha0``的攻角（度），对应*f*等于0.7，近似为正失速攻角。该参数在``flookup=false``和确定``Cn1``的默认值时使用。
- ``alpha2``：小于``alpha0``的攻角（度），对应*f*等于0.7，近似为负失速攻角。该参数在``flookup=false``和确定``Cn2``的默认值时使用。
- ``alphaUpper``：Cn或Cl曲线完全附着区域的上边界攻角（度）。在``UA_Mod=5``时用于计算分离函数。
- ``alphaLower``：Cn或Cl曲线完全附着区域的下边界攻角（度）。在``UA_Mod=5``时用于计算分离函数。（在``alphaUpper``和``alphaLower``之间，分离函数值为1。）
- ``eta_e``：恢复因子，``UA_Mod = 1``时通常取值范围为[0.85到0.95]；如果输入关键字``DEFAULT``替代数值，``UA_Mod = 1``时``eta_e``设置为0.9，其他``UA_Mod``值且``FLookup = TRUE``时``eta_e``设置为1.0。
- ``C_nalpha``：线性区域二维法向力系数曲线的斜率。
- ``C_lalpha``：线性区域二维升力系数曲线的斜率。用于``UA_Mod=4、6``。
- ``T_f0``：*Df*和*f'*表达式中与*Df*相关的时间常数初始值；如果输入关键字``DEFAULT``替代数值，``T_f0``设置为3.0。
- ``T_V0``：与涡升力衰减过程相关的时间常数初始值，用于``Cvn``表达式；取决于雷诺数、马赫数和翼型；如果输入关键字``DEFAULT``替代数值，``T_V0``设置为6.0。
- ``T_p``：*Dp*表达式中的边界层前缘压力梯度时间常数，应根据翼型实验数据调整；如果输入关键字``DEFAULT``替代数值，``T_p``设置为1.7。
- ``T_VL``：与涡对流过程相关的时间常数，表示涡从前缘到尾缘所需的无量纲时间（半弦长单位），用于*Cvn*表达式；取决于雷诺数、马赫数（弱相关）和翼型；取值范围为[6到13]；如果输入关键字``DEFAULT``替代数值，``T_VL``设置为11.0。
- ``b1``：:math:`\phi_\alpha^c`和:math:`\phi_q^c`表达式中的常数；薄翼型的该值相对不敏感，但涡轮翼型可能不同；如果输入关键字``DEFAULT``替代数值，基于实验结果，``b1``设置为0.14。
- ``b2``：:math:`\phi_\alpha^c`和:math:`\phi_q^c`表达式中的常数；薄翼型的该值相对不敏感，但涡轮翼型可能不同；如果输入关键字``DEFAULT``替代数值，基于实验结果，``b2``设置为0.53。
- ``b5``：:math:`K^{'''}_q`、:math:`Cm_q^{nc}`和:math:`K_{m_q}`表达式中的常数；如果输入关键字``DEFAULT``替代数值，基于实验结果，``b5``设置为5。
- ``A1``：:math:`\phi_\alpha^c`和:math:`\phi_q^c`表达式中的常数；薄翼型的该值相对不敏感，但涡轮翼型可能不同；如果输入关键字``DEFAULT``替代数值，基于实验结果，``A1``设置为0.3。
- ``A2``：:math:`\phi_\alpha^c`和:math:`\phi_q^c`表达式中的常数；薄翼型的该值相对不敏感，但涡轮翼型可能不同；如果输入关键字``DEFAULT``替代数值，基于实验结果，``A2``设置为0.7。
- ``A5``：:math:`K^{'''}_q`、:math:`Cm_q^{nc}`和:math:`K_{m_q}`表达式中的常数；如果输入关键字``DEFAULT``替代数值，基于实验结果，``A5``设置为1。
- ``S1``：``UA_Mod = 1``时，``alpha0`` ≤ 攻角 ≤ ``alpha1``范围内*f*最佳拟合曲线的常数（其他UA模型不使用）；根据定义，取决于翼型。
- ``S2``：``UA_Mod = 1``时，攻角 > ``alpha1``范围内*f*最佳拟合曲线的常数（其他UA模型不使用）；根据定义，取决于翼型。
- ``S3``：``UA_Mod = 1``时，``alpha2`` ≤ 攻角 ≤ ``alpha0``范围内*f*最佳拟合曲线的常数（其他UA模型不使用）；根据定义，取决于翼型。
- ``S4``：``UA_Mod = 1``时，攻角 < ``alpha2``范围内*f*最佳拟合曲线的常数（其他UA模型不使用）；根据定义，取决于翼型。
- ``Cn1``：正攻角下前缘分离时:math:`C^{\prime}_n`的临界值，应从给定雷诺数和马赫数下的翼型数据中提取；``Cn1``可以从俯仰力矩突变或失速开始时弦向力损失处的静态*Cn*值计算得到；低马赫数下，``Cn1``接近翼型最大升力的条件。
- ``Cn2``：负攻角下前缘分离时:math:`C^{\prime}_n`的临界值，应从给定雷诺数和马赫数下的翼型数据中提取；``Cn2``可以从俯仰力矩突变或失速开始时弦向力损失处的静态*Cn*值计算得到；低马赫数下，``Cn2``接近翼型最大升力的条件。
- ``St_sh``：斯特劳哈尔脱落频率；如果输入关键字``DEFAULT``替代数值，``St_sh``设置为0.19。
- ``Cd0``：零升攻角下的阻力系数。
- ``Cm0``：零升攻角下四分之一弦长位置的俯仰力矩系数，抬头为正。
- ``k0``：:math:`\hat{x}_{cp}`最佳拟合曲线中的常数，等于:math:`\hat{x}_{AC}-0.25`，仅用于``UA_Mod = 1``（其他UA模型不使用）。
- ``k1``：``UA_Mod = 1``时:math:`\hat{x}_{cp}`最佳拟合曲线中的常数（其他UA模型不使用）。
- ``k2``：``UA_Mod = 1``时:math:`\hat{x}_{cp}`最佳拟合曲线中的常数（其他UA模型不使用）。
- ``k3``：``UA_Mod = 1``时:math:`\hat{x}_{cp}`最佳拟合曲线中的常数（其他UA模型不使用）。
- ``k1_hat``：``UA_Mod = 1``时前缘涡效应导致的*Cc*表达式中的常数（其他UA模型不使用）。
- ``x_cp_bar``：``UA_Mod = 1``时:math:`\hat{x}_{cp}^{\nu}`表达式中的常数（其他UA模型不使用）；如果输入关键字``DEFAULT``替代数值，``x_cp_bar``设置为0.2。
- ``UACutOut``：UA失活的攻角绝对值阈值（度）；如果输入关键字``DEFAULT``替代数值，``UACutOut``设置为45。
- ``UACutOut_delta``：UA开始关断的攻角差（度），与``UACutOut``共同确定非定常气动开始关闭的时机；如果输入关键字``DEFAULT``替代数值，``UACutOut_delta``设置为5度。当攻角小于``UACutOut - UACutout_delta``度时，使用非定常解；当攻角大于``UACutout``时，使用稳态解（即UA失活）。在这两个角度之间，稳态和非定常解会进行混合。
- ``filtCutOff``：UA输入的攻角以及UA内部从攻角导出的变桨速率和变桨加速度的低通滤波器的截止减缩频率；如果输入关键字``DEFAULT``替代数值，``filtCutOff``设置为0.5。该无量纲值对应的频率为:math:`\frac{U \times \mathrm{filtCutOff}}{\pi \times \mathrm{chord}}` Hz。

``NumAlf``是不同攻角条目的数量，决定了后续静态翼型系数表的行数；``NumAlf``必须大于等于1（``NumAlf = 1``表示系数恒定，与攻角无关）。

AeroDyn将根据提供的数据使用线性插值或三次样条进行攻角插值，具体取决于上面``InterpOrd``输入的设置。如果``AFTabMod``设置为``1``，每个文件中仅使用第一个翼型表。如果``AFTabMod``设置为``2``，AeroDyn会查找包围计算雷诺数的翼型表，并使用雷诺数的对数在表之间进行线性插值。如果``AFTabMod``设置为``3``，会基于``UserProp``字段查找包围的翼型表，并基于该字段进行线性插值。注意，OpenFAST目前将``UserProp``输入值设置为``0``，除非使用DLL控制器并设置该值，因此使用该功能可能需要修改代码。

对于每个攻角，必须设置攻角（度）``alpha``、升力系数``Coefs(:,1)``、阻力系数``Coefs(:,2)``，可选的俯仰力矩系数``Coefs(:,3)``和最小压力系数``Coefs(:,4)``，但列顺序取决于AeroDyn主输入文件翼型信息部分中``InCol_Alfa``、``InCol_Cl``、``InCol_Cd``、``InCol_Cm``和``InCol_Cpmin``的设置。攻角必须以单调递增顺序输入——从最低到最高攻角；第一行应为攻角=-180度，最后一行为攻角=+180度（除非``NumAlf = 1``，此时攻角未使用）。如果AeroDyn主输入文件转子/叶片属性部分中``UseBlCm = FALSE``忽略俯仰力矩项，文件中可以缺少包含俯仰力矩系数的列。同理，如果AeroDyn主输入文件常规选项部分中``CavitCheck = FALSE``忽略空化检查，文件中可以缺少包含最小压力系数的列。

.. _blade_data_input_file:

叶片数据输入文件
-----------------
叶片数据输入文件包含叶片的节点离散化、几何、扭转、弦长、翼型标识以及浮力/附加质量/流体惯性属性。每个叶片使用独立的文件，因此可以建模气动不平衡。叶片数据输入文件的示例见:numref:`ad_appendix`。

输入文件开头两行是头信息，仅供用户使用，软件不会读取。

``NumBlNds``是用户指定的叶片分析节点数量，决定了后续表格的行数（在两个表头行之后）。``NumBlNds``必须大于等于2；数值越高，分辨率越细，计算时间越长；建议``NumBlNds``在10到20之间，以平衡精度和计算成本。尽管每个叶片文件中都定义了``NumBlNds``，但所有叶片必须具有相同的节点数。每个节点的参数：

- ``BlSpn``：叶片节点沿（可能带预锥的）变桨轴从叶根开始的局部展向位置；``BlSpn``必须以单调递增顺序输入——从最内侧到最外侧，第一个节点必须为零；当AeroDyn与OpenFAST耦合时，最后一个节点应位于叶尖。
- ``BlCrvAC``：气动中心（翼型升力和阻力的参考点）由于叶片预弯导致的局部平面外偏移（变桨角为零时），垂直于变桨轴；``BlCrvAC``向下游为正；迎风式风力机使用负的``BlCrvAC``以提高塔筒净空。
- ``BlSwpAC``：气动中心（翼型升力和阻力的参考点）由于叶片后掠导致的局部平面内偏移（变桨角为零时），垂直于变桨轴；正的``BlSwpAC``与旋转方向相反。
- ``BlCrvAng``：由于叶片平面外预弯导致的翼型平面法向量与变桨轴的局部夹角（度）（变桨角为零时）；``BlCrvAng``向下游为正；迎风式风力机使用负的``BlCrvAng``以提高塔筒净空。
- ``BlTwist``：翼型的局部气动扭转角（度）；是当地弦长绕翼型平面法向量的方向，顺桨为正，前缘迎风；变桨角会叠加到局部扭转上。
- ``BlChord``：局部弦长。
- ``BlAFID``：局部叶片节点关联的翼型数据编号；有效值为1到``NumAFfiles``之间的数（对应AeroDyn主输入文件翼型文件表中的行号）；多个叶片节点可以使用相同的翼型数据。
- ``t_c``：叶片厚度弦长比，用于计算附加质量和流体惯性载荷的参考横截面积，不能小于0。
- ``BlCb``：叶片浮力系数，定义为叶片局部横截面积除以直径等于``BlChord``的圆的面积；如果要忽略叶片上的浮力载荷，将``BlCb``设置为0；由于叶片和轮毂是连接部件，如果包含轮毂浮力，也应该包含叶片浮力，反之亦然。
- ``BlCenBn``：叶片浮力中心相对于气动中心在弦向法向的偏移（正方向指向翼型吸力侧）。
- ``BlCenBt``：叶片浮力中心相对于气动中心在弦向切向的偏移（正方向指向翼型后缘）。
- ``BlCpn``：叶片弦向法向动压力系数；如果要忽略叶片上的弦向法向流体惯性载荷，将``BlCpn``设置为0。
- ``BlCpt``：叶片弦向切向动压力系数；如果要忽略叶片上的弦向切向流体惯性载荷，将``BlCpt``设置为0。
- ``BlCan``：叶片弦向法向附加质量系数，不能小于0；如果要忽略叶片上的弦向法向附加质量载荷，将``BlCan``设置为0。
- ``BlCat``：叶片弦向切向附加质量系数，不能小于0；如果要忽略叶片上的弦向切向附加质量载荷，将``BlCat``设置为0。
- ``BlCam``：叶片变桨附加质量系数，不能小于0；如果要忽略叶片上的变桨附加质量载荷，将``BlCam``设置为0。

参见:numref:`ad_blade_geom`。扭转在:numref:`ad_appendix`的:numref:`ad_blade_local_cs`中展示。

.. _TF_tf_input-file:

尾翼输入文件
-------------
尾翼输入文件的示例如下：

.. code::

    ------- TAIL FIN AERODYNAMICS INPUT FILE--------------------------------------------
    注释
    ======  通用输入 =============================================================
    1         TFinMod     - 尾翼空气动力学模型 {0：无，1：基于极曲线，2：基于USB}（开关）
    0.3       TFinArea    - 尾翼平面面积 (m^2)
    10.,0.,0. TFinRefP_n  - 尾翼参考点相对于塔顶的未变形位置（m）
    0.,0.,0.  TFinAngles  - 尾翼弦线相对于参考点的偏斜、倾斜和滚转角（度）
    0         TFinIndMod  - 诱导速度计算模型 {0：无，1：转子平均}（开关）
    ====== 基于极曲线的模型 ================================ [仅在TFinMod=1时使用]
    1         TFinAFID - 尾翼翼型编号索引 [1到NumAFfiles]
    0.5       TFinChord   - 尾翼弦长（m）
    ====== 非定常细长体模型  ===================== [仅在TFinMod=2时使用]
    0.9           TFinKp        - 尾翼势流系数（-）
    0.3,0.1,0.1   TFinSigma     - 尾涡分离函数的经验常数（1/度）
    40,60,60      TFinAStar     - 尾涡分离函数的初始角度（度）
    3.1416        TFinKv        - 尾翼涡升力系数（-）
    1.3           TFinCDc       - 尾翼阻力系数（-）

通用输入
~~~~~~~~
``TFinMod``：选择尾翼空气动力学模型的开关：0）无（气动力为零），1）基于极曲线，2）基于USB（参见:numref:`TF-aerotheory`）。（开关）

``TFinArea``：尾翼的面积（m²）。这是尾翼板的平面面积，用于将局部动压和翼型系数关联到气动载荷。该值不能为负，且仅在TFinMod设置为1时使用。（m²）

``TFinRefP_n``：尾翼参考点在机舱坐标系中相对于塔顶的未变形位置(:math:`x_{\text{ref},x_n},x_{\text{ref},y_n}, x_{\text{ref},z_n}`)（之前使用``TFinCPxn``、``TFinCPyn``、``TFinCPzn``定义）。这些距离定义了卷角为零时的配置。对于典型的迎风式风力机，:math:`x_n`向下游为正，:math:`y_n`向下游看时向左为正，:math:`z_n`向下游看时向上为正。参见:numref:`figTFGeom`和:numref:`figTFcoord1`。（m）

``TFinAngles``：尾翼的角度(:math:`\theta_\text{skew},\theta_\text{tilt}, \theta_\text{bank}`)（之前定义为``TFinSkew``、``TFinTilt``、``TFinBank``）。参见:numref:`figTFGeom`和:numref:`figTFcoord1`。这些角度定义了卷角为零时的弦线，假设弦线经过参考点。
:math:`\theta_\text{skew}`是尾翼弦线在标称水平面内的偏斜角。正偏斜将尾翼弦线的标称水平投影绕:math:`z_n`轴旋转。上述弦线是经过尾翼参考点的弦线。该值必须大于-180且小于等于180度。
:math:`\theta_\text{tilt}`是尾翼弦线相对于标称水平面的倾斜角。该值必须在-90到90度之间（含）。正倾斜意味着尾翼的后缘高于前缘。
:math:`\theta_\text{bank}`是尾翼平面绕尾翼弦线的滚转角。该值必须大于-180且小于等于180度。（度）

``TFinIndMod``：选择计算转子及其尾流在尾翼上的诱导速度的模型（不是尾翼自身的诱导速度）。可用选项：
0）无（诱导速度为零）
1）转子平均（使用所有叶片和叶片节点的平均诱导速度）
（参见:numref:`TF-aerotheory`）。（开关）

基于极曲线的模型输入
~~~~~~~~~~~~~~~~~~~~
``TFinAFID``：该整数告诉AeroDyn哪个输入翼型文件（``AFNames``）分配给尾翼。例如，值为2表示尾翼将使用``AFNames(2)``作为本地尾翼翼型。该值必须在1到``NumAFfiles``之间，且仅在TFinMod设置为1时使用。（-）

非定常细长体（USB）模型输入
~~~~~~~~~~~~~~~~~~~~~~~~~~~
有关如何为基于非定常细长体理论的模型选择参数的指导，请参考:numref:`TF-aerotheory`和:cite:`ad-hammam_NREL:2023`。

``TFinKp``：非定常气动的势流升力系数。``TFinKp``用于计算尾翼上非定常气动力的势流贡献。

``TFinSigma``：非定常气动模型中使用的分离函数衰减的尾翼经验常数。分离函数及其对``TFinSigma``的依赖在:numref:`TF-aerotheory`中描述。

``TFinAStar``：非定常气动模型中使用的分离函数的尾翼特征角度。分离函数及其对``TFinAStar``的依赖在:numref:`TF-aerotheory`中描述。

``TFinKv``：非定常气动的涡升力系数。``TFinKv``用于计算尾翼上非定常气动力的涡流贡献。

``TFinCDc``：非定常气动模型使用的尾翼阻力系数。尾翼上的阻力在大偏航角下对法向力有显著贡献。
