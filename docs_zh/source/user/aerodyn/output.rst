.. _ad_output:

输出文件
============

AeroDyn生成三种类型的输出文件：回显文件、摘要文件和时间序列结果文件。以下各节详细介绍这些文件的用途和内容。

回显文件
----------
如果你在AeroDyn驱动文件或AeroDyn主输入文件中将``Echo``标志设置为``TRUE``，这些文件的内容将被回显到指定命名规则的文件中：驱动输入文件的回显文件为*OutFileRoot.ech*，AeroDyn主输入文件的回显文件为*OutFileRoot.AD.ech*。当独立运行AeroDyn时，``OutFileRoot``由驱动输入文件的I/O设置部分指定；当运行耦合仿真时，由FAST程序指定。回显文件有助于调试输入文件。如果AeroDyn在解析输入文件时遇到错误，回显文件的内容将被截断。错误通常对应于最后成功回显行的下一行。

.. _sec:ad_SumFile:

摘要文件
------------
如果``SumPrint``参数设置为``TRUE``，AeroDyn会生成命名规则为*OutFileRoot.AD.sum*的摘要文件。当独立运行AeroDyn时，``OutFileRoot``由驱动输入文件的I/O设置部分指定；当运行耦合仿真时，由FAST程序指定。该文件总结了气动模型的关键信息，包括启用了哪些功能以及选择了哪些输出。

结果文件
-------------
在独立模式下，AeroDyn的时间序列结果（每个案例对应一个单独文件）会写入文本格式的文件，命名规则为*OutFileRoot.#.out*，其中``OutFileRoot``由驱动输入文件的I/O设置部分指定，'*#*'字符是对应于组合案例分析部分中测试案例行的整数。如果AeroDyn耦合到FAST，FAST将生成包含AeroDyn结果的主结果文件，AeroDyn不会自行写出结果。结果采用表格格式，每列是一个数据通道（第一列始终是仿真时间），每行对应一个仿真输出时间步。数据通道在AeroDyn主输入文件的OUTPUTS部分指定。AeroDyn生成文件的列格式由驱动输入文件的``OutFmt``参数指定。
