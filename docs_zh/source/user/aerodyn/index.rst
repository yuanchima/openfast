AeroDyn 用户指南与理论手册
======================================

本文档是 AeroDyn 软件程序的快速参考指南，供普通用户与其他 OpenFAST 手册结合使用。本手册会随着新版本发布以及软件升级或修改的需要进行更新。参考资料方面，可从以下列表下载演示文稿、开发计划、发表论文等额外材料：

- :download:`AeroDyn 中新的叶素动量偏斜尾流模型的开发与验证 <https://www.nrel.gov/docs/fy15osti/63217.pdf>`
- :download:`FAST 8 的非定常空气动力学模块 <https://www.nrel.gov/docs/fy20osti/66347.pdf>`
- :download:`使用 FAST v8 研究水平轴潮汐涡轮机的附加质量效应 <https://doi.org/10.1016/j.renene.2018.04.023>`
- :download:`使用 AeroDyn V15.04 预测海洋和水动力涡轮机叶片的空化现象 <https://www.nrel.gov/docs/fy17osti/68398.pdf>`
- :download:`OpenFAST 空气动力学线性化开发计划 <../../../OtherSupporting/AeroDyn/AeroLin_2019-12.pdf>`
- :download:`AeroDyn 网格及相关计算 <../../../OtherSupporting/AeroDyn/AeroDynMesh_Rev4.docx>`
- :download:`AeroDyn 中海洋水动力涡轮机的浮力计算 <../../../OtherSupporting/AeroDyn/Buoyancy_Implementation_Plan_Rev11.docx>`
- :download:`AeroDyn 中 MHK 涡轮机的流体惯性和附加质量载荷计算 <../../../OtherSupporting/AeroDyn/Fluid_Inertia_Added_Mass_Implementation_Plan.docx>`
- :download:`使用计算流体动力学确定浮动水动力涡轮机叶片的附加质量系数 <../../../OtherSupporting/AeroDyn/UMERC24-Poster.pdf>`
