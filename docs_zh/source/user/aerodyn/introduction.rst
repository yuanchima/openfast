介绍
============

AeroDyn 是一个时域风力机空气动力学模块，耦合在 OpenFAST 多物理场工程工具中，用于水平轴风力机的气动弹性仿真。AeroDyn 也可以作为独立代码运行，不与 OpenFAST 耦合，单独计算风力机的空气动力学响应。当与 OpenFAST 耦合时，AeroDyn 也可以作为全耦合解线性化的一部分进行线性化（独立模式下不支持线性化）。AeroDyn 最初是为风力机空气动力学建模开发的，但该模块同样适用于海洋水动力（MHK）涡轮机的流体动力学（本文档中的“风力机”、“塔筒”、“空气动力学”等术语对于 MHK 涡轮机而言分别对应“MHK 涡轮机”、“MHK 支撑结构”、“流体动力学”等）。AeroDyn 还计算对 MHK 涡轮机重要但不适用于风力机的额外物理量，包括空化检查、叶片、塔筒、轮毂和机舱的浮力和力矩，以及叶片和塔筒的附加质量和惯性力和力矩。本文档对应于 OpenFAST GitHub 仓库中的 AeroDyn 版本。随 OpenFAST 1.0.0 发布的 AeroDyn 版本与旧版本号中的 AeroDyn 15 版本最为接近。AeroDyn 15 版本是对早期 AeroDyn 版本的彻底重构，AeroDyn 15 及更高版本遵循 FAST 模块化框架的要求。

AeroDyn 计算叶片和塔筒上的空气动力学载荷。AeroDyn 中的空气动力学计算基于致动线原理，即物体周围的三维（3D）流动通过截面处的局部二维（2D）流动来近似，分布的压力和剪切应力通过集中在 2D 截面节点处的升力、阻力和俯仰力矩来近似。分析节点沿每个叶片和塔筒的长度分布，每个节点处的 2D 力和力矩被计算为单位长度的分布载荷，总 3D 空气动力学载荷通过沿长度积分 2D 分布载荷得到。当 AeroDyn 与 OpenFAST 耦合时，叶片和塔筒分析节点的离散化可以独立于结构模块中的节点离散化。致动线近似限制了模型仅适用于细长结构，3D 效应要么被忽略，要么通过模型固有的修正来捕捉（例如叶尖损失、轮毂损失或偏斜尾流修正），要么包含在输入数据中（例如应用于翼型数据的旋转增广修正）。

AeroDyn 假设风机几何结构由单塔筒顶部的 1 叶、2 叶或 3 叶转子组成。假设未变形的塔筒是笔直且垂直的，未变形的叶片可以考虑面外曲率和面内后掠。对于叶片，进行空气动力学分析的 2D 截面可以随面外曲率变化，但假设面内后掠通过剪切实现，而非旋转 2D 截面。通过在叶片之间设置几何差异，可以实现气动不平衡。

当 AeroDyn 与 OpenFAST 耦合时，AeroDyn 接收塔筒、轮毂和叶片中分析节点的瞬时（可能位移/变形）结构位置、方向和速度。与曲率和后掠类似，进行叶片空气动力学分析的 2D 截面会随面外变形变化，但假设面内变形通过剪切实现，而非旋转 2D 截面。AeroDyn 还接收塔筒和叶片节点处的局部来流（未受扰动）流体速度。（流体和结构计算在 AeroDyn 模块之外进行，由驱动代码作为输入传递给 AeroDyn。）每个耦合时间步都会提供流体和结构运动，然后 AeroDyn 计算叶片和塔筒节点上的空气动力学载荷，并将其返回给 OpenFAST，作为气动弹性计算的一部分。在独立模式下，AeroDyn 的输入由简单的驱动程序指定，没有气动弹性耦合。

AeroDyn 包含七个子模型：(1) 转子尾流/诱导，(2) 叶片翼型空气动力学，(3) 塔筒对叶片节点局部流体的影响，(4) 塔筒和机舱阻力，(5) 气动声学，(6) 叶片、轮毂、机舱和塔筒的浮力（针对 MHK 涡轮机），以及 (7) 叶片和塔筒的附加质量和流体惯性（针对 MHK 涡轮机）。机舱、轮毂和尾翼的流体影响和载荷（机舱阻力以及机舱和轮毂浮力载荷除外），以及风电场中多台风机之间的尾流和阵列效应，目前在 AeroDyn 中尚未提供。MHK 涡轮机不支持气动声学。

对于运行中的风力和 MHK 涡轮机转子，AeroDyn 通过基于准稳态叶素/动量（BEM）理论的诱导因子计算尾流的影响，这需要迭代非线性求解（通过 Brent 方法实现）。准稳态意味着诱导会对载荷变化做出瞬时反应。诱导计算以及由此得到的入流速度和角度，基于每个叶片每个分析节点的局部流动，取决于流体与结构之间的相对速度（根据启用的功能，包括局部入流偏斜、剪切、湍流、塔筒流动扰动和结构运动的影响）。Glauert 经验修正（带有 Buhl 修改）在高轴向诱导因子下替代了线性动量平衡。在 BEM 求解中，Prandtl 叶尖损失、Prandtl 轮毂损失以及 Pitt 和 Peters 偏斜尾流都是可选应用的 3D 修正。启用偏斜尾流修正时，它会在 BEM 迭代之后应用。此外，切向诱导的计算（来自角动量平衡）、轴向诱导计算中阻力的使用，以及切向诱导计算中阻力的使用，都是 BEM 迭代中可选包含的项（即使 BEM 迭代中不使用阻力，在得到诱导结果后，阻力仍会用于计算节点载荷）。尾流/诱导计算可以完全绕过，用于建模停放或空转的转子，此时入流速度和角度完全由几何确定。在 AeroDyn 与 OpenFAST 耦合且启用 BEM 的线性化分析期间，尾流可以假设为冻结的（即轴向和切向诱导速度 :math:`-V_x a` 和 :math:`V_y a'` 在线性化期间固定在其工作点值），或者可以在非线性化期间使用 BEM 理论重新计算诱导。AeroDyn v15 及更高版本目前还不支持考虑瞬态条件下诱导动态的动态尾流。

叶片翼型空气动力学可以是定常或非定常的，但如果 MHK 需要空化检查，则仅支持定常空气动力学。在定常模型中，提供的静态翼型数据——包括升力、阻力，以及可选的俯仰力矩和最小压力系数随攻角（AoA）的变化——直接用于计算节点载荷。`AirfoilPrep <https://nwtc.nrel.gov/AirFoilPrep>`__ 预处理器可用于基于未修正的 2D 数据（例如基于风洞中的翼型试验或 `XFoil <http://web.mit.edu/drela/Public/web/xfoil/>`__）生成所需的静态翼型数据，包括在不同翼型之间融合数据、应用 3D 旋转增广以及外推到高攻角的功能。非定常翼型空气动力学（UA）模型考虑流动滞后，包括非定常附着流、后缘流动分离、动态失速和流动再附。UA 模型可以看作是对随时间变化的入流速度和角度导致的静态翼型响应的 2D 动态修正。有三种半经验 UA 模型可用：Beddoes-Leishman（B-L）的原始理论发展、González 开发的 B-L 扩展，以及 Minnema/Pierce 开发的 B-L 模型扩展。**虽然本手册记录了所有 UA 模型，但原始 B-L 模型目前还无法正常工作。测试表明，如果 UA 模型参数针对给定翼型、雷诺数和/或马赫数进行适当设置，González 和 Minnema/Pierce 模型能够产生合理的法向力、切向力和俯仰力矩系数滞后。然而，即使使用默认 UA 模型参数，结果也会与早期版本的 AeroDyn（基于 Minnema/Pierce 对 B-L 的扩展）略有不同，因为版本之间的 UA 模型逻辑存在差异。我们建议用户使用均匀风入流和固定偏航误差运行测试用例（例如通过独立的 AeroDyn 驱动程序），以检查法向力、切向力和俯仰力矩系数滞后的准确性，并适当调整 UA 模型参数。**UA 模型的翼型、雷诺数和马赫数相关参数可以从静态翼型数据中导出。这些 UA 模型在正常转子运行下适用于中小攻角；在停放或空转条件下，定常模型更合适。静态翼型数据始终用于 BEM 迭代；启用 UA 时，它会在 BEM 迭代和偏斜尾流修正之后应用。UA 模型不支持线性化，因此在 AeroDyn 与 OpenFAST 耦合的线性化分析期间必须禁用 UA。AeroDyn v15 及更高版本目前还不支持基于雷诺数或气动控制设置（例如襟翼）的翼型数据插值。

塔筒对叶片局部流体流动的影响基于势流和/或塔筒阴影模型。势流模型使用圆柱绕流的解析势流解来模拟塔筒对迎风转子的阻挡效应。在该模型中，每个叶片节点处的来流（未受扰动）流动会根据叶片节点相对于塔筒的位置和塔筒直径发生扰动，包括塔筒上下游的较低速度、塔筒左右两侧的较高速度以及横流。势流模型中可选包含 Bak 修正，它会增强塔筒上游扰动，并基于塔筒阻力系数改善背风转子的塔筒尾流。也可以启用塔筒阴影模型来考虑背风转子的塔筒尾流亏损。该模型基于 Powles 的工作，根据叶片节点相对于塔筒的位置、塔筒直径和阻力系数，在每个叶片节点的来流流体中引入轴向流动亏损。两种塔筒影响模型都是准稳态模型，即扰动直接应用于叶片节点处的来流流体，没有动态效应，并且在 BEM 迭代中应用。

塔筒上的空气动力学载荷直接基于塔筒直径和阻力系数，以及每个塔筒分析节点处来流（未受扰动）流动与结构之间的局部相对流体速度（根据启用的功能，包括局部剪切、湍流和结构运动的影响）。塔筒阻力载荷计算是准稳态的，独立于塔筒对流动模型的影响。

类似地，机舱上的空气动力学阻力载荷使用机舱几何形状、阻力系数以及来流（未受扰动）流动与机舱之间的局部相对流体速度计算。机舱阻力载荷计算是准稳态的，独立于转子对流动模型的影响。

AeroDyn 主输入文件定义建模选项、环境条件（来流除外）、翼型、塔筒节点离散化和属性、塔筒、轮毂和机舱属性，以及输出文件规范。翼型数据属性从专用输入文件中读取（每个翼型一个文件），包括升力系数、阻力系数，以及可选的俯仰力矩和最小压力系数随攻角的变化，以及 UA 模型参数。（如果需要空化检查，翼型输入文件中还包含最小压力系数随攻角的变化。）叶片节点离散化、几何形状、扭转、弦长、翼型标识符和浮力属性同样从单独的输入文件中读取（每个叶片一个文件）。
