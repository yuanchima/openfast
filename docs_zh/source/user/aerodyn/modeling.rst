建模注意事项
=======================

AeroDyn被设计为一个极其灵活的工具，用于对各种气动条件和风机配置进行建模。本节提供一些通用指导，帮助你构建与AeroDyn兼容的模型。

请参考第7节的理论，了解我们在AeroDyn中采用的实现方法的详细信息。

环境条件
------------------------
对于空气，``AirDens``、``KinVisc``、``SpdSound``和``Patm``的典型值分别约为1.225 kg/m³、1.460E-5 m²/s、340.3 m/s和101325 Pa。对于海水，``FldDens``、``KinVisc``、``SpdSound``和``Pvap``的典型值分别约为1025 kg/m³、1.004E-6 m²/s、1500 m/s和2000 Pa。

时间和空间离散化
-----------------------------------
为了保证精度和数值稳定性，我们建议设置``DTAero``使得转子每转至少有200个方位角步。但当AeroDyn与FAST耦合时，FAST可能需要比这个经验法则小得多的时间步长。如果启用UA同时使用非常小的时间步长，你可能需要使用双精度重新编译AeroDyn，以避免UA例程中的数值问题。

对于叶片和塔筒的空间离散化，使用更多的分析节点可以得到更精确的解，但会增加计算时间。当AeroDyn与FAST耦合时，叶片和塔筒分析节点的离散化可以独立于结构模块中的节点离散化。

我们建议``NumBlNds``设置在10到20之间，以平衡转子气动载荷计算的精度和计算成本。在气动载荷预期会有较大梯度的位置（例如叶尖附近）使用更精细的节点分辨率可能会有好处。通过在叶片之间设置几何差异，可以建模气动不平衡。

当启用塔筒势流（``TwrPotent > 0``）、塔筒阴影（``TwrShadow > 0``）和/或塔筒气动载荷（``TwrAero = TRUE``）模型时，我们同样建议``NumTwrNds``设置在10到20之间，以平衡精度和计算成本。通常，塔筒节点的地面以上局部高程（海上风电和漂浮式MHK涡轮机相对于平均海平面，固定式MHK涡轮机相对于海床）（``TwrElev``）必须按从最低（塔筒底部）到最高（塔筒顶部）高程的单调递增顺序输入（对于漂浮式MHK涡轮机也可以是单调递减顺序）。然而，当AeroDyn与FAST耦合时，AeroDyn中的塔筒底部节点不能低于InflowWind模块中指定的最低风高。为了避免AeroDyn中塔筒下部被截断，我们建议在InflowWind中尽可能低地指定风高（对于海上风机到平均海平面，对于固定和漂浮式MHK涡轮机到海床）（这对于全场风文件格式是一个特别需要注意的问题）。

运行和停机/空转条件下的模型选项
------------------------------------------------------------
对于运行状态的转子建模，我们建议包含动态BEM模型（``Wake_Mod = 1``）和UA（``AFAeroMod = 2``）。通常，Pitt和Peters偏斜尾流（``SkewMod = 2``）、Prandtl叶尖损失（``TipLoss = TRUE``）、Prandtl轮毂损失（``HubLoss = TRUE``）和切向诱导（``TanInd = TRUE``）模型都应该启用，但``SkewMod = 2``对于非常大的偏航误差（远大于45度）是无效的。BEM解中的非线性求解是基于入流角的，但``IndToler``表示无量纲残差方程的容差，没有物理关联；我们建议将``IndToler``设置为``DEFAULT``。

*虽然本手册记录了所有UA模型，但原始B-L模型目前尚未可用。测试表明，如果针对给定翼型、雷诺数和/或马赫数适当设置UA模型参数，González和Minnema/Pierce模型能够产生合理的法向力、切向力和俯仰力矩系数滞后。然而，即使使用默认UA模型参数，结果也会与早期版本的AeroDyn（基于Minnema/Pierce对B-L的扩展）略有不同，因为版本之间的UA模型逻辑存在差异。我们建议用户使用均匀入流和固定偏航误差运行测试用例（例如通过独立的AeroDyn驱动程序），以检查法向力、切向力和俯仰力矩系数滞后的准确性，并适当调整UA模型参数。*

对于停机或空转转子的建模，我们建议禁用诱导（``Wake_Mod = 0``）和UA（``AFAeroMod = 1``），在这种情况下，入流速度和角度完全由几何确定，翼型数据采用静态值。

在切出风速以上的停机或空转条件下，塔筒上的直接气动载荷通常主导转子上的气动载荷，在这种情况下我们建议设置``TwrAero = TRUE``。否则，``TwrAero = FALSE``可能就足够了。

对于运行和停机/空转转子，我们建议都包含塔筒对叶片局部流体的影响。我们建议对于迎风式转子设置``TwrPotent > 0``，对于背风式转子设置``TwrPotent = 2``或``TwrShadow > 0``。

线性化
-------------
当与FAST耦合时，AeroDyn可以作为全耦合解线性化的一部分进行线性化。部分AeroDyn模块选项可用。

动态尾流可以使用以下设置线性化：
`DBEMT_Mod=-1`（冻结尾流）
`DBEMT_Mod=3`（动态连续状态空间模型）

非定常空气动力学可以使用以下设置线性化：
`UAMod={0,4,5,7}`（无UA，或连续状态空间模型）
