.. _OLAF:

OLAF用户指南与理论手册（AeroDyn中的自由涡尾迹模块）
===================================================================

.. only:: html

   本文档为OpenFAST的AeroDyn模块中包含的名为OLAF的自由涡尾迹模块提供快速参考指南。它旨在供普通用户与AeroDyn的其他功能以及OpenFAST的其他模块结合使用。随着新版本的发布，以及根据需要提供有关软件改进或修改的更多信息，本手册将不断更新。

   本文档来源于K. Shaler、E. Branlard和A. Platt编写的OLAF用户手册。（`https://www.nrel.gov/docs/fy20osti/75959.pdf <https://www.nrel.gov/docs/fy20osti/75959.pdf>`_）
