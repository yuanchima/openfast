.. _Introduction:

介绍
============
在过去几十年中，风力发电成本的大幅降低主要得益于转子尺寸的大幅增加。对于这种大型风机，一个重要的考虑因素是叶片柔性的增加。特别是，大的叶片挠度可能导致扫掠面积明显偏离转子平面。这种偏离违反了常见气动模型（如叶素动量（BEM）方法）所使用的假设。这些方法依赖于执行器盘假设，该假设仅对包含在平面内的轴对称转子载荷有效。大的叶片挠度还可能导致风机的近尾迹偏离均匀螺旋形状。此外，风机叶片与局部近尾迹之间的相互作用可能会增加，从而违反了不考虑近尾迹位置和动力学的模型假设。另外，高度柔性的叶片可能会增加气动效应的非定常性和三维性，从而提高了对准确、鲁棒的动态失速模型的需求。还有许多其他复杂的风电场景违反了简单的工程假设。这些场景包括获得非直叶片几何形状（例如内置曲率或后掠）的准确气动载荷；由偏航入流或风机倾斜引起的偏斜流动；以及将风机安装在柔性海上浮式平台上导致的大转子运动。

需要更高保真度的气动模型来应对柔性和浮式转子日益增加的复杂性。虽然计算流体动力学（CFD）方法能够捕捉这些特征，但其计算成本限制了可实际执行的仿真数量，这在风机设计的载荷分析中是一个重要考虑因素。自由涡尾迹（FVW）方法的计算成本低于CFD方法，同时能够建模类似的复杂物理过程。与BEM方法不同，FVW方法不需要依赖特设工程模型来考虑动态入流、偏斜尾迹、叶尖损失或地面效应。这些效应是模型固有的组成部分。现已开发了许多基于涡量的工具，从Rosenhead的早期处理（:cite:`olaf-Rosenhead31_1`），Winckelmans和Leonard提出的涡粒子方法（:cite:`olaf-Winckelmans93_1`），到Papadakis最近提出的欧拉-拉格朗日混合可压缩公式（:cite:`olaf-Papadakis14_1`）。在风能领域应用的长期存在的代码示例包括使用涡粒子方法的GENUVP（:cite:`olaf-Voutsinas06_1`）和使用涡丝方法的AWSM（:cite:`olaf-Garrel03_1`）。这两个工具都已成功与结构求解器耦合。Branlard等人扩展了该方法（:cite:`olaf-Branlard15_1`），一致地使用涡方法对剪切和湍流入流下的风机进行气动弹性仿真。大多数公式依赖于叶片的升力线表示，但最近，粘性-无粘表示已与结构求解器结合使用（:cite:`olaf-Miras17_1`）。

对流拉格朗日涡丝（OLAF）是一个自由涡尾迹（FVW）模块，用于计算运动中的两叶片或三叶片水平轴风力机的气动力。该模块已被纳入美国国家可再生能源实验室基于物理的工程工具OpenFAST中，该工具用于求解单个风机的气动-水动-伺服-弹性动力学。OLAF已集成到OpenFAST的*AeroDyn*模块中，作为传统叶素动量（BEM）选项的替代方案，如图:numref:`figOpenFAST_a`和:numref:`figOpenFAST_b`所示。

将OLAF模块集成到OpenFAST中，可以对高度柔性的风机进行建模，并利用OpenFAST的气动-水动-伺服-弹性响应能力。OLAF模块遵循OpenFAST模块化框架的要求（:cite:`olaf-Sprague15_1,olaf-Jonkman13_1`）。

OLAF模块使用叶片的升力线表示，其特征是附着环量的分布。附着环量的空间和时间变化导致自由涡量在尾迹中释放。OLAF以时间精确的方式求解风机尾迹，允许涡对流、拉伸和扩散。OLAF模型基于拉格朗日方法，其中风机尾迹被离散为拉格朗日标记点。有许多方法用拉格朗日标记点表示尾迹（:cite:`olaf-Branlard17_1`）。在本工作中，使用了混合格架/涡丝方法，如图:numref:`Lagrangian`所示。

这里，拉格朗日标记点的位置由尾迹年龄:math:`\zeta`和方位角位置:math:`\psi`定义。在叶片的近尾迹中使用格架方法。近尾迹跨越用户指定的角度或非旋转情况的距离。尽管过去的研究表明30°的近尾迹区域就足够了（:cite:`olaf-Leishman_book,olaf-Ananthan02_1`），但研究表明，对于高推力和其他具有挑战性的工况，需要更大的近尾迹。在近尾迹区域之后，假设尾迹瞬间卷起为叶尖涡和根涡，这被认为是尾迹其余部分最主要的特征（:cite:`olaf-Leishman02_1`）。每个拉格朗日标记点通过直涡丝连接到相邻标记点，近似到二阶精度（:cite:`olaf-Gupta05_1`）。尾迹基于叶片截面的展向位置和指定的时间步长(:math:`dt`)进行离散，该时间步长可能与AeroDyn的时间步长不同。在可选的初始化期之后，尾迹被允许移动和变形，从而随着标记点向下游对流而改变尾迹结构。为了限制计算成本，根涡和叶尖涡在离风机下游指定距离（取为面板数**nNWPanels**）之后被截断。尾迹截断违反了亥姆霍兹第一定律，因此引入了错误的边界条件。为了缓解这一问题，尾迹在指定的缓冲距离**nFWPanelsFree**和**nFWPanels**之间的缓冲区中被"冻结"。在该缓冲区中，标记点以平均环境速度对流。通过这种方式，截断误差被最小化（:cite:`olaf-Leishman02_1`）。缓冲区通常选择为转子旋转一周的对流距离。

作为OpenFAST的一部分，升力线/叶片处的诱导速度被传递到*AeroDyn*，用于计算每个叶片截面的有效叶片攻角，然后用于计算叶片上的气动力。OLAF方法返回与BEM方法相同的信息，但在BEM假设不成立的区域（如上述讨论的情况）可以进行更准确的计算。由于OLAF方法的计算成本高于BEM，因此两种方法在OpenFAST中都可用，用户可以在*AeroDyn*输入文件中指定使用哪种方法。

OLAF输入文件定义了尾迹对流和环量求解方法、尾迹尺寸和长度选项、拉格朗日标记点正则化（粘性核心）方法以及其他仿真和输出参数。近尾迹和远尾迹的范围由以转子直径为单位的无量纲长度指定。涡元素有不同的正则化函数可供选择。此外，可以选择不同的方法来计算附着涡量和尾迹涡量的正则化参数。特别是，可以通过动态改变正则化参数来考虑粘性扩散。还提供尾迹可视化输出选项。
