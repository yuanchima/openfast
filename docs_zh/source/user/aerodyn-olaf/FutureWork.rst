未来工作
=========

第一个实现阶段专注于单风机功能，满足了大型新型转子概念设计的基本要求。未来的开发工作将转向实现支持在中大型计算集群上进行多风机仿真的功能。减少计算时间也将是重点。这可以通过树技术（如快速多极方法）来实现。还将考虑进一步的算法选项，例如远尾流中的涡旋合并，以加快仿真速度。本手册中介绍的框架与无网格或基于网格的涡旋粒子公式兼容。此类基于粒子的实现也将在未来进行规划。还将继续针对测量数据和高阶工具对代码进行进一步验证。还将研究应用于已知对 BEM 算法具有挑战性的情况，例如高度柔性转子、海上浮式风机、小型风电场、多转子风机或风筝。

以下是 OLAF 软件的未来工作列表：

-  拉格朗日粒子

-  多风机，集成到 FAST.Farm

-  代码加速

-  专用动态失速模型
