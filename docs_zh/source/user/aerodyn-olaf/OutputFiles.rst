输出文件
============

OLAF模块本身不生成自己的输出文件。但是，*AeroDyn*中提供了额外的输出通道。因此，这里简要描述*AeroDyn15*输出文件以及OLAF提供的输出。可视化文件通过使用参数**WrVTK**生成。如果在OLAF输入文件中设置该参数，VTK文件将写入文件夹``vtk_fvw``；如果在主``.fst``文件中设置，VTK文件将写入文件夹``vtk``。

速度场输出可以导出为VTK文件。用户可以使用**nGridOut**和后续的表格控制这些输出。


结果文件
------------

OpenFAST生成一个主结果文件，其中包含*AeroDyn*的结果。结果为表格格式，每列是一个数据通道，每行对应一个仿真输出时间步。数据通道在*AeroDyn*主输入文件的*OUTPUTS*部分指定。AeroDyn生成文件的列格式使用OpenFAST驱动输入文件的**OutFmt**参数指定。
