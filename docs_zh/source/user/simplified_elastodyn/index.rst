.. _SED:

简化版 ElastoDyn
======================================


本文档介绍简化版 ElastoDyn（SED）模块。
该模块具有以下特性：

- 转子为刚性
- 使用一个自由度，表示可变的转子转速
- 不计算结构载荷
- 可使用大步长运行
- 恒定的平台倾斜角
- 兼容 AeroDyn 和 AeroDisk
- 兼容转矩和偏航（以及变桨）的主动控制
