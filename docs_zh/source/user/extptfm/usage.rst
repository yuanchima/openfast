使用方法
--------

*ExtPtfm* 模块使用用户提供的支撑结构超单元属性（例如质量、刚度、阻尼和激振力时间序列）来计算支撑结构在界面处的反作用力。
该模块使用线性公式，并内部跟踪 Guyan 和 Craig-Bampton 自由度。

*ExtPtfm* 的典型顺序耦合工作流程
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

整体工作流程包括以下步骤：

- 子结构设计人员使用外部工具（例如能够生成超单元模型的有限元工具），在给定海况下对孤立子结构进行时域仿真。外部工具背后的基础模型和载荷时间序列使用 :ref:`ep-theory` 中描述的 CB 技术进行降阶，其中主导自由度选择为子结构界面节点处的自由度。降阶结果写入包含降阶系统矩阵 :math:`\boldsymbol{M}_r`、:math:`\boldsymbol{C}_r`、:math:`\boldsymbol{K}_r` 以及降阶载荷时间序列 :math:`\boldsymbol{f}_r` 的文件。

- 该文件由 *ExtPtfm* 模块导入到 *OpenFAST* 中，使用子结构的降阶表示运行整个风力机的时域仿真。在每个时间步，*ExtPtfm* 接收界面点的位移、速度和加速度作为输入，并返回该点的载荷。

- *OpenFAST* 导出界面处的载荷和位移时间序列，然后返回给子结构设计人员。这些输入用作外部工具的边界条件，然后运行子结构的另一个时域仿真。计算应力集中，并进行规范检查。

使用模块
~~~~~~~~

通过在 OpenFAST 主输入文件中将标志 ``CompSub`` 设置为 :math:`2` 来激活 ``ExtPtfm`` 模块。同一文件中的变量 ``SubFile`` 需要设置为该模块的有效输入文件（输入文件规范参见 :ref:`ep_input-files`）。

.. code::

   ---  [...]
     2  CompSub - Compute sub-structural dynamics (switch) {0=None; 1=SubDyn; 2=ExtPtfm}
   ---  [...]
   "Turbine_ExtPtfm.dat" SubFile - Sub-structure input file (SubDyn or ExtPtfm)

建议
~~~~

**时间步长** 超单元可能包含高频成分。根据经验，建议使用满足以下准则的时间步长：:math:`\Delta t=\frac{1}{10 f_\text{max}}`，其中 :math:`f_\text{max}` 是超单元或整个 OpenFAST 模型中存在的最高频率。

**Craig-Bampton 模态数量** 建议对不断增加的 Craig-Bampton 模态数量进行结果敏感性分析，以了解需要多少模态才能达到收敛，并了解哪些模态对系统响应贡献最大。

OpenFAST 5.0
~~~~~~~~~~~~

随着 OpenFAST 5.0 的发布，ExtPtfm 的输入文件及其内部公式发生了重大变化。启用了 ExtPtfm 与 HydroDyn 之间以及 ExtPtfm 与系泊模块之间的耦合，以便更方便地模拟柔性浮式结构。最后，现在可以使用 ExtPtfm 进行线性化。

在 ExtPtfm 中模拟浮式结构时，可以在粘合代码中启用 HydroDyn，通过 `NAddDOF` 选项为刚体模态和附加广义自由度计算并提供势流波浪激励和辐射载荷以及静水载荷（参见 HydroDyn 文档）。使用此设置时，我们需要 ExtPtfm 中的活动模态数量等于 HydroDyn 中的 :math:`6+NAddDOF`，其中前 6 个模态是刚体模态，后跟若干弹性模态。

请注意，如果 HydroDyn 还包含条带理论构件，则生成的条带理论载荷将全部仅映射到 ExtPtfm 刚体模态，而不是弹性模态。因此，不建议用户在 HydroDyn 中使用仅条带理论的构件。这同样适用于 HydroDyn 中的海洋生物附着和压载/注水功能。但是，在许多情况下，仍然可以使用仅考虑阻力的混合构件来帮助获得更真实的浮体运动。阻力往往较小，对结构载荷没有强烈的直接影响。在这种情况下，仅将阻力映射到刚体模态是可以接受的简化。同样的考虑也适用于 HydroDyn 中尚不支持广义自由度的二阶势流选项。

当与系泊耦合时，必须在 ExtPtfm 模块中定义一组连接点。这些连接点与系泊模型中的导缆孔耦合。通常，ExtPtfm 中的连接点应该与系泊模型中用作导缆孔的点集相同；但是，它们不必完全相同，因为 OpenFAST 会自动在两者之间引入最近邻映射，假设是刚性连接。

请注意，上述 ExtPtfm 与 HydroDyn 和系泊耦合的工作流程仍在开发中。
