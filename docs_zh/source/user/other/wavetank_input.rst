.. _WaveTank-Input:

输入文件
----------

本文档介绍用于设置和运行海洋动能（MHK）水轮机测试的
WaveTank 模型配置输入文件（``wavetankconfig_input.txt``）。

- 此文件由 WaveTank 库在初始化期间读取。

约定与单位
---------------------

- 全文使用 SI 单位制：m、s、kg、N、Pa。
- 除非另有说明，角度以度为单位。
- 旋转速度在注明处以 rpm 为单位。
- 除非另有说明，位置和高度以平均海平面（MSL）为参考。
- 模块的输入文件可以使用相对路径或绝对路径。

文件与仿真控制
---------------------------

OutRootName（字符串）
  写入汇总文件或其他文件时使用的根名称。
  示例：``FRM1Q_Floating_tank_test``。

DT（s）
  WaveTank 内部调度的名义时间步长。当前未使用/预留。

TMax（s）
  WaveTank 内部调度的最大仿真时间。当前未使用/预留。

MHK（开关）
  MHK 水轮机类型开关：

  - 0：非 MHK 水轮机
  - 1：固定式 MHK 水轮机
  - 2：浮式 MHK 水轮机

  目前仅支持浮式选项（2）。

InterpOrd（-）
  内部数据插值的插值阶数。当前未使用/预留。

DebugLevel（开关）
  控制日志记录和可视化详细程度：

  - 0：无
  - 1：I/O 摘要
  - 2：+ 传递的位置/方向
  - 3：+ 输入文件
  - 4：+ 所有网格

.. note::
   标记为"未使用"的参数保留用于未来开发，当前被代码路径忽略。

Froude 缩放（已禁用）
-------------------------

以下参数可能出现，但通常被注释掉。Froude 缩放在当前代码中尚未完成。
除非显式启用，否则不要使用。

ScaleFact（-）
  Froude 缩放因子 λ =（全尺寸）/（模型尺寸）。对于缩比模型试验，期望 > 1。

DensFact（-）
  密度比 ρ_full / ρ_model，用于力和力矩的 Froude 缩放。

环境
-----------

Gravity（m/s^2）
  重力加速度。

WtrDens（kg/m^3）
  水（工作流体）密度。

WtrVisc（m^2/s）
  工作流体的运动粘度。

SpdSound（m/s）
  工作流体中的声速。

Patm（Pa）
  大气压力。用于空化检查。

Pvap（Pa）
  工作流体的汽化压力。用于空化检查。

WtrDpth（m）
  水深。

MSL2SWL（m）
  静水位（SWL）与平均海平面（MSL）之间的偏移量；向上为正。

海洋状态
---------

SS_InputFile（字符串）
  定义波浪条件的 SeaState 输入文件路径。确保路径相对于运行目录有效，
  或使用绝对路径。

WaveTimeShift（s）
  应用于 SeaState 波浪时间序列的时间偏移，用于调整相位以匹配水槽条件。

MoorDyn
-------

MD_InputFile（字符串）
  定义系泊系统属性和连接的 MoorDyn 输入文件路径。

AeroDyn 与 InflowWind
----------------------

AD_InputFile（字符串）
  定义气动模型配置的 AeroDyn 输入文件路径
  （用于 MHK 场景中适用的水力/气动耦合）。

IfW_InputFile（字符串）
  定义转子来流条件（如海流或风，取决于模型设置）的 InflowWind 输入文件路径。

水轮机几何与参考系
-------------------------------------

NumBl（-）
  转子叶片数。

HubRad（m）
  从转子顶点到叶片根部的距离。

PreCone（deg）
  叶片锥角。

OverHang（m）
  从偏航轴（塔筒中心线）到转子顶点的距离。
  负值表示按模型约定转子顶点位于偏航轴后方。

ShftTilt（deg）
  转子轴倾斜角。

Twr2Shft（m）
  从塔筒顶部到转子轴中心（机舱中心）的垂直距离。负值表示在塔筒顶部以下。

TowerHt（m）
  塔筒相对于 MSL 的高度。塔筒垂直对齐于 ``TowerBsPt``（不支持倾斜塔筒）。

TowerBsPt（m, m, m）
  塔筒基底相对于平台参考位置的位置（x 和 y 方向）以及相对于 MSL 的高度（z 方向）：

  - x：沿纵荡轴
  - y：沿横荡轴
  - z：相对于 MSL 的高度

PtfmRefPos（m, m, m）
  平台参考点相对于 MSL 的位置。所有平台运动和载荷在此点连接。

PtfmRefOrient（deg, deg, deg）
  平台参考方向，以 Euler 角 [roll, pitch, yaw] 给出。

水轮机初始条件
--------------------------

RotSpeed（rpm）
  转子的初始旋转速度（转子坐标系中）。

NacYaw（deg）
  初始或固定的机舱偏航角。

BldPitch（deg）
  叶片 1 的初始变桨角。如果使用多叶片模型，叶片变桨控制
  通常在其他模块中按叶片应用；此处初始化叶片 1。

Azimuth（deg）
  转子初始方位角。

波浪浮标
---------

WaveBuoyLoc（m, m）
  波浪高程测量浮标在水槽坐标系中的位置。
  SeaState 数据在每个时间步在该位置返回。

输出
------

SendScreenToFile（flag）
  如果为 true，将屏幕输出发送到名为 ``<OutRootName>.screen.log`` 的文件。

OutFile（switch）
  控制通道的表格输出：

  - 0：无通道输出文件
  - 1：文本格式的输出文件（以默认 DT 写入）

OutFmt（字符串）
  文本表格输出通道的格式说明符（时间通道除外）。使用类似 Fortran 的格式字符串。
  示例：``ES20.6E2``。

VTK 可视化输出
------------------------

WrVTK_Dir（字符串）
  VTK 可视化文件的输出目录。

WrVTK（switch）
  VTK 可视化数据输出：

  - 0：无
  - 1：仅初始化数据
  - 2：动画
  - 3：模态振型

WrVTK_type（switch）
  VTK 可视化数据类型：

  - 1：表面
  - 2：基本网格（线/点）
  - 3：所有网格（调试）

.. note::
   某些构建版本可能仅支持线/点。如果表面不受支持，
   请使用 ``WrVTK_type = 2`` 可视化线/点数据。

WrVTK_DT（s）
  写入 VTK 文件的时间步长。

VTKNacDim（m, m, m, m, m, m）
  用于 VTK 表面渲染的机舱尺寸，格式为 ``[x0, y0, z0, Lx, Ly, Lz]``：

  - ``x0, y0, z0``：机舱原点偏移
  - ``Lx, Ly, Lz``：机舱沿 x, y, z 方向的范围

实现说明与最佳实践
---------------------------------------

- 目前仅支持浮式 MHK（``MHK = 2``）；其他 MHK 模式将不会
  按预期运行。
- 确保外部文件路径（*SeaState*、*MoorDyn*、*AeroDyn*、*InflowWind*）
  相对于工作目录有效，或指定绝对路径。
- 坐标约定：

  - 除非另有说明，位置和高度以 MSL 为参考。
  - 平台参考点（``PtfmRefPos``）是运动和载荷的耦合点。
  - 塔筒基底在 x 和 y 方向上相对于 ``PtfmRefPos`` 定义，在 z 方向上
    相对于 MSL 定义。

- 选择 ``OutFmt`` 以在精度和文件大小之间取得平衡。示例 ``ES20.6E2``
  适用于固定宽度的科学记数法。
