代码间比较
~~~~~~~~~~

为了验证 OpenFAST 链接的噪声模型与德国慕尼黑工业大学风能研究所可用的实现，进行了详细的代码间比较。后者在 Sucameli (:cite:`aa-Sucameli:2018`) 中描述，并在风力机设计框架 Cp-Max 中实现，该框架采用基于多体的气动伺服弹性求解器 Cp-Lambda。

针对主要噪声源——湍流来流和 TBL-TE 噪声，分别对单翼型剖面和全尺寸风力机进行了比较。这帮助解决了一些实现错误和小的不一致性。比较在 8 米/秒（m/s）的稳定风、无剪切、额定变桨角 1.17 度（deg）和固定转子转速 10.04 转/分钟（rpm）的条件下进行。假设入射湍流强度 :math:`I_{1}` 的固定值为 0.1。

:numref:`aa-fig:TI-compare` 展示了 OpenFAST 中带攻角修正的 Amiet 模型、OpenFAST 生成的简化 Guidati 模型以及 Cp-Max 中的 Amiet 模型在 SPL 方面的预测结果。

.. figure:: media/NoiseN003.png
   :alt:    TI 模型的代码间比较
   :name:   aa-fig:TI-compare
   :width:  100.0%

   TI 模型的代码间比较

湍流来流 Amiet 模型的两个实现在 OpenFAST 和 Cp-Max 之间返回了完美的匹配。所选场景下叶片运行在最佳攻角，因此攻角修正的影响可以忽略。图中还显示了 Amiet 模型和简化 Guidati 模型之间的巨大差异。需要记住的是，简化 Guidati 模型过去曾经应用过 +10 dB 的修正因子，这里也应用了这个修正。

对于相同的来流和转子条件，:numref:`aa-fig:BPM-TNO-compare` 比较了 BPM 和 TNO TBL-TE 噪声模型。匹配度同样令人满意，尽管出现了稍大的差异，这归因于两个气动弹性求解器之间攻角的差异以及 TNO 公式中不同积分方案的差异。

.. figure:: media/NoiseN004.png
   :alt:    BPM 和 TNO TBL-TE 模型的代码间比较
   :name:   aa-fig:BPM-TNO-compare
   :width:  100.0%

   BPM 和 TNO TBL-TE 模型的代码间比较。边界层特性可以通过 BPM 模型估算（BPM BL）或由用户定义（Ext BL）

最后一项比较考察了指向性模型和不同观察者位置的总声压级。仿真中在 500 米 × 500 米的水平正方形区域内分布了 200 个观察者（见 :numref:`aa-fig:obs-loc`）。噪声通过 Amiet 和 BPM 湍流边界层-后缘模型计算。代码间比较显示 OpenFAST 和 Cp-Max 的预测结果相似。比较结果如 :numref:`aa-fig:SPL-obs` 所示。

本次代码间比较的主要结论是，据作者所知，模型现在已经正确实现，对于任意观察者都能生成相似的 SPL 和总 SPL 水平。尽管如此，显然所有提出的模型都不完美，在理论实现层面都还有改进空间。

.. _aa-sec-ModelUsage:

模型使用
~~~~~~~~

OpenFAST 的气动噪声模型有四种输出选项：

1. 总声压级（dB/A 计权分贝 [dBA]）——每个观察者每个时间步生成一个值

2. 总声压级谱（dB/dBA）——每个观察者每个时间步生成一个 10 Hz 到 20 kHz 之间的谱

3. 按机制区分的声压级谱（dB/dBA）——每个观察者每个时间步每个激活的噪声机制生成一个 10 Hz 到 20 kHz 之间的谱

4. 总声压级（dB/A 计权分贝 [dBA]）——每个观察者每个时间步每个叶片每个节点生成一个值

第一种选项的总 SPL 可用于绘制噪声的指向性图。使用 Python 脚本生成的一个示例 [3]_ 如 :numref:`aa-fig:SPL-map` 所示。该噪声图显示了在 8 m/s 稳定风速、10.04 rpm 固定转子转速和 1.17 度变桨角条件下，1 个转子旋转周期内平均的总 SPL。在直径 500 m 的水平圆内，2 米高度处放置了 1681 个观察者。仅激活了简化 Guidati 和 BPM TBL-TE 噪声模型。

.. figure:: media/NoiseN007.png
   :alt:    参考风力机总 SPL 图
   :name:   aa-fig:SPL-map
   :width:  100.0%

   简化 Guidati 和 BPM TBL-TE 噪声模型得到的参考风力机在 2 米高度处的总 SPL 图。风力机位于 x=0, y=0 处。8 m/s 的稳定风从左侧（-x）吹向右侧（+x）。

第二种输出可用于生成 SPL 谱。这些谱可以为不同的观察者计算，并可选择应用 A 计权以考虑人耳听觉特性。:numref:`aa-fig:A-SPL` 显示了为与前例相同转子条件计算的总 SPL 谱。A 计权极大地降低了 1000 Hz 以下频率的曲线，同时略微提高了 1 kHz 到 8 kHz 之间的曲线。

.. figure:: media/NoiseN008.png
   :alt:    绝对 SPL 和 A 计权 SPL 的比较
   :name:   aa-fig:A-SPL
   :width:  100.0%

   绝对 SPL 和 A 计权 SPL 的比较

第三种输出区分了每个机制的 SPL 谱。:numref:`aa-fig:SPL-spectra` 显示了每个噪声模型为前述相同转子条件估算的各种 SPL 谱。总谱明显由湍流来流、TBL-TE 和后缘钝度噪声机制主导。值得注意的是，后者对其输入 :math:`\Psi` 和 :math:`h` 极其敏感。参考风力机是纯数值模型，这些量是任意设置的。用户在调用后缘钝度模型时应注意这些输入。与文献一致，层流边界层-涡脱落和叶尖涡噪声机制具有负 dB 值，因此不可见。注意这些谱没有应用 A 计权，但用户可以激活标志以获得 A 计权谱。

.. figure:: media/NoiseN009.png
   :alt:    各种噪声机制的非计权 SPL 谱
   :name:   aa-fig:SPL-spectra
   :width:  100.0%

   各种噪声机制的非计权 SPL 谱

最后，第四种输出可用于可视化整个转子的噪声排放。:numref:`aa-fig:rotor-map` 显示了从位于下风方向 175 米、高度 2 米处的观察者看到的转子噪声产生情况。该图通过绘制一个叶片在一个转子旋转周期内产生的总 SPL 生成。图中显示，当叶片下降时观察到更高的噪声（从后方看转子逆时针旋转）。这个效应与 :cite:`aa-MoriartyMigliore:2003` 中显示的结果一致，可以通过 :eq:`aa-eq:31` 的不对称性来解释。实际上，当观察者面对翼型前缘（高 :math:`\Theta_e`）时，噪声比面对后缘（低 :math:`\Theta_e`）时更高。

   :alt:    简化 Guidati 和 BPM TBL-TE 噪声模型得到的参考风力机转子总 SPL 图。观察者位于下风方向 175 米、高度 2 米处。
   :name:   aa-fig:rotor-map
   :width:  100.0%

   简化 Guidati 和 BPM TBL-TE 噪声模型得到的参考风力机转子总 SPL 图。观察者位于下风方向 175 米、高度 2 米处。
