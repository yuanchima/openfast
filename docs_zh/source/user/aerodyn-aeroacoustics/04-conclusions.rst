结论
-----

本文档描述了耦合到开源气动伺服弹性求解器 OpenFAST 的一组基于频率的气动噪声模型。这些模型的目标是预测风力机转子的气动噪声排放。文档展示了耦合到 OpenFAST 的模型与慕尼黑工业大学实现并耦合到气动伺服弹性求解器 Cp-Lambda 的模型之间的代码间比较。比较通过仿真 IEA 风能任务 37 陆上参考风力机的气动噪声排放进行。结果显示两个实现之间具有良好的一致性。随后使用相同的风力机模型测试了气动噪声模型，展示了其功能。最后，附录描述了运行气动噪声分析所需的 OpenFAST 输入文件条目。

未来的工作将集中在气动噪声模型的验证上。同时，将研究并实现传播模型。最后，将关注次声噪声以及能够仿真次声噪声的时域模型。
