输出文件
============
SeaState生成五种类型的输出文件：回显文件、波浪高程文件、波浪运动学文件、汇总文件和时间序列文件。以下各节详细说明这些文件的用途和内容。

回显文件
~~~~~~~~~~
如果您在SeaState驱动文件或SeaState主输入文件中将**Echo**标志设置为TRUE，这些文件的内容将被回显到一个文件中，驱动输入文件的命名约定为**OutRootName**\ *.dvr.ech*，SeaState主输入文件的命名约定为**OutRootName**\ *.SeaSt.ech*。**OutRootName**要么在驱动输入文件的SEASTATE部分指定，要么由OpenFAST程序指定。回显文件有助于调试输入文件。如果SeaState在解析输入文件时遇到错误，回显文件的内容将被截断。错误通常对应于最后成功回显行之后的行。

波浪高程文件
~~~~~~~~~~~~~~~~~~~~
将驱动文件中的**WaveElevSeriesFlag**设置为TRUE可以将整个SeaState波浪网格的波浪高程输出到一个名为``OutRootName.WaveElev.out``的文本文件中。输出波浪网格由SeaState主输入文件的空间离散化部分控制。这些波浪高程与SeaState主输入文件中由**NWaveElev**确定的波浪高程是分开的，后者记录在时间序列输出文件中。波浪高程输出文件``OutRootName.WaveElev.out``包含总波浪高程，即一阶和二阶项之和（当可选地启用二阶波浪运动学时）。此处描述的波浪高程文件可用于可视化目的。

波浪运动学文件
~~~~~~~~~~~~~~~~~~~~~
**WrWvKinMod**控制SeaState驱动的波浪运动学输出。如果**WrWvKinMod** = 1，驱动将在单独的*.Elev*文件中输出全局原点(0,0)处的波浪高程时间序列。该文件也可以作为SeaState主输入文件中**WaveMod** = 5（外部生成的波浪高程时间序列）的有效**WvKinFile**。这是一个独立的波浪高程输出，与**WaveElevSeriesFlag** = TRUE获得的波场输出以及SeaState主输入文件中**NWaveElev**获得的波浪高程时间序列无关。

如果**WrWvKinMod** = 2，SeaState将在八个输出文件中输出所有波浪网格点的完整波浪运动学（速度、加速度、动压力和波浪高程），文件扩展名为*.Vxi*、*.Vyi*、*.Vzi*、*.Axi*、*.Ayi*、*.Azi*、*.DynP*和*.Elev*。速度和加速度输出均在全局地固坐标系中。这些文件也可以作为**WaveMod** = 6（外部生成的完整波浪运动学时间序列）的有效**WvKinFile**，如果用户想要为**WaveMod** = 6构建自己的输入文件，可以作为模板。

汇总文件
~~~~~~~~~~~~
如果**SeaStSum**参数设置为TRUE，SeaState将生成一个命名约定为**OutRootName**\ *.SeaSt.sum*的汇总文件。该文件汇总了海况模型的关键信息，包括水密度、水深、静水位、波浪网格、一阶波浪频率分量以及任何用户请求的时间序列输出。

用户请求输出的汇总
---------------------------------
汇总文件包含所有用户请求的波浪高程和波浪运动学时间序列输出通道的信息。

波浪运动学输出位置
++++++++++++++++++++++++++++++++
第一列列出了波浪运动学输出位置的索引，如SeaState输入文件的输出通道部分中输入的那样。**Xi**、**Yi**和**Zi**提供了波浪运动学输出位置在全局惯性坐标系中的空间坐标。

波浪高程输出位置
+++++++++++++++++++++++++++++++
第一列列出了波浪高程输出位置的索引，如SeaState输入文件的输出通道部分中输入的那样。**Xi**和**Yi**提供了波浪高程输出位置在全局惯性坐标系中的空间坐标。

请求的输出通道
+++++++++++++++++++++++++
此处汇总了所有请求的时间序列输出通道的字符串标签，如SeaState主输入文件的输出通道部分中输入的那样。

波浪频率分量
-------------------------
本节提供了自由表面上(0,0)处一阶波浪高程的频域描述（根据离散傅里叶变换或DFT），但当**WaveMod** = 0或6时不会写入。第一列**index**标识每个波浪频率分量的索引。波浪分量的有限深度波数、角频率和方向分别由**k**、**Omega**和**Direction**给出。最后两列提供了一阶DFT波浪振幅的实部（**REAL(DFT{WaveElev})**）和虚部（**IMAG(DFT{WaveElev})**）。DFT同时产生负频率和正频率分量。由于时域波浪高程是实数值，负频率分量是正频率分量的复共轭。DFT的负频率和正频率分量之间的关系由:math:`k\left( - \omega \right) = - k\left( \omega \right)`和:math:`H\left( - \omega \right) = {H\left( \omega \right)}^{*}`给出，其中*H*是波浪高程的DFT，*\**表示复共轭。

结果文件
~~~~~~~~~~~~
当**OutSwtch**设置为1或3时，SeaState时间序列结果将写入命名约定为``OutRootName.SeaSt.out``的文本文件中。如果SeaState与OpenFAST耦合且**OutSwtch**设置为2或3，则OpenFAST将生成一个包含SeaState结果的主结果文件。结果采用表格格式，其中每列是一个数据通道（第一列始终是仿真时间），每行对应一个仿真输出时间步。数据通道在SeaState主输入文件的输出通道部分指定。SeaState生成文件的列格式使用主输入文件的**OutFmt**和**OutSFmt**参数指定。
