输入文件
===========

用户通过SeaState主输入文件配置海况模型参数。在独立模式下使用时，还需要额外的驱动输入文件。该驱动文件指定了通常由OpenFAST提供给SeaState的初始化输入。

除非在指定行数的表格中，否则不得在输入文件中添加或删除行。

单位
~~~~~
SeaState使用国际单位制（kg, m, s）。

.. _sea-driver-input:

SeaState驱动输入文件
~~~~~~~~~~~~~~~~~~~~~~~~~~
驱动输入文件仅在独立版本的SeaState中需要，包含通常由OpenFAST生成的输入。控制非耦合模型的海况条件是必要的。附录B中给出了SeaState驱动输入文件的示例。

如果希望``SeaStateDriver``回显驱动输入文件的内容（对调试驱动文件中的错误很有用），请将此文件中的**Echo**标志设置为TRUE。回显文件的命名约定为``OutRootName.dvr.ech``。**OutRootName**在驱动输入文件的SEASTATE部分指定。使用**Gravity**参数设置重力常数。SeaState期望的是幅值，因此在国际单位制中应设置为9.80665 :math:`\frac{m}{s^{2}}`。
**WtrDens**指定水的密度，必须大于或等于零；海水的典型值约为1025 kg/m³。**WtrDpth**指定相对于平均海平面（MSL）的水深（平坦海床的深度），必须大于零。**MSL2SWL**是平均海平面（MSL）和静水位（SWL）之间的偏移量，如果SWL高于MSL则为正。**SeaStateInputFile**是SeaState主输入文件的文件名。该名称应加引号，可以包含绝对路径或相对路径。

**WrWvKinMod**控制SeaState驱动的波浪运动学输出。设置为0会抑制波浪运动学的驱动输出。如果**WrWvKinMod** = 1，驱动将在单独的*.Elev*文件中输出全局原点(0,0)处的波浪高程时间序列。该文件也可以作为SeaState主输入文件中**WaveMod** = 5（外部生成的波浪高程时间序列）的有效**WvKinFile**。如果**WrWvKinMod** = 2，SeaState将在八个输出文件中输出所有波浪网格点的完整波浪运动学（速度、加速度、动压力和波浪高程），文件扩展名为*.Vxi*、*.Vyi*、*.Vzi*、*.Axi*、*.Ayi*、*.Azi*、*.DynP*和*.Elev*。速度和加速度输出均在全局地固坐标系中。这些文件也可以作为**WaveMod** = 6（外部生成的完整波浪运动学时间序列）的有效**WvKinFile**，如果用户想要为**WaveMod** = 6构建自己的输入文件，可以作为模板。
**NSteps**指定仿真时间步的数量，**TimeInterval**指定步间的时间间隔。**WaveElevSeriesFlag**可以设置为TRUE，以输出扩展名为*.WaveElev.out*的文件，其中包含每个时间步的波高程场，用于可视化目的。设置为FALSE会抑制此输出。请注意，**WrWvKinMod** = 2和**WaveElevSeriesFlag** = TRUE的网格点都由下面解释的SeaState主输入文件的空间离散化部分控制。

环境条件
------------------------
环境条件现在在驱动输入文件中指定，但为了向后兼容，仍保留在主输入文件中。使用关键字DEFAULT来传入驱动输入文件指定的值。否则，主输入文件中给出的值将覆盖驱动输入文件中给出的值。
**WtrDens**指定水的密度，必须大于或等于零；海水的典型值约为1025 kg/m³。**WtrDpth**指定基于参考平均海平面（MSL）的水深（平坦海床的深度），必须大于零。**MSL2SWL**是MSL和SWL之间的偏移量，当SWL高于MSL时为正。此参数在模拟潮汐或风暴潮海平面变化的影响时非常有用，无需更改子结构几何信息。当**WaveMod** = 6时不使用此参数，如果在HydroDyn中使用势流模型（**PotMod** = 1或2），则必须将其设置为零。

空间离散化
---------------------------
空间离散化部分控制波浪网格的生成。该波浪网格主要由HydroDyn使用，但也被OpenFAST的其他模块用于计算水中结构的水动力和静水载荷。添加波浪网格是为了让HydroDyn中的切片理论构件在评估载荷时，可以使用结构瞬时位移位置处的波浪运动学和动压力。它还允许HydroDyn中的势流波浪激励基于水平面内的任何大漂移运动（例如由强风推力引起的漂移）进行修正。

请注意，在以前版本的OpenFAST中，势流波浪激励和切片理论构件的波场是在结构处于未位移位置时预先计算的。OpenFAST中不再存在这种操作模式，即使用户在HydroDyn中评估切片理论和/或势流水动力载荷时选择不考虑结构位移，也必须始终定义波浪网格。

目前，SeaState波浪网格始终以全局原点为中心，并且关于*XZ*平面和*YZ*平面对称。

**X_HalfWidth**设置波浪网格在全局*X*方向的半宽（单位：m），使得波浪网格覆盖区域为−**X_HalfWidth** ≤ *X* ≤ +**X_HalfWidth**。**X_HalfWidth**必须大于零。

**Y_HalfWidth**设置波浪网格在全局*Y*方向的半宽（单位：m），使得波浪网格覆盖区域为−**Y_HalfWidth** ≤ *Y* ≤ +**Y_HalfWidth**。**Y_HalfWidth**必须大于零。

**Z_Depth**设置波浪网格的深度（单位：m），使得波浪网格覆盖区域为(**MSL2SWL** − **Z_Depth**) ≤ *Z* ≤ **MSL2SWL**。**Z_Depth**必须大于零且小于或等于**MSL2SWL** + **WtrDpth**。将**Z_Depth**设置为DEFAULT将自动将其值设置为**MSL2SWL** + **WtrDpth**。

**NX**设置*X*方向上半域的均匀分布网格点数量，包括原点处的一个点。因此，*X*方向上的总网格点数等于2**NX**−1。**NX**必须大于或等于2。

**NY**设置*Y*方向上半域的均匀分布网格点数量，包括原点处的一个点。因此，*Y*方向上的总网格点数等于2**NY**−1。**NY**必须大于或等于2。

**NZ**设置垂直*Z*方向上从*Z* = (**MSL2SWL** − **Z_Depth**)到*Z* = **MSL2SWL**的网格点数量。*Z*方向上的网格点分布不是均匀的，而是遵循余弦分布：*Z*\ [*n*\ ] = **Z_Depth**\ (cos(\ *n*\ ·d\ *θ*\ )–1)，其中*n* = 0,1,…,**NZ**-1，d\ *θ* = *π*/(2(**NZ**-1))。这种分布在自由表面附近放置更多的网格点。**NZ**必须大于或等于2。

设置波浪网格时，必须确保波浪网格在所有三个方向上都足够大，使得HydroDyn中定义的结构的任何部分在仿真过程中都不会移出波浪网格。同时，网格也应足够精细，以解析感兴趣的最短波长。

OpenFAST在仿真开始时预先计算并保存波场速度、加速度、动压力和波浪高程。对于长仿真，生成和维护波浪网格可能会占用大量内存。用户应将波浪网格设置为不超过必要的大小或精细度，以减少内存使用。减小**WaveTMax**或增大**WaveDT**（见下文波浪部分）也可以减少内存使用。对于沿*X*方向（或*Y*方向）对齐的长峰波（无方向扩展），可以将**NY**（或**NX**）减小到允许的最小值2以节省内存。

波浪
-----
输入文件的波浪部分控制一阶波浪的内部生成或外部生成波浪的使用，供HydroDyn中的切片理论和势流建模使用。本节中的波浪谱设置仅适用于一阶波浪频率分量。当可选地启用二阶项时（参见下文:ref:`sea-2nd_order_waves_input`和:ref:`hd-2nd_order_floating_platform_forces_input`部分），二阶项使用一阶波浪分量幅值计算，并向波浪谱中添加额外能量（在差频和和频处）。

**WaveMod**指定入射波浪运动学模型。选项包括：

* 0: 无 = 静水

* 1: 规则（周期性）波浪

* 1P#: 用户指定相位的规则（周期性）波浪，例如1P20.0表示相位为20˚的规则波浪（如果没有P#，相位将基于**WaveSeed**随机生成）；0˚相位表示余弦函数，从峰值开始并随时间减小

* 2: 基于JONSWAP或Pierson-Moskowitz频谱的不规则（随机）波浪

* 3: 基于白噪声频谱的不规则（随机）波浪

* 4: 基于*UserWaveSpctrm()*例程的用户自定义频谱的不规则（随机）波浪；需要重新编译SeaState独立程序或OpenFAST。

* 5: 外部生成的波浪高程时间序列

* 6: 外部生成的完整波浪运动学时间序列

* 7: 用户定义的波浪频率分量

选项4要求用户实现*Waves.f90*源文件中的*UserWaveSpctrm()*子例程，并且需要重新编译独立SeaState程序或OpenFAST。选项5允许使用外部生成的波浪高程时间序列，从中内部推导出势流解中的水动力载荷或切片理论解中使用的波浪运动学。选项6允许将完整的外部生成波浪运动学用于切片理论解（但不适用于势流解）。选项7允许用户指定波浪频率分量（幅值/波高、相位和方向）。对于选项5、6和7，外部生成的波浪数据通过输入文件提供，所有这些文件的根名称由下面的**WvKinFile**参数给出。

**WaveStMod**设置波浪拉伸公式，允许在HydroDyn中评估直至瞬时入射波自由表面的切片理论水动力和静水载荷（包含波斜率贡献）。目前实现了三种不同的波浪拉伸公式：垂直拉伸（选项1）、外推拉伸（选项2）和Wheeler拉伸（选项3）。使用这三种波浪拉伸模型中的任何一种还将导致HydroDyn计算直至瞬时自由表面的切片理论构件上的非线性静水载荷，包括非零波斜率的任何贡献。将**WaveStMod**设置为0将禁用波浪拉伸，切片理论水动力和静水载荷将始终评估到SWL。当**WaveMod** = 6（外部生成的完整波浪运动学时间序列）时，不支持外推拉伸（**WaveStMod** = 2）。

**WvCrntMod**控制波浪和水流组合条件的建模。可以设置为0、1或2，具有以下效果。

+----------------------+-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| **WvCrntMod** 值      | 效果                                                                                                                                                                                                                                                                                       |
+======================+===============================================================================================================================================================================================================================================================================================+
| 0                    | 简单叠加，将水流速度和加速度添加到波浪的速度和加速度中。水流对波浪没有直接影响。此选项重现了以前版本OpenFAST的行为。                                                                                                                                                                    |
+----------------------+-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| 1                    | 通过求解经水流修正的波浪色散关系，包含波浪的多普勒效应。输入波浪谱/时间序列假定为直接在有水流区域测量的，SeaState不会对其进行修改。波长会根据多普勒效应进行修正。                                                                                                                    |
+----------------------+-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| 2                    | 波浪和水流之间的完全相互作用，包含多普勒效应和波流相互作用的波浪幅值/谱缩放。输入波浪谱/时间序列假定为在无水流区域测量的，并根据水流速度/方向重新缩放。                                                                                                                            |
+----------------------+-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+

将**WvCrntMod**设置为1和2会对允许的波浪和水流施加额外限制。

+----------------------+------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| **WvCrntMod** 值      | 限制                                                                                                                                                                                                                       |
+======================+==============================================================================================================================================================================================================================+
|  0                   | 无额外限制                                                                                                                                                                                                                   |
+----------------------+------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
|  1                   | 无方向扩展的一阶长峰波                                                                                                                                                                                                       |
+----------------------+------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
|  2                   | 无方向扩展的一阶长峰波；波浪和水流仅共线（对齐或反向）；实现的幅值/谱缩放假定为深水条件，尽管不会对此进行检查。                                                                                                                |
+----------------------+------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+

严格来说，**WvCrntMod**的选项1和2仅适用于均匀水流；但是允许剪切水流，由用户确保从表面到波浪相关深度的水流剖面是合理均匀的。SeaState在计算水流对波浪的影响时，仅取静水位处的水流速度。改进的波流建模可以与SeaState水流或InflowWind的动态水流一起使用，用于模拟海洋水动力涡轮机。对于后者，波流相互作用基于静水位处的时间平均水流速度。对于InflowWind中适用的**WindType**，用户应确保InflowWind的流场网格到达静水位。当**WaveMod** = 0或6，或者SeaState（**CurrMod** = 0）或InflowWind（如果模拟海洋水动力涡轮机）没有水流时，**WvCrntMod**无效。

**WaveTMax**设置入射波浪运动学时间序列的长度，但它也决定了逆FFT中使用的频率步长，内部波浪时间序列由此推导得到（*Δω* = 2*π*/**WaveTMax**）。当**WaveMod** = 7（用户定义的波浪频率分量）时，用户指定的所有频率分量必须是*Δω*的整数倍，最低允许频率等于*Δω*。如果**WaveTMax**小于总仿真时间，SeaState将实现周期为**WaveTMax**的重复波浪运动学；当**WaveMod** = 5时，**WaveTMax**不得小于总仿真时间。**WaveDT**确定波浪运动学时间序列的时间步长，但它也决定了逆FFT中的最大频率（*ω*\ :sub:`max` = *π*/**WaveDT**）。当**WaveMod** = 7时，不使用**WaveDT**，合适的时间步长由用户定义的频率分量内部确定。在模拟不规则海况时，我们建议**WaveTMax**设置为至少1小时（3600秒），**WaveDT**设置为0.1到1.0秒之间的值，以确保波浪谱和波浪运动学的足够分辨率。当SeaState与OpenFAST耦合时，**WaveDT**可以独立于OpenFAST的耦合框架时间步长任意指定（波浪运动学将根据需要在时间上进行插值）；当**WaveMod** = 6时，**WaveDT**必须等于OpenFAST的耦合框架时间步长。**WaveTMax**和**WaveDT**也会影响SeaState波浪网格使用的内存量；较短的**WaveTMax**和较长的**WaveDT**可以减少内存使用。

对于内部生成的波浪，规则波的波高（波峰到波谷，两倍振幅）和不规则波的有效波高使用**WaveHs**设置（仅在**WaveMod** = 1、2或3时使用）。规则波的周期和不规则波的谱峰周期由**WaveTp**参数控制（仅在**WaveMod** = 1或2时使用）。**WavePkShp**是JONSWAP不规则波浪谱的峰形参数（仅在**WaveMod** = 2时使用）。将**WavePkShp**设置为DEFAULT可获得IEC 61400-3附录B中推荐的值，该值基于谱峰周期和有效波高推导得到[IEC, 2009]。将**WavePkShp**设置为1.0则为Pierson-Moskowitz谱。

**WvLowCOff**和**WvHiCOff**控制一阶波浪谱的下限和上限截止频率（单位：rad/s）；一阶波浪分量幅值分别在这些截止频率以下和以上被置零。可以将**WvLowCOff**设置为低于一阶波浪谱的低能量限值，以最小化计算成本。设置适当的上限截止频率（**WvHiCOff**）也可以最小化计算成本，并且对于在接近破碎波极限时防止非物理效应，以及在使用切片理论解时避免高频（即短波长）下的非物理波浪力非常重要。当**WaveMod** = 0、1或6时，不使用**WvLowCOff**和**WvHiCOff**。

**WaveDir**（**WaveMod** = 0或6时不使用）是平均波浪传播方向（单位：度），必须在(-180,180]范围内。方向为0对应沿X轴正方向传播的波浪。方向为90对应沿Y轴正方向传播的波浪。**WaveDirMod**指定波浪方向扩展模型（仅在**WaveMod** = 2、3或4时使用）。将**WaveDirMod**设置为0会禁用方向扩展，导致沿**WaveDir**方向传播的长峰（平面推进）海况。将**WaveDirMod**设置为1可启用短峰海况建模，平均传播方向为**WaveDir**，通过常用的余弦扩展函数（COS:sup:`2\ S`）定义方向扩展谱，基于通过**WaveDirSpread**定义的扩展系数（*S*）。波浪方向扩展谱使用等能量方法离散化，使用**WaveNDir**个等能量箱。**WaveNDir**是大于或等于1的奇整数（1、3、5…），但SeaState可能会略微增加**WaveDir**的指定值，以确保每个方向箱内的波浪分量数量相同；设置**WaveNDir** = 1等效于设置**WaveDirMod** = 0。方向扩展的范围（单位：度）通过**WaveDirSpread**定义。等能量方法假定方向扩展谱是频率谱和扩展函数的乘积，即*S*\ (*ω*,\ *β*) = *S*\ (*ω*)\ *D*\ (*β*)。当使用二阶差频势流载荷的Newman近似时，不允许方向扩展。

**WaveSeed(1)**和**WavedSeed(2)**（**WaveMod** = 0、5或1时不使用）共同决定了内部伪随机数生成器（pRNG）的初始种子（起点），用于从波浪频率和方向谱推导内部波浪运动学。如果两者都是数值，则使用Fortran内置pRNG。如果**WaveSeed(2)**是字符串"RANLUX"，则使用NWTC库中包含的替代pRNG，**WaveSeed(1)**的值为种子。如果希望在给定边界条件（有效波高、谱峰周期等）下运行不同的时域实现，应在仿真之间更改一个或两个种子。虽然波浪谱的每个频率和方向分量的相位始终基于均匀分布（除非使用1P# **WaveMod**选项），但可以通过将**WaveNDAmp**设置为TRUE来随机化波浪频率谱的幅值（遵循正态分布）。将**WaveNDAmp**设置为FALSE意味着波浪频率谱的幅值始终与目标谱匹配。**WaveNDAmp**仅在**WaveMod** = 2、3或4时使用。

当使用外部生成的波浪数据（**WaveMod** = 5、6或7）时，输入参数**WvKinFile**应设置为：当**WaveMod** = 5或6时，输入文件的根名称（不带扩展名）；当**WaveMod** = 7时，带扩展名的完整文件名。

使用外部生成的波浪高程时间序列（**WaveMod** = 5）需要一个扩展名为*.Elev*的文本格式输入数据文件，包含两列数据——第一列是时间（从零开始，单位：秒），第二列是(0,0)处的波浪高程（单位：米），由空格分隔。标题行（识别为不以数字开头的行）将被忽略。时间序列长度必须至少为**WaveTMax**，且不小于总仿真时间，时间步长必须与**WaveDT**匹配。指定的波浪高程时间序列假定为一阶长峰波，但不会检查其物理正确性。当可选地启用二阶项时（见下文二阶波浪部分），二阶项使用从提供的波浪高程时间序列推导的波浪分量幅值计算，并向波浪谱中添加额外能量（在差频和和频处）。

使用完整的外部生成波浪运动学（**WaveMod** = 6）需要八个文本格式的输入数据文件，均没有标题。七个扩展名为*.Vxi*、*.Vyi*、*.Vzi*、*.Axi*、*.Ayi*、*.Azi*和*.DynP*的文件分别对应全局惯性坐标系中的*X*、*Y*、*Z*速度（单位：m/s）和加速度（单位：m/s²）以及动压力（单位：Pa）时间序列。每个文件必须有13个标题行，SeaState将跳过这些行，然后恰好有**WaveTMax**/**WaveDT**行和*N*个空格分隔的列，其中*N*是SeaState波浪网格点的总数（与写入SeaState汇总文件的完全对应）。节点的排序方式是首先按*X*位置递增，然后按*Y*位置递增，最后按*Z*位置递增，如SeaState汇总文件中所示。第一个节点位于(-**X_HalfWidth**,-**Y_HalfWidth**,\ **MSL2SWL**-**Z_Dpth**)。文件中不包含时间，但假定时间从零到**WaveTMax**，步长为**WaveDT**。第八个文件扩展名为*.Elev*，包含波浪高程时间序列（单位：米）。该文件必须恰好有**WaveTMax**/**WaveDT**行，列数与水平面中的网格节点数相同，由空格分隔。节点的排序方式是首先按*X*位置递增，然后按*Y*位置递增。第一个节点位于(-**X_HalfWidth**,-**Y_HalfWidth**)。使用此功能时，用户有责任在SeaState的每个时间步和网格点生成波浪运动学数据。SeaState在填充波浪网格时不会对数据进行插值。在这些输入文件中，数值（包括0）被假定为有效数据（0对应0 m、0 m/s、0 m/s²或0 Pa）；非数字字符串将被转换为零。这些文件中的数据不会被处理（过滤等）或检查物理正确性。完整的外部生成波浪运动学（**WaveMod** = 6）不能与势流解结合使用，并且只允许垂直和Wheeler波浪拉伸，不允许外推拉伸。用户可以运行SeaState独立驱动程序，使用任何内部波浪生成模型，例如**WaveMod** = 2，在驱动输入中设置**WrWvKinMod** = 2，生成一组有效的**WaveMod** = 6输入文件作为模板。

使用用户定义的波浪频率分量（**WaveMod** = 7）需要一个扩展名为*.Comp*的文本格式输入数据文件，包含四列数据。第一列包含波浪分量的角频率（单位：rad/s），第二列是分量的峰到谷波高（单位：米），第三列是分量的波浪方向，遵循上述**WaveDir**的约定（单位：度），最后一列是频率分量的波浪相位（单位：度）。相位为零对应*t* = 0时全局原点处的波峰。四列由空格分隔。标题行（识别为不以数字开头的行）将被忽略。有效的输入文件必须满足以下要求：

* 所有频率条目必须是频率步长*Δω* = 2π/**WaveTMax**的整数倍。强制执行10⁻³的相对容差，以允许输入频率中的某些截断误差。用户应确保输入频率和**WaveTMax**包含足够的有效数字以满足此要求。最低允许的波浪角频率是*Δω*。

* 如果某个频率分量的波高为零，则可以从输入文件中省略。

* 输入文件中列出的频率分量不需要按任何特定顺序排列。

* 对于每个频率，只能有一个条目。例如，不允许有两个不同方向但频率相同的波浪分量。

指定的波浪分量假定为一阶长峰波，但不会检查其物理正确性。当可选地启用二阶项时（见下文二阶波浪部分），二阶项使用指定的波浪分量计算，并向波浪谱中添加额外能量（在差频和和频处）。

.. _sea-2nd_order_waves_input:

二阶波浪
------------------------
输入文件的二阶波浪部分（**WaveMod** = 0或6时不使用）允许选择向切片理论解使用的波浪运动学中添加二阶贡献。当可选地启用二阶项时，二阶项使用一阶波浪分量幅值计算，并向波浪谱中添加额外能量（在差频和和频处）。如果不包含上文波浪部分的一阶项，则无法计算二阶项。启用二阶项可以捕捉真实表面波浪的某些非线性特性，从而能够更准确地模拟海况和相关的波浪载荷，但会增加计算量（主要在SeaState初始化阶段）。

虽然本节中的截止频率适用于SeaState的二阶波浪运动学（用于HydroDyn中的切片理论载荷）和HydroDyn中的**二阶势流载荷**，但二阶项本身是单独启用的。切片理论使用的二阶波浪运动学在本节中启用，而势流理论的二阶衍射载荷在HydroDyn主输入文件的:ref:`hd-2nd_order_floating_platform_forces_input`部分中启用。只有当本节中启用二阶波浪运动学时，SeaState的波浪高程输出才会包含二阶贡献。

要在切片理论解中使用二阶波浪运动学，请将**WvDiffQTF**和/或**WvSumQTF**设置为TRUE。当**WvDiffQTF**设置为TRUE时，使用完整差频QTF计算的二阶差频项将被纳入波浪运动学。当**WvSumQTF**设置为TRUE时，使用完整和频QTF计算的二阶和频项将被纳入波浪运动学。完整的差频和和频波浪运动学QTF是根据[Sharma and Dean, 1981]解析实现的，该文献将Stokes二阶理论扩展到不规则多向波。设置为FALSE则忽略切片理论解中波浪运动学的二阶贡献。

**WvLowCOffD**和**WvHiCOffD**控制二阶差频项的下限和上限截止频率（单位：rad/s）；二阶差频项分别在这些截止频率以下和以上被置零。这些截止直接适用于物理差频，而不是导致差频的两个独立一阶频率分量。在HydroDyn中启用二阶势流载荷时，建议将**WvLowCOffD**设置为0，以避免消除平均漂移项（二阶波浪运动学没有非零均值）。**WvHiCOffD**不需要设置得高于一阶波浪谱的谱峰频率（*ω*\ :sub:`p` = 2*π*/**WaveTp**），以最小化计算成本。

同样，**WvLowCOffS**和**WvHiCOffS**控制二阶和频项的下限和上限截止频率（单位：rad/s）；二阶和频项分别在这些截止频率以下和以上被置零。这些截止直接适用于物理和频，而不是导致和频的两个独立一阶频率分量。**WvLowCOffS**不需要设置得低于一阶波浪谱的谱峰频率（*ω*\ :sub:`p` = 2*π*/**WaveTp**），以最小化计算成本。设置适当的上限截止频率（**WvHiCOffS**）也可以最小化计算成本，并且对于（1）确保二阶求和的收敛性，（2）避免波谷中出现非物理的"凸起"，（3）在接近破碎波极限时防止非物理效应，以及（4）在使用切片理论解时避免高频（即短波长）下的非物理波浪力非常重要。

由于二阶项是使用一阶波浪分量幅值计算的，因此二阶截止频率（**WvLowCOffD**、**WvHiCOffD**、**WvLowCOffS**和**WvHiCOffS**）与波浪部分的一阶截止频率（**WvLowCOff**和**WvHiCOff**）结合使用。但是，二阶差频势流载荷的Newman近似不使用二阶截止频率，这些载荷仅由一阶效应推导得到。

约束波浪
----------------
**约束波浪**部分允许用户按照Taylor、Jonathan和Harland（1997）的约束NewWave方法，在JONSWAP随机波浪（**WaveMod** = 2）中规定并嵌入大的波峰。

**ConstWaveMod**可以设置为0表示无嵌入波，1表示嵌入波具有从SWL开始的规定波峰高程，2表示嵌入波具有规定的峰到谷波高。

**CrestHmax**（单位：m）：如果**ConstWaveMod** = 1，则为从SWL开始的波峰高程的两倍；如果**ConstWaveMod** = 2，则为峰到谷波高。**CrestHmax**必须大于**WaveHs**。

**CrestTime**是用户规定的波峰出现的时间（单位：秒），从仿真开始时计算。

**CrestXi**是嵌入波峰在全局参考系中的*X*位置（单位：米）。

**CrestYi**是嵌入波峰在全局参考系中的*Y*位置（单位：米）。

约束波浪仅与**WaveMod** = 2（JONSWAP波浪谱）兼容。如果**WaveMod**设置为其他值，输入文件的此部分将被忽略。

在没有二阶波浪分量的情况下，波峰高程或波高将与用户输入的**CrestHmax**完全匹配。如果通过将**WvDiffQTF**或**WvSumQTF**设置为TRUE来包含二阶波浪分量，则得到的波峰高程或波高可能会偏离**CrestHmax**。

水流
-------
通过将**CurrMod**设置为1，可以包含水流模型引起的水流速度。如果**CurrMod**设置为零，则仿真将不包含水流。**CurrMod** = 2要求用户实现*Current.f90*源文件中的*UserCurrent()*子例程，并且需要重新编译独立SeaState程序或OpenFAST。水流通过HydroDyn中切片理论构件的粘性阻力项（分布和集中）产生稳态水动力载荷。势流解中或**WaveMod** = 6时不使用水流。

SeaState的标准水流模型包含三个子模型：近表面、次表面和深度无关，如:numref:`sea-fig:current_sub_model`所示。所有三个水流与波浪粒子运动学速度进行矢量求和。

.. figure:: figs/current_sub_models.jpg
  :align: center
  :name: sea-fig:current_sub_model

  标准水流子模型

次表面水流模型遵循幂律，

.. math::
  :label: SubsurfacePowerLaw

  U_{SS}(Z) = U_{0_{SS}} \left( \frac{Z+d}{d} \right)^{ \frac{1}{7} }

其中:math:`Z`是SWL以下的局部深度（向下为负），:math:`d`是水深（等于**WtrDpth** + **MSL2SWL**），:math:`U_{0_{SS}}`是SWL处的水流速度，对应**CurrSSV0**。次表面水流的方向使用**CurrSSDir**定义，遵循与**WaveDir**相同的约定。

近表面水流模型遵循线性关系，直至参考深度，即：

.. math::
  :label: NearsurfacePowerLaw

  U_{NS}(Z) = U_{0_{NS}} \left( \frac{Z+h_{ref}}{h_{ref}} \right), Z\in[-h_{ref},0]

在其他深度处：

.. math::
  :label: NearsurfaceDeep

  U_{NS}(Z) = 0

其中:math:`h_{ref}`是参考深度，对应**CurrNSRef**，必须为正值。:math:`U_{0_{NS}}`是SWL处的水流速度，对应**CurrNSV0**。近表面水流的方向使用**CurrNSDir**定义，遵循与**WaveDir**相同的约定。

深度无关水流速度在所有位置都等于**CurrDIV**。该水流的方向为**CurrDIDir**，遵循与**WaveDir**相同的约定。

MacCamy-Fuchs衍射模型
-------------------------------
HydroDyn现在支持切片理论构件的MacCamy-Fuchs波浪衍射解。当波长与构件直径相当或更小时，此选项会衰减切片理论波浪激励，从而在更高频率下提供更真实的载荷。为了限制内存使用，当前OpenFAST实现要求HydroDyn中使用MacCamy-Fuchs衍射解的所有切片理论构件的直径在此处给出的参考直径**MCFD**的+/-10%范围内。如果HydroDyn中不使用MacCamy-Fuchs衍射解，请将**MCFD**设置为小于或等于零的数，以减少内存使用和SeaState初始化时间。

输出通道
---------------
本节控制SeaState生成的输出量。输入一行或多行包含引号的字符串，其中包含一个或多个输出参数名称。输出参数名称可以通过逗号、分号、空格和/或制表符的任意组合分隔。如果在参数名称前加上减号"-"、下划线"_"或字符"m"或"M"，SeaState会在写入数据前将该通道的值乘以-1。参数不一定按输入文件中列出的顺序写入。SeaState允许使用多行，以便您可以将列表分成有意义的组，并使行更短。您可以在任何行的右引号后输入注释。如果行首或行首的带引号字符串开头包含字符串"END"，将导致SeaState停止扫描更多通道名称行。
如果SeaState遇到未知/无效的通道名称，会向用户发出警告，但会从输出文件中移除可疑通道。请参阅附录C获取可能输出参数的完整列表。

您可以生成最多9个波浪高程输出。**NWaveElev**确定数量（0到9之间），**WaveElevxi**和**WaveElevyi**的空格分隔列表确定这**NWaveElev**个点在全局惯性坐标系中的位置。

您还可以指定最多9个空间位置来输出波浪运动学（流体速度和加速度）和动压力。**NWaveKin**确定数量（0到9之间），**WaveKinxi**、**WaveKinyi**和**WaveKinzi**的空格分隔列表确定这**NWaveKin**个点在全局惯性坐标系中的位置。如果选择了波浪拉伸模型之一，其效果将反映在波浪运动学和动压力输出中。例如，SWL以下的点如果由于波谷而暂时露出水面，其所有输出将为零。同样，SWL以上的点如果由于波峰而暂时在水中，将根据所选的波浪拉伸模型输出波浪运动学和动压力。任何露出水面的点在重新进入水中之前，所有波浪运动学和动压力输出都将为零。
