
.. _bd-output-files:

输出文件
========

根据选择的选项，BeamDyn 会生成三种类型的输出文件：回显文件、摘要文件和时间序列结果文件。以下部分详细说明这些文件的用途和内容。

回显文件
--------

如果用户在 BeamDyn 主输入文件中将 ``Echo`` 标志设置为 TRUE，该文件的内容将被回显到命名为 ``InputFile.ech`` 的文件中。回显文件有助于调试输入文件。如果 BeamDyn 在解析输入文件时遇到错误，回显文件的内容将被截断。错误通常对应于最后成功回显行的下一行。

.. _sum-file:

摘要文件
--------

在独立模式下，如果 ``SumPrint`` 参数设置为 TRUE，BeamDyn 会生成命名为 ``InputFile.sum`` 的摘要文件。当耦合到 FAST 时，摘要文件命名为 ``InputFile.BD.R*.B*.sum.yaml``。此文件总结了仿真的关键信息，包括：

- 叶片质量。
- 叶片长度。
- 叶片质心。
- BD 坐标系中的初始全局位置矢量。
- BD 坐标系中的初始全局旋转张量。
- 分析类型。
- 数值阻尼系数。
- 时间步长。
- Newton-Raphson 求解中的最大迭代次数。
- 停止准则中的收敛参数。
- Newton-Raphson 求解中的分解频率。
- 数值积分（求积）方法。
- 梯形求积中使用的有限元网格细化因子。
- 单元数量。
- 有限元节点数量。
- BD 坐标系中有限元节点的初始位置矢量。
- BD 坐标系中有限元节点的初始旋转矢量。
- BD 坐标系中求积点位置矢量。对于高斯求积，列出高斯点的物理坐标。对于梯形求积，列出求积点的物理坐标。
- 局部叶片参考坐标系中求积点处的截面刚度和质量矩阵。这些是在求积点计算中使用的数据，可能与叶片输入文件中的截面不同，因为 BeamDyn 会根据需要将截面特性线性插值到求积点。
- BD 坐标系中有限元节点的初始位移矢量。
- BD 坐标系中有限元节点的初始旋转位移矢量。
- BD 坐标系中有限元节点的初始平移速度矢量。
- BD 坐标系中有限元节点的初始角速度矢量。
- 请求的输出信息。

所有这些量都在 BD 坐标系（BeamDyn 内部计算使用的坐标系）中输出。遵循 IEC 标准的初始叶片参考坐标系（由下标 :math:`r0` 表示）与内部 BD 坐标系的关系在 :numref:`beamdyn-theory` 中的 :numref:`IECBD` 中说明。

结果文件
--------

当 BeamDyn 在独立模式下运行时，BeamDyn 时间序列结果会写入文本文件，命名为 ``DriverInputFile.out``，其中 ``DriverInputFile`` 是驱动输入文件的名称。如果 BeamDyn 耦合到 FAST，则 FAST 将生成包含 BeamDyn 结果的主结果文件。``DriverInputFile.out`` 中的结果采用表格格式，其中每列是一个数据通道（第一列始终是仿真时间），每行对应一个仿真时间步。数据通道在主输入文件的 OUTPUT 部分指定。BeamDyn 生成的文件的列格式使用主输入文件的 ``OutFmt`` 参数指定。
