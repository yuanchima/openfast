
BeamDyn 用户指南和理论手册
===========================

本文档为 BeamDyn 软件程序提供快速参考指南。它旨在供普通用户与其他 OpenFAST 手册结合使用。随着新版本的发布，本手册将根据需要更新，以提供有关软件改进或修改的更多信息。作为参考，其他材料如演示幻灯片、开发计划和出版物可以从下面的列表中下载。

- :download:`基于截面梁特性的 BeamDyn 输入 <../../../OtherSupporting/BeamDyn/beamdyn_inputs_sectional_props.pdf>`

作者感谢美国能源部风能和水电计划以及落基山国家实验室（NLR）通过"风力机结构动力学高保真计算建模"项目提供的实验室自主研究与开发（LDRD）计划支持，本软件的开发得到了这些支持。
