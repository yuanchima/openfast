未来工作
========

以下是 BeamDyn 软件的未来工作列表：

- 消除单精度计算中的数值问题。
- 实现特征值分析功能。
- 改进独立版本的输入选项，使其更加用户友好。
- 实现基于模态方法的 GEBT，以提高计算效率。
- 增加更多叶片截面特性输入选项。例如，对于一般各向同性梁，将使用包括截面偏移、材料特性等工程参数来生成 BeamDyn 需要的 6×6 矩阵。
- 编写使用 BeamDyn 建模复合材料梁结构的通用指南，例如如何选择时间步长、如何选择模型离散化方式、如何定义叶片参考轴、从何处获取 6x6 质量/刚度矩阵等。
- 将在 FAST 中的应用扩展到风力机系统中的其他细长结构，例如塔筒、系泊缆和主轴。
- 开发仅包含旋转自由度（弯曲、扭转）的简化形式 GEBT，以提高计算效率。
