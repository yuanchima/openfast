
.. _hd-output:

输出文件
============
HydroDyn 生成三种类型的输出文件：回显文件、摘要文件和时间序列文件。以下各节详细说明这些文件的用途和内容。

回显文件
~~~~~~~~~~
如果在 HydroDyn 驱动文件或 HydroDyn 主输入文件中将 **Echo** 标志设置为 TRUE，这些文件的内容将回显到相应文件中，命名规则为：驱动输入文件的回显文件为 **OutRootName**\ *.dvr.ech*，HydroDyn 主输入文件的回显文件为 **OutRootName**\ *.HD.ech*。**OutRootName** 可以在驱动输入文件的 HYDRODYN 部分指定，或者由 OpenFAST 程序指定。回显文件有助于调试输入文件。如果 HydroDyn 在解析输入文件时遇到错误，回显文件的内容将被截断。错误通常对应于最后一次成功回显行的下一行。

.. _hd-summary-file:

摘要文件
~~~~~~~~~~~~
如果将 **HDSum** 参数设置为 TRUE，HydroDyn 将生成一个命名规则为 **OutRootName**\ *.HD.sum* 的摘要文件。该文件汇总了水动力学模型的关键信息，包括浮力、子结构体积、海洋生物附着重量、仿真网格及其属性，以及势流物体的辐射核。

当文中提到索引时，它指的是表格中的指定行。索引从 1 开始，沿行向下连续递增。

WAMIT 模型体积和浮力信息
-------------------------------------------
本节汇总了每个势流物体在未位移位置的浮力。对于混合势流/切片理论模型，这些浮力值必须与后续章节中报告的切片理论构件浮力相加，才能得到平台的总浮力。

切片理论体积计算
--------------------------------
本节汇总了所有切片理论构件在未位移位置的总体积、淹没体积、海洋生物附着体积和充液（进水/压载）体积。除充液体积值外，报告的体积仅适用于 **PropPot** 标志设置为 FALSE 的构件。进水/压载体积适用于任何充液构件，与其 **PropPot** 标志无关。

总浮力载荷
-------------------------
本节详细说明未位移子结构的浮力载荷（相对于 (0,0,0) 求和）。外部浮力包含海洋生物附着的影响，仅适用于 **PropPot** 标志设置为 FALSE 的构件。内部浮力是由于进水或压载对浮力产生的负向影响，与 **PropPot** 标志无关。

总海洋生物附着重量
--------------------------------
本节详细说明未位移子结构的海洋生物附着重量载荷（相对于 (0,0,0) 求和）。

切片理论节点表
-----------------------
该表详细列出了所有用户定义的节点和 HydroDyn 生成的内部分析节点的未位移切片理论节点信息和属性。内部节点是通过沿输入构件长度方向拆分构件生成的，以满足主输入文件构件表中 **MDivSize** 参数的要求。第一列提供节点索引。第二列提供每个内部节点所属的输入构件索引（不要与 **MemberID** 混淆）。用户定义的节点不一定属于特定构件，因此这些节点在该列中没有信息。**Nxi**、**Nyi** 和 **Nzi** 提供全局惯性坐标系下的 (*X*, *Y*, *Z*) 坐标。**R** 是节点处构件的外半径（不含海洋生物附着），**t** 是节点处构件的壁厚。**tMG** 是海洋生物附着厚度，**MGDens** 是海洋生物附着密度。**PropPot** 指示连接到该节点的单元是否采用势流理论建模。如果 **FilledFlag** 为 TRUE，则 **FillMass** 给出分配给该节点的充液质量。**Cd**、**Ca**、**Cp**、**Cb**、**AxCd**、**AxCa**、**AxCp**、**JAxCd**、**JAxCa** 和 **JAxCp** 分别是横向阻力、横向附加质量、横向动压力、浮力缩放、轴向阻力、轴向附加质量、轴向动压力、端板轴向阻力、端板轴向附加质量和端板轴向动压力系数。请注意，某些列仅针对用户定义的节点填充，而其他列仅针对属于单个构件的内部分析节点填充。

切片理论构件表
-------------------------
本节详细列出了未位移切片理论构件及其相关属性。列标题中的后缀 1 或 2 分别指构件的起始或结束节点。第一列是构件索引。**joint1** 和 **joint2** 指上一节节点表中的节点索引。接下来是构件 **Length**（长度）、满足 **MDivSize** 要求的细分单元数 **NElem**，以及外部 **Volume**（体积）。该外部体积计算包含构件上的任何海洋生物附着体积。**MGVolume** 提供海洋生物附着带来的体积贡献。对于采用势流建模的构件，即 **PropPot** = T（TRUE），**Volume** 和 **MGVolume** 将为零。每个节点的外半径（含海洋生物附着）和壁厚的截面属性分别由 **R1**、**t1**、**R2** 和 **t2** 给出。**PropPot** 指示构件是否采用势流理论建模。如果单元是充液的（有进水或压载），则 **FilledFlag** 设置为 T（TRUE）。**FillDensity** 和 **FillFSLoc** 是充液流体密度和自由液面位置（全局惯性坐标系下的 *Z* 坐标）。**FillMass** 是通过将 **FillDensity** 值乘以单元内部体积计算得到的。最后列出了两个端节点处的水动力系数。这些系数与上面节点表中列出的系数相同。

用户请求输出汇总
---------------------------------
摘要文件包含所有请求的构件和节点输出通道的信息。

构件输出
++++++++++++++
第一列列出数据通道的字符串标签，与 HydroDyn 输入文件的“输出通道”部分输入的内容一致。**Xi**、**Yi** 和 **Zi** 提供结构未位移时输出位置在全局惯性坐标系下的坐标。下一列 **MemberID** 给出相应的输入构件索引。接下来是包含该输出位置的构件的起始节点（**StartXi**、**StartYi**、**StartZi**）和结束节点（**EndXi**、**EndYi**、**EndZi**）的坐标。**Loc** 是距该构件起始节点的归一化距离。

节点输出
+++++++++++++
第一列列出数据通道的字符串标签，与 HydroDyn 输入文件的“输出通道”部分输入的内容一致。**Xi**、**Yi** 和 **Zi** 提供结构未位移时输出节点在全局惯性坐标系下的坐标。**InpJointID** 指定 HydroDyn 输入文件的“构件节点”表中给出的输出 **JointID**。

辐射记忆效应卷积核
------------------------------------------
在基于频域到时域变换的势流求解中，HydroDyn 通过对辐射问题得到的与频率相关的水动力阻尼矩阵进行余弦变换，计算卷积法用于计算辐射记忆效应的辐射核。本节提供生成的时域辐射核（辐射脉冲响应函数），它是一个与时间相关的矩阵。**n** 和 **t** 给出时间步索引和时间，后面是与该时间相关的辐射核矩阵的条目（**K11**、**K12** 等）。由于与频率相关的水动力阻尼矩阵是对称的，辐射核也是对称的；因此，仅提供矩阵的对角线和上三角部分。辐射核应在短时间内衰减到零，这有助于选择合适的 **RdtnTMax** 值。辐射核矩阵的维度取决于 HydroDyn 主输入文件中存在的势流物体数量（**NBody**）和 **NBodyMod**。如果 **NBodyMod** = 1（完全水动力耦合），摘要文件将包含单个 6**NBody** × 6**NBody** 矩阵的数据。如果 **NBodyMod** > 1（无水动力耦合），摘要文件将包含 **NBody** 个 6×6 辐射核矩阵的数据。

结果文件
~~~~~~~~~~~~
当 **OutSwtch** 设置为 1 或 3 时，HydroDyn 时间序列结果将写入命名规则为 ``OutRootName.HD.out`` 的文本文件。如果 HydroDyn 与 OpenFAST 耦合且 **OutSwtch** 设置为 2 或 3，则 OpenFAST 将生成包含 HydroDyn 结果的主结果文件。结果采用表格格式，其中每列是一个数据通道（第一列始终是仿真时间），每行对应一个仿真输出时间步。数据通道在 HydroDyn 主输入文件的“输出通道”部分指定。HydroDyn 生成文件的列格式使用主输入文件的 **OutFmt** 和 **OutSFmt** 参数指定。
