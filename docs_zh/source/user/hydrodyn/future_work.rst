
未来工作
===========
此列表包含可能在未来版本中实现的功能：

*  在独立版 HydroDyn 中启用 Morison 构件的时间序列输入运动（**MorisonInputsMod** = 2）

*  启用与 FAST 的紧耦合，包括线性化。

*  启用对浮式平台力标志的完全支持。

*  启用节点重叠计算（**JointOvrlp** = 1）。

*  启用所有可能输出通道的自动生成（**OutAll** = TRUE）。

*  添加与构件沿线节点和节点处施加的总水动力载荷相关的输出。

*  确保输出通道按照输入的顺序写入。

*  允许 **RdtnDT** 独立于 FAST 仿真时间步长。

*  为填充流体的构件和海洋生物生长添加转动惯量项。

*  添加对流流体加速度项。

*  允许波浪方向扩展包含随方向变化的能谱（需要从等能量方法更改）。

*  为固定式基础子结构添加更高阶的规则波浪运动学模型。

*  为固定式基础子结构添加破碎波浪冲击载荷。

*  为浮式平台添加压力映射。

*  添加切片理论构件静水恢复矩阵的自动计算和使用。
