
输入文件
========

用户通过 HydroDyn 主输入文件配置水动力模型参数以及子结构几何和属性。在独立模式下使用时，还需要额外的驱动输入文件。该驱动文件指定通常由 OpenFAST 提供给 HydroDyn 的初始化输入，以及每个时间步的输入。

不得在输入文件中添加或删除行，除非是指定了行数的表格。

单位
~~~~~
HydroDyn 使用国际单位制（kg、m、s、N）。

.. _hd-driver-input:

HydroDyn 驱动输入文件
~~~~~~~~~~~~~~~~~~~~~~~~~~
驱动输入文件仅适用于独立版本的 HydroDyn，包含通常由 OpenFAST 生成的输入，是控制非耦合模型水动力仿真的必要条件。附录 B 提供了 HydroDyn 驱动输入文件的示例。

如果希望 ``HydroDynDriver`` 回显驱动输入文件的内容（有助于调试驱动文件中的错误），请将该文件中的 **Echo** 标志设置为 TRUE。回显文件的命名规则为 ``OutRootName.dvr.ech``。**OutRootName** 在驱动输入文件的 HYDRODYN 部分指定。使用 **Gravity** 参数设置重力常数。HydroDyn 需要其数值大小，因此在国际单位制中应设置为 9.80665 :math:`\frac{m}{s^{2}}`。**WtrDens** 指定水的密度，必须大于或等于零；海水的典型值约为 1025 kg/m\ :sup:`3`。**WtrDpth** 指定基于平均海平面（MSL）的水深（平坦海床的深度），必须大于零。**MSL2SWL** 是平均海平面（MSL）和静水位（SWL）之间的偏移量，向上为正。该参数在模拟潮汐或风暴潮海平面变化的影响时非常有用，无需更改子结构几何信息。当 **WaveMod** = 6 时不使用该参数，如果使用势流模型（**PotMod** = 1 或 2），则必须将其设置为零。**WaveMod** 和 **PotMod** 在 HydroDyn 主输入文件中指定。

**HDInputFile** 是 HydroDyn 主输入文件的文件名。该名称应使用引号括起来，可以包含绝对路径或相对路径。请注意，独立 HydroDyn 程序和作为 OpenFAST 一部分的 HydroDyn 都必须依赖 SeaState 才能运行。因此，除了 HydroDyn 主输入文件外，还必须通过 **SeaStateInputFile** 提供 SeaState 输入文件的路径。

所有 HydroDyn 生成的输出文件都将以 **OutRootName** 为前缀。如果该参数包含文件路径，输出将生成在该文件夹中。**Linearize** 可以设置为 TRUE 或 FALSE。如果为 TRUE，将计算线性化的 6×6 刚度、阻尼和附加质量矩阵，并打印到调用终端。**NSteps** 指定仿真时间步的数量，**TimeInterval** 指定步长。

结构的运动可以根据 **PRPInputsMod** 以不同方式指定。无论选择哪种 **PRPInputsMod**（下文将解释），平移位移、速度和加速度始终在全局惯性坐标系中指定。由于 OpenFAST 现已更新以支持平台可能的大旋转，旋转的指定方式与以前版本不同。HydroDyn 现在使用 Tait-Bryan 滚转、俯仰和偏航角描述物体旋转，遵循内旋（绕体固轴）约定，顺序为先偏航，再俯仰，最后滚转。此外，HydroDyn 现在需要 Tait-Bryan 滚转、俯仰和偏航角的一阶和二阶时间导数，而不是角速度和角加速度。独立 HydroDyn 驱动程序将在内部将这些输入转换为角速度和角加速度。

**NAddDOF** 表示势流物体包含的附加自由度数量。这些附加模式可用于描述柔性或铰接体。**NAddDOF** > 0 仅允许单个势流物体，并且驱动输入文件中的 **NAddDOF** 值必须与 HydroDyn 主输入文件中的值匹配。如果包含多个势流物体，驱动输入文件中的 **NAddDOF** 应为单个零。这与 HydroDyn 主输入文件不同，在主输入文件中 **NAddDOF** 应包含 **NBody** 个零。详见下文 HydroDyn 主输入文件的说明。请注意，**NAddDOF** > 0 的广义模式仍属于实验性功能。

将 **PRPInputsMod** 设置为 0 会强制所有平台参考点（PRP）的输入运动在所有时间都为零。如果将 **PRPInputsMod** 设置为 1，则必须在文件的“PRP 稳态输入”部分设置稳态输入。将 **PRPInputsMod** 设置为 2 需要通过 **PRPInputsFile** 参数指定时间序列输入文件的名称。PRP 输入文件是文本格式文件，没有标题行。每个数据行对应一个时间步，由空格分隔的浮点数列代表所需的运动输入，如 :numref:`hd-prp_input_table` 所示。

HydroDyn 主输入文件
~~~~~~~~~~~~~~~~~~~~~~~~~~~
HydroDyn 输入文件定义了子结构几何、水动力系数、入射波浪运动学和海流、势流求解选项、进水/压载和海洋生物附着，以及辅助参数。切片理论构件的几何由未位移子结构在全局参考系中的节点坐标定义，原点位于未变形塔筒中心线与平均海平面（MSL）的交点。一个构件连接两个节点；多个构件可以共用同一个节点。水动力载荷在节点处计算，节点是将构件细分为多个（**MDivSize** 输入参数）单元后的结果（节点位于每个单元的端点），由模块自动计算。构件属性包括外径、厚度，以及动压力、附加质量和粘性阻力系数。构件属性在节点处指定；如果两个节点之间的属性发生变化，将对内部节点进行线性插值。

该文件分为多个功能部分。每个部分对应水动力模型或水下子结构的一个方面。:ref:`hd-primary-input-example` 提供了 HydroDyn 主输入文件的示例。

如果本手册提到表项中的 ID，这是该表项的整数标识符，这些 ID 不需要连续或递增，但对于给定的表项必须唯一。

输入文件开头有两行供用户使用的标题信息，但软件不会使用这些信息。在接下来的一行中，如果希望 HydroDyn 回显 HydroDyn 输入文件的内容（有助于调试输入文件中的错误），请将 **Echo** 标志设置为 TRUE。回显文件的命名规则为 **OutRootName**\ *.HD.ech*。**OutRootName** 在独立运行 HydroDyn 时由驱动输入文件的 HYDRODYN 部分指定，在运行耦合仿真时由 OpenFAST 程序指定。


浮式平台
-----------------

输入文件的本节和接下来几节的标题中都包含“浮式平台”，但这些输入参数控制势流模型，无论子结构是否为浮式。势流求解不能与非零的 **MSL2SWL** 或 SeaState 中的 **WaveMod** = 6 同时使用。

如果要包含势流理论的载荷贡献，请将 **PotMod** 设置为 1 以使用基于 WAMIT 输出的频域到时域变换，或设置为 2 以使用 FIT（FIT 尚未在本手册中说明）。本节中的其余参数仅在 **PotMod** = 1 时使用。

**ExctnMod** 可以设置为 0（无波浪激励）、1（使用离散傅里叶变换的频域到时域波浪激励）或 2（状态空间波浪激励模型）。根据 **ExctnMod** 的选择，必须通过 **PotFile** 输入提供合适的水动力输入文件。详见下文。

**ExctnDisp** 指定在评估势流波浪激励时是否以及如何考虑水平面内的结构位移。将 **ExctnDisp** 设置为 0 会忽略结构位移，波浪激励将使用未位移的结构位置计算，与 OpenFAST 以前版本相同。如果 **ExctnDisp** = 1，HydroDyn 将使用水平面内未滤波的瞬时 PRP 位置计算势流波浪激励。如果 **ExctnDisp** = 2，HydroDyn 将基于水平面内低通滤波后的 PRP 位置计算波浪激励。截止频率通过 **ExctnCutOff** 指定，单位为 Hz。此选项在启用二阶势流波浪激励时非常有用。截止频率的设置应尽可能滤除 PRP 的波浪频率运动，同时保留低频漂移运动，以防止重复计算已包含在二阶势流波浪激励中的一阶结构运动贡献。

HydroDyn 现在支持纯切片理论模型和混合势流模型下平台的大而慢（远低于波浪频率）的瞬态偏航运动。要启用此功能，必须正确设置输入参数 **PtfmYMod**、**PtfmRefY**、**PtfmYCutoff** 和 **NExctnHdg**。请注意，HydroDyn 仍要求平台滚转和俯仰角较小，即在 ±15 度范围内。

为了符合一阶和二阶势流理论（该理论限制结构在参考平均位置附近做小位移运动），必须建立恒定或缓慢变化的平台偏航参考方向。

将 **PtfmYMod** 设置为 0 时，HydroDyn 使用 **PtfmRefY** 给出的恒定参考偏航角，单位为度。在这种情况下，仿真期间平台的偏航旋转（由 **PRPYaw** 输出通道给出）必须保持在用户指定的 **PtfmRefY** 的 ±15 度范围内。如果在仿真过程中的任何时刻不满足此要求，将显示严重警告，但仍允许仿真在可能的情况下继续。对于混合势流模型，势流波浪激励输入文件需要覆盖应用 **PtfmRefY** 偏航偏移后相对于平台的合适波向范围。

或者，将 **PtfmYMod** 设置为 1 时，HydroDyn 可以基于低通滤波后的平台偏航旋转动态更新参考偏航位置 **PtfmRefY**，类似于上文 **ExctnDisp** = 2 时的慢漂运动建模。在这种情况下，**PtfmRefY** 输入允许用户指定 **t** = 0 时的初始参考偏航位置。平台偏航旋转的一阶低通滤波器截止频率可以通过 **PtfmYCutoff** 设置，单位为 Hz。理想情况下，**PtfmYCutoff** 应设置在波浪频率区域和平台航向任何缓慢但大幅变化的特征频率之间，以尽可能滤除平台的波浪频率运动，同时最小化低频航向变化的相位偏移。在整个仿真过程中，瞬时平台偏航旋转应保持在随时间变化的 **PtfmRefY** 的 ±15 度范围内。如果在仿真过程中的任何时刻不满足此要求，将显示严重警告，但仍允许仿真在可能的情况下继续。

当 **PtfmYMod** = 1 时，HydroDyn 要求一阶和二阶（仅来自 Newman 近似的平均或慢漂载荷）势流波浪激励输入文件覆盖所有可能的波向范围，第一个（最小）波向恰好为 -180 度，最后一个（最大）波向恰好为 +180 度（±180 度的重复波向是有意设置的）。如果输入文件不满足此要求，HydroDyn 将报错退出。HydroDyn 使用此信息为 [-180, +180) 度范围内均匀分布的 **NExctnHdg** 个平台偏航/航向角预计算平台上的波浪激励。例如，当 **NExctnHdg** = 36 时，HydroDyn 将为 0、10、20、…、350 度的平台航向预计算波浪激励。时域仿真期间施加在平台上的瞬时波浪激励是基于瞬时 **PtfmRefY** 从该数据中插值得到的。应适当设置 **NExctnHdg** 以确保平台航向有足够的角分辨率。但是，较高的 **NExctnHdg** 会大幅增加 OpenFAST 的内存使用。

当 **PtfmYMod** = 1 时，HydroDyn 输入还有其他约束。必须通过设置 **WaveDisp** = 1，使用位移后结构位置处的波浪运动学和动压力来评估切片理论水动力载荷。不能使用状态空间波浪激励。**ExctnMod** 必须为 0（无波浪激励）或 1（使用离散傅里叶逆变换的频域到时域变换）。最后，不支持完整的差频和和频 QTF，要求 **DiffQTF** 和 **SumQTF** 都设置为 0。但是，基于 Newman 近似的平均或慢漂载荷可以通过下文说明的 **MnDrift** 或 **NewmanApp** 输入包含在内。

请注意，输入参数 **PtfmYMod** 和 **PtfmRefY** 也会影响切片理论水动力载荷。这是因为切片理论构件的方向是基于 **PtfmRefY** 而不是瞬时平台偏航旋转更新的。将 **PtfmYMod** 设置为 0 并将 **PtfmRefY** 设置为 0 度，可以近似恢复 HydroDyn 以前版本的行为，在这种情况下，不会使用输入参数 **PtfmYCutoff** 和 **NExctnHdg**。

HydroDyn 有两种计算辐射记忆效应的方法。将 **RdtnMod** 设置为 1 使用卷积方法，设置为 2 使用线性状态空间模型，设置为 0 禁用记忆效应计算。对于卷积方法，**RdtnTMax** 确定跟踪记忆效应的时长（在 *t* – **RdtnTMax** 处截断卷积，其中 *t* 是当前仿真时间），但它也确定余弦变换中使用的频率步长，时域辐射核（辐射脉冲响应函数）就是从余弦变换导出的。通常 60 秒的 **RdtnTMax** 已经足够，因为辐射核会在短时间内衰减到零；将 **RdtnTMax** 设置得远大于此值会导致 HydroDyn 运行速度显著变慢。（**RdtnTMax** 不需要匹配或超过总仿真时长。）将 **RdtnTMax** 设置为 0 秒会禁用记忆效应，类似于将 **RdtnMod** 设置为 0。对于卷积方法，**RdtnDT** 是辐射计算（数值卷积）的时间步长，但也确定余弦变换中的最高频率。对于状态空间模型，**RdtnDT** 是线性状态空间模型时间积分的时间步长。在此版本的 HydroDyn 中，**RdtnDT** 必须与耦合代码（OpenFAST/驱动程序）的仿真时间步长匹配；可以使用 DEFAULT 关键字。根据 **RdtnMod** 的选择，必须通过 **PotFile** 输入提供合适的水动力输入文件。详见下文。

HydroDyn 支持包含多个势流物体。**NBody** 指定存在的势流物体数量。**NBodyMod** 控制如何对多个势流物体建模。如果 **NBodyMod** = 1，HydroDyn 将保留势流物体之间的完整水动力耦合。对于此选项，所有物体应在同一次 WAMIT 运行中计算，HydroDyn 中的 **NBody** 应等于 WAMIT 输入文件中的 NBODY。WAMIT 输出文件应包含 6·NBody 个模式的结果。如果 **NBodyMod** = 2 或 3，HydroDyn 将忽略势流物体之间的水动力耦合。在这两种情况下，都应分别对每个物体单独运行 WAMIT。如果 WAMIT 计算时每个物体的中心都在原点（WAMIT 中的 XBODY=0），则在 HydroDyn 中应使用 **NBodyMod** = 2。在这种情况下，HydroDyn 将处理 WAMIT 输出，以考虑每个势流物体相对于原点/PRP 的任何偏移引起的波相偏移。HydroDyn 还将根据 HydroDyn 中每个物体的航向旋转 WAMIT 输出。例如，当结构中存在多个相同的势流物体时，**NBodyMod** = 2 非常方便。如果可以忽略物体之间的水动力耦合，通过设置 **NBodyMod** = 2，每个物体可以使用同一组 WAMIT 输出文件。另一方面，如果通过在 WAMIT 输入文件中设置 XBODY，每个物体在 WAMIT 中已经相对于原点/PRP 正确定位和定向，则应使用 **NBodyMod** = 3。在这种情况下，HydroDyn 将直接使用提供的 WAMIT 输出。

**PotFile** 输入应包含用引号括起来的 WAMIT 输出文件的路径和根名称（不带扩展名）。这些文件包括 *.1*、*.3*、*.hst* 和二阶文件。*.hst* 文件包含静水恢复（刚度）矩阵。*.1* 文件包含波浪辐射问题中与频率相关的水动力附加质量和阻尼矩阵。*.3* 文件包含线性波浪衍射问题中与频率和方向相关的一阶波浪激励向量。这些文件由 WAMIT 程序生成，不应包含任何文件头。当使用线性状态空间模型代替频域到时域变换进行波浪激励计算，或代替卷积进行辐射计算时，波浪激励的 *.ssexctn* 文件（更多信息将在未来提供）和/或由 `SS_Fitting <https://www.nrel.gov/wind/nwtc/ss-fitting.html>`__ 生成的辐射 *.ss* 文件必须与其他 WAMIT 相关文件具有相同的根名称。

当 **NBodyMod** = 1 时，无论 **NBody** 是多少，**PotFile** 都应只包含一个条目，因为具有水动力耦合的所有物体的水动力系数都应包含在同一组文件中。当 **NBodyMod** = 2 或 3 时，**PotFile** 应包含 **NBody** 个条目，每个条目用引号括起来，并用逗号或空格分隔。**PotFile** 的每个条目对应一个单独的势流物体。

在本节的其余部分，无论 **NBodyMod** 是多少，每个输入都应包含 **NBody** 个条目，用逗号或空格分隔。

WAMIT 的输出文件采用标准无量纲形式，HydroDyn 在输入时会在内部将其转换为有量纲形式。**WAMITULEN** 是用于将 WAMIT 输出重新量纲化的特征物体长度，单位为 m。这些 WAMIT 文件中的物体运动和力/力矩始终在 WAMIT 输入文件中 XBODY 给定的物体局部参考系中解析。为了正确解释 WAMIT 输出，必须使用 **PtfmRefxt**、**PtfmRefyt**、**PtfmRefzt** 和 **PtfmRefztRot**（单位为 m 或度）指定每个势流物体相对于原点/PRP 的位置和航向。除了 **NBodyMod** = 2 的情况外，这些输入必须与 WAMIT 输入文件中的 XBODY 匹配。当 **NBodyMod** = 2 时，除了 **PtfmRefzt** 必须始终为零外，这些输入可以自由设置。

虽然 HydroDyn 期望使用 WAMIT 导出的水动力系数，但如果不使用 WAMIT，建议在输入到 HydroDyn 之前根据 WAMIT 格式（包括无量纲化）重新格式化数据。有关 WAMIT 格式的信息，请参见《WAMIT 用户指南》第 4 章 :cite:`LeeNewman:2006`。

**PtfmVol0** 是势流物体处于未位移位置时的排水体积，单位为 m\ :sup:`3`。该值应设置为与 WAMIT ``.out`` 文件中输出的 WAMIT 计算值相等。**PtfmCOBxt** 和 **PtfmCOByt** 是每个物体的浮心相对于原点/PRP 的 *X* 和 *Y* 偏移量，单位为 m，而不是相对于 **PtfmRefxt** 和 **PtfmRefyt** 的偏移量。

*实验性功能*

**NAddDOF** 是一个包含 **NBody** 个数字的数组，表示每个势流物体的附加广义自由度数量。这些附加模式可用于描述柔性或铰接体，并且必须与一阶 WAMIT 风格输入文件（即 .1、.3 和 .hst 文件）中的模式匹配。WAMIT 风格输入文件的约定要求前 6 个模式始终为刚体模式，附加广义模式从 7 开始编号。每个物体的一阶 WAMIT 风格输入文件中的总模式数应为 **6+NAddDOF**。目前，使用附加自由度时只允许一个势流物体，要求 **NBody = 1**。在这种情况下，**NBodyMod** 的选择无关紧要。如果存在多个势流物体，**NAddDOF** 应填充 **NBody** 个零。这是因为在内部，HydroDyn 支持任意数量的物体使用任何 **NBodyMod** 选项的附加自由度。仅允许一个势流物体的限制是由于与 ExtPtfm 耦合的约束（ExtPtfm 是目前唯一可以使用这些附加模式的模块）以及输入文件的限制。广义模式尚未针对二阶载荷实现；因此，二阶 WAMIT 风格输入文件（如果包含）应始终包含 **6NBody** 个模式，与 **NAddDOF** 无关。最后，当 **NAddDOF** > 0 时，**WAMITULEN** 必须为 1。

目前，附加自由度的 HydroDyn 载荷只能由 OpenFAST 的 ExtPtfm 模块使用，需要外部生成结构质量（M）、刚度（K）和阻尼（C）矩阵。此工作流仅适用于具有 6DOF 刚体运动和用户定义数量附加弹性模式的浮式结构。HydroDyn 和 ExtPtfm 中的模式数量必须匹配。更具体地说，ExtPtfm 中激活的模式数量必须等于 **6+NAddDOF**，且前 6 个模式也应为刚体模式。

二阶浮式平台力
-------------------------------------------
输入文件的“二阶浮式平台力”部分允许向势流求解中添加二阶贡献。当可选地启用二阶项时，二阶项使用一阶波分量振幅计算，并在差频和/或和频处添加到一阶波浪激励中。如果不包含上一节“浮式平台”中的一阶项（**PotMod** = 1），则无法计算二阶项。启用二阶项可以捕捉波浪载荷中的一些非线性特性，从而实现更精确的建模，但会增加计算量（主要是在 HydroDyn 初始化阶段）。

虽然 SeaState 模块的 :ref:`sea-2nd-order-waves-input` 部分中的截止频率同时适用于切片理论使用的二阶波浪运动学和势流理论中的二阶衍射载荷，但二阶项本身是单独启用的。切片理论使用的二阶波浪运动学在 :ref:`sea-2nd-order-waves-input` 部分启用，而势流理论中的二阶衍射载荷在本节启用。

二阶差频势流项可以通过三种方式之一启用。要仅计算平均漂移项，请将 **MnDrift** 设置为非零值；要仅基于一阶效应，使用 Standing 等人对 Newman 近似的扩展来估计平均和慢漂项，请将 **NewmanApp** 设置为非零值；或者要使用完整差频 QTF 计算平均和慢漂项，请将 **DiffQTF** 设置为非零值。**MnDrift** 的有效值为 0、7、8、9、10、11 或 12，对应于计算平均漂移项的 WAMIT 输出文件。**NewmanApp** 的有效值为 0、7、8、9、10、11 或 12，对应于计算 Newman 近似的 WAMIT 输出文件。Newman 近似不能与方向扩散同时使用（**WaveDirMod** 必须为 0），且二阶截止频率不适用于 Newman 近似。**DiffQTF** 的有效值为 0、10、11 或 12，对应于计算完整差频势流解的 WAMIT 输出文件。**MnDrift**、**NewmanApp** 和 **DiffQTF** 中只能有一个为非零值；设置为 0 时忽略势流解的二阶差频贡献。

WAMIT 的 *.7* 文件包含基于一阶解通过控制面积分方法导出的所有自由度的平均漂移载荷（差频 QTF 的对角线）。WAMIT 的 *.8* 文件包含基于一阶解通过动量守恒原理导出的仅浪向、横向和偏航方向的平均漂移载荷（差频 QTF 的对角线）。WAMIT 的 *.9* 文件包含基于一阶解通过压力积分方法导出的所有自由度的平均漂移载荷（差频 QTF 的对角线）。对于差频项，10、11 和 12 分别对应 WAMIT 的 *.10d*、*.11d* 和 *.12d* 文件，其中 *.10d* 是与一阶量二次相互作用相关的所有自由度载荷的完整 QTF，*.11d* 是通过间接方法导出的所有自由度的总载荷（二次项加二阶势），*.12d* 是通过直接方法导出的所有自由度的总载荷（二次项加二阶势）。

二阶和频势流项只能通过将 **SumQTF** 设置为非零值，使用完整和频 QTF 启用。**SumQTF** 的有效值为 0、10、11 或 12，对应于计算完整和频势流解的 WAMIT 输出文件；设置为 0 时忽略势流解的二阶和频贡献。对于和频项，10、11 和 12 分别对应 WAMIT 的 *.10s*、*.11s* 和 *.12s* 文件，其中 *.10s* 是与一阶量二次相互作用相关的所有 6 个自由度载荷的完整 QTF，*.11s* 是通过间接方法导出的所有自由度的总载荷（二次项加二阶势），*.12s* 是通过直接方法导出的所有自由度的总载荷（二次项加二阶势）。

请注意，上文“浮式平台”部分讨论的针对多势流物体运行 WAMIT 的各种注意事项同样适用于此处。

平台附加刚度和阻尼
-----------------------------------------
本节的向量和矩阵用于生成平台上的附加载荷（除了 HydroDyn 计算的其他水动力项之外），计算公式如下。

.. math::
  :标签: PtfmStiffDamp

  \overrightarrow{F}_{Add} = \overrightarrow{F}_{0} - [C] \overrightarrow{q} - [B] \dot{\overrightarrow{q}} - [B_{quad}] ABS \left(\dot{\overrightarrow{q}}\right) \dot{\overrightarrow{q}}

其中 :math:`\overrightarrow{F}_{0}` 对应 **AddF0** 静载荷（预载荷）向量，:math:`[C]` 对应 **AddCLin** 线性恢复（刚度）矩阵，:math:`[B]` 对应 **AddBLin** 线性阻尼矩阵，:math:`[B_{quad}]` 对应 **AddBQuad** 二次阻尼矩阵，:math:`\overrightarrow{q}` 对应势流物体的位移向量（平移和旋转），上加点表示一阶时间导数。

在没有附加自由度的情况下，即 **NAddDOF** 全为零，如果 **NBodyMod** = 1，**AddF0** 是一个包含 6·**NBody** 个条目的列向量；如果 **NBodyMod** = 2 或 3，**AddF0** 是 **NBody** 个列向量，每个包含 6 个条目。在前一种情况下，输入文件中的 **AddF0** 将占据 6·**NBody** 行，每行包含一个数字。在后一种情况下，输入文件中的 **AddF0** 将占据 6 行，每行包含 **NBody** 个数字。当包含附加自由度时，只允许一个势流物体，**AddF0** 应为一个占据 6 + **NAddDOF** 行的列向量。

在没有附加自由度的情况下，如果 **NBodyMod** = 1，**AddCLin**、**AddBLin** 和 **AddBQuad** 是单个 6·**NBody** × 6·**NBody** 矩阵；如果 **NBodyMod** = 2 或 3，它们是 6 个 6×6 矩阵。在前一种情况下，每个矩阵在输入文件中占据 6·**NBody** 行，每行包含 6·**NBody** 个数字。在后一种情况下，每个矩阵在输入文件中占据 6 行，每行包含 6·**NBody** 个数字。当包含附加自由度时，只允许一个势流物体，每个矩阵应占据 6 + **NAddDOF** 行，每行包含 6 + **NAddDOF** 个数字。

这些项可用于例如模拟线性化系泊系统、用线性静水恢复矩阵增强切片理论构件（参见 :numref:`hd-modeling-hydrostatic-restoring-strip-theory`），或者“校准”HydroDyn 以使阻尼与实验结果（如自由衰减试验）匹配。虽然这些矩阵可能对浮式系统最有用，但也可用于固定式基础系统；在这两种情况下，生成的载荷都施加在每个势流物体的参考点上，该参考点由 **PtfmRefxt**、**PtfmRefyt** 和 **PtfmRefzt** 给出。当势流物体包含附加广义自由度时，**AddF0** 可用于向广义模式施加恒定静水/浮力载荷。

切片理论选项
--------------------
**WaveDisp** 可以设置为 0，使用结构未位移位置处的波浪运动学和动压力计算切片理论载荷。如果设置为 1，将使用切片理论构件瞬时位移位置处的波浪运动学和动压力计算载荷。请注意，当不使用波浪拉伸时（SeaState 中的 **WaveStMod** = 0），当 **WaveDisp** = 1 时，仅考虑切片理论构件节点的 *X* 和 *Y* 位移，而忽略垂直 *Z* 位移。这样做是为了避免不连续的节点载荷，这些载荷可能导致 SubDyn 子结构模型出现非物理结构振动。当 **WaveStMod** > 0 且 **WaveDisp** = 1 时，计算波浪运动学时会考虑切片理论构件在所有三个方向上的位移。在这种情况下会执行载荷平滑程序以避免不连续的节点载荷。

**AMMod** 控制分布切片理论附加质量力的计算。如果 **AMMod** = 0，即使启用了波浪拉伸，切片理论附加质量力也始终计算到静水位（SWL），同时忽略切片理论构件节点的垂直位移。当 **AMMod** = 1 时，如果 **WaveStMod** > 0，切片理论附加质量力计算到瞬时自由表面。如果 **WaveDisp** = 1，还会考虑切片理论构件的垂直位移。只有当波浪拉伸导致 SubDyn 中建模的柔性固定式基础支撑结构出现数值不稳定时，才应将 **AMMod** 设置为 0。

**HstMod** 控制切片理论构件上分布静水载荷的计算。如果 **HstMod** = 0，即使启用了波浪拉伸，静水压力也始终在直至静水位（SWL）的瞬时湿表面积分。如果 **HstMod** = 1 且通过 **WaveStMod** > 0 选择了其中一种波浪拉伸模型，静水压力将积分到瞬时波浪自由表面，同时考虑波高和波斜率。如果不使用波浪拉伸，HydroDyn 内部将始终把 **HstMod** 设置为零，忽略用户输入。无论 **HstMod** 是多少，计算静水载荷时始终使用结构的精确位移位置，以获得正确的静水恢复效应。

轴向系数
-----------------
输入文件的本节和接下来几节控制固定式基础和浮式子结构的切片理论模型。

HydroDyn 在构件端部（节点）计算集中粘性阻力、附加质量、流体惯性和静压力载荷。节点处集中载荷的水动力系数称为“轴向系数”，包括粘性阻力系数 **AxCd**、附加质量系数 **AxCa** 和动压力系数 **AxCp**。**AxCa** 同时影响附加质量载荷和流体惯性载荷的散射分量。通过设置 **NAxCoef** > 1，可以指定任意数量的独立轴向系数集，由 **AxCoefID** 区分。

有三个可选输入会影响端板上的粘性阻力。它们是 **AxFdMod**、**AxVnCOff** 和 **AxFDLoFSc**。

**AxFdMod** 可以是 0 或 1。当设置为 0 时，端板上的阻力将按照 OpenFAST 以前版本的方式计算。当设置为 1 时，只有当相对流背离端板（预计会发生流动分离）时才会施加阻力，而当相对流冲击端板（不太可能发生流动分离）时不会施加阻力。选项 0 适用于纯切片理论构件，而选项 1 可能更适合带有阻力的混合势流构件。请注意，选项 0 在计算阻力时使用 1/4 的前置系数，而选项 1 使用更常见的 1/2 前置系数，因为阻力通常仅施加在构件两个端板中的一个上，而不是两个都施加。

**AxVnCOff** 是用于对计算端板阻力的相对法向流速进行高通滤波的截止频率，单位为 Hz。此输入参数应与加权因子 **AxFDLoFSc**（介于 0 和 1 之间）一起使用。当 **AxFDLoFSc** = 0 时，端板阻力完全基于高通滤波后的相对法向速度计算。当 **AxFDLoFSc** = 1 时，端板阻力完全基于未滤波的相对法向速度计算。添加此公式是为了允许用户衰减对低频运动的阻力响应。在某些情况下，这种方法可以帮助解决低频共振运动预测不足的问题。

用户可以选择省略所有三个可选输入。在这种情况下，HydroDyn 将按照 OpenFAST 以前版本的方式计算端板阻力。或者，用户可以仅包含可选参数 **AxFdMod**。在这种情况下不会应用速度滤波。最后，用户可以包含所有三个可选输入，以按照上述说明控制端板阻力的行为。

将为所有指定的构件节点计算轴向粘性阻力载荷。轴向附加质量、流体惯性和静压力载荷仅针对未采用势流建模的构件的节点计算（**PropPot** = FALSE）。轴向载荷仅在用户指定的节点处计算。在 HydroDyn 求解过程中自动创建的节点处不会计算轴向载荷。例如，如果希望在海洋生物附着边界（HydroDyn 会在此处自动添加节点）处考虑轴向效应，必须在该位置显式设置一个节点。

构件节点
-------------
切片理论模型基于由构件相互连接的节点组成的子结构。**NJoints** 是用户指定的节点数量，决定了后续表格的行数。因为一个构件连接两个节点，所以 **NJoints** 必须恰好为零或大于等于 2。表中列出的每个节点由唯一的整数 **JointID** 标识。每个节点的 (*X*,*Y*,*Z*) 坐标分别通过 **Jointxi**、**Jointyi** 和 **Jointzi** 在全局惯性坐标系中指定。**JointAxID** 对应于“轴向系数”表中的一个条目，用于设置节点的轴向系数。此版本的 HydroDyn 无法计算多个构件交汇于公共节点时的节点重叠；因此 **JointOvrlp** 必须设置为 0。未来版本将启用节点重叠计算。

对嵌入海床的固定式基础子结构（例如通过桩或吸力桶）建模时，要求最低的构件节点位于水深以下。将节点放置在水深或水深以上会导致施加静压力载荷。

构件截面
---------------------
HydroDyn 中的构件假定为直的，具有圆形截面或矩形截面。在这两种情况下都允许变锥，包括矩形截面构件两个边的独立变锥。但是，矩形构件不允许扭转，构件的四个侧壁必须保持平面。

HydroDyn 主输入文件包含两个独立的构件截面属性部分。第一部分用于圆形截面，第二部分用于矩形截面。

在标有“圆柱形构件截面属性”的第一部分中，可以输入 **NPropSetsCyl** 个不同的截面定义，每个截面定义占单独一行，由其 **PropSetID** 标识。**PropSetID** 用于下文 :numref:`hd-members` 所述的“构件”表中。对于每个截面定义，用户需要提供构件外径 **PropD** 和构件壁厚 **PropThck**。**PropD** 决定构件外部的静水浮力载荷，以及粘性阻力计算中使用的面积和附加质量与流体惯性载荷计算中使用的体积。**PropThck** 决定充液（进水/压载）构件的内部体积。

在标有“矩形构件截面属性”的第二部分中，可以输入 **NPropSetsRec** 个不同的截面定义，每个截面定义占单独一行，由其 **PropSetID** 标识。**PropSetID** 在下文 :numref:`hd-members` 所述的“构件”表中引用。对于每个截面定义，用户需要提供矩形截面的构件外边长。**PropA** 是 A 边的外长度，**PropB** 是 B 边的外长度（参见 :numref:`hd-members` 了解如何识别这两个边）。**PropThck** 同样是截面壁厚。目前，我们假定每个矩形截面的四个侧壁具有相同的均匀壁厚，因此每个矩形截面只能指定一个 **PropThck**。

请注意，圆形截面和矩形截面的 **PropSetID** 是独立的。例如，允许圆形截面和矩形截面具有相同的 **PropSetID**。HydroDyn 将根据为每个构件指定的截面形状查找正确的截面属性。

水动力系数
-------------------------
HydroDyn 计算沿构件的分布粘性阻力、附加质量、流体惯性和静水浮力载荷。

分布切片理论载荷的水动力系数可以使用三种可用模型中的任意一种指定，我们称之为简单模型（模型 1）、基于深度的模型（模型 2）和基于构件的模型（模型 3）。所有这些模型都需要指定粘性阻力、附加质量和动压力的横向和轴向水动力系数。附加质量系数同时影响附加质量载荷和流体惯性载荷的散射分量。有两套独立的水动力系数，一套用于构件有海洋生物附着的部分，另一套用于没有海洋生物附着的部分。哪些构件有海洋生物附着由 :numref:`hd-marine-growth` 的“海洋生物附着”表定义。对于“构件”表中的任何给定构件，只能指定一种模型类型（**MCoefMod** = 1、2 或 3）。但是，不同的构件可以使用不同的系数模型。

在水动力系数表中，**Cd**、**Ca** 和 **Cp** 分别表示粘性阻力系数、附加质量系数和动压力系数。对于圆形截面，由于轴对称性，这些系数适用于任何径向的载荷。对于矩形截面，必须提供两套横向 **Cd** 和 **Ca** 系数，一套附加字母“A”，用于垂直于截面 A 边的载荷分量（例如 **CdA**），另一套附加字母“B”，用于垂直于截面 B 边的载荷分量（例如 **CaB**）。请注意，只有横向 **Cd** 和 **Ca**（有和没有海洋生物附着）会区分矩形截面的两个横向方向。其他系数都不做这种区分。**MG** 标识应用于有海洋生物附着的构件截面的系数（标准值不带 **MG**），**Ax** 标识应用于变锥构件的轴向系数（横向系数不带 **Ax**）。**Cb** 系数允许用户缩放静水载荷，例如用于非圆形和非矩形构件截面。为了避免非物理静水载荷，**Cb** 系数不用于直接缩放分布静水载荷。相反，在计算静水载荷时，局部构件直径或边长（如果指定有海洋生物附着则包含其厚度）会乘以 **Cb** 的平方根。为了一致性，这种缩放也会影响构件端板上的静水载荷。虽然切片理论求解假定截面为圆形或矩形，但水动力系数可以包含形状修正。

对于三种可用系数模型中的每一种，都有两个独立的输入部分，第一部分用于圆形截面，第二部分用于矩形截面。这些将在下文说明。

MacCamy-Fuchs 衍射载荷模型
++++++++++++++++++++++++++++++++++++
对于使用上述三种系数模型中任意一种的切片理论构件，可以启用 MacCamy-Fuchs 衍射载荷模型。要启用 MacCamy-Fuchs 模型，所有横向 **Cp** 和 **CpMG** 系数应替换为关键字 **MCF**，而不是数值。对于简单模型，这包括 **SimplCp** 和 **SimplCpMG**。对于基于深度的模型，所有行的 **DpthCp** 和 **DpthCpMG** 都应使用关键字 **MCF**。最后，对于基于构件的模型，仅对于要使用 MacCamy-Fuchs 模型的构件，其 **MemberCp1**、**MemberCp2**、**MemberCpMG1** 和 **MemberCpMG2** 都应使用关键字 **MCF**。所有其他系数可以照常指定，包括附加质量系数。采用这种配置时，构件上的分布横向流体惯性力将直接遵循 MacCamy-Fuchs 衍射载荷，与用户设置的附加质量系数无关。在这种情况下，附加质量系数仅影响与结构加速度成比例的力分量，而不影响与流体加速度成比例的力分量。

严格来说，MacCamy-Fuchs 衍射解仅适用于直径恒定的固定式基础或深吃水垂直圆柱。为了确保其近似适用，同时保留一定的灵活性，在应用 MacCamy-Fuchs 模型时对构件有一些约束：

* 构件必须具有圆形截面。
* 至少当结构在静水中未位移时，构件必须是穿水的。
* 构件必须接近垂直，与垂直方向的倾角小于 10 度。
* 构件可以有轻微锥度，但直径必须在 SeaState 输入文件中 **MCFD** 的 ±10% 范围内。
* 构件的吃水必须至少为 0.5·**MCFD**。

由于 MacCamy-Fuchs 衍射解基于线性势流理论，即使在 SeaState 中启用了二阶波浪运动学，计算波浪载荷时也会忽略对流体加速度的二阶贡献。但是，MacCamy-Fuchs 衍射模型可以与任何可用的波浪拉伸模型结合使用。

构件
-------

**NMembers** 是用户指定的构件数量，决定了后续表格的行数。对于由 **MemberID** 标识的每个构件，**MJointID1** 指定起始节点，**MJointID2** 指定结束节点，对应于“构件节点”表中的标识符（**JointID**）。同样，**MPropSetID1** 对应起始截面属性，**MPropSetID2** 指定结束截面属性，从而允许变锥构件。**MSecGeom** 表示构件的截面形状。可以设置为 1（圆形截面）或 2（矩形截面）。根据 **MSecGeom** 的不同，**MPropSetID1** 和 **MPropSetID2** 引用“圆柱形构件截面属性”表或“矩形构件截面属性”表中的条目。**MSpinOrient** 是一个以度为单位的角度，指定每个构件的旋转方向，即绕构件轴线的旋转。当 **MSpinOrient** = 0 时，前文所述矩形截面的 A 边平行于水平面。如果构件完全垂直，当 **MSpinOrient** = 0 时，A 边平行于全局 *X* 轴。将 **MSpinOrient** 设置为非零值将使构件绕其轴线（从起始节点指向结束节点）按照右手定则旋转指定的角度。对于矩形截面构件和圆形截面构件都应指定 **MSpinOrient**；但是，它对后者没有影响。**MDivSize** 确定实际计算分布载荷的仿真节点之间的最大间距（以米为单位）；数值越小，分辨率越高，计算时间越长。

模型中的每个构件都有水动力系数，使用三种模型之一（**MCoefMod**）指定。模型 1 使用“简单水动力系数”部分中的单一系数集。模型 2 是基于深度的，通过“基于深度的水动力系数”部分中的表确定。模型 3 通过引用“基于构件的水动力系数”部分为特定构件指定系数。根据 **MSecGeom** 的不同，HydroDyn 将酌情使用圆形截面或矩形截面输入表中的水动力系数。当 **PropPot** = FALSE 时，**MHstLMod** 开关控制切片理论构件上静水载荷的计算。将 **MHstLMod** 设置为 0 将禁用静水载荷。如果设置为 1，将通过解析方法计算静水载荷。这种方法效率很高，但仅适用于完全淹没或穿水的、远非水平的、没有部分湿端板的构件。对于接近自由表面的近水平构件或经历部分湿端板的构件，可以通过将 **MHstLMod** 设置为 2 来选择半数值方法计算静水载荷。这种方法适用于任何相对于自由表面的构件位置，但计算时间略长。请注意，对于矩形截面构件，**MHstLMod** 必须为 0 或 2。矩形构件不支持 **MHstLMod** 设置为 1 的解析方法。**PropPot** 标志指示相应构件是否包含在势流求解中。当 **PropPot** = TRUE 时，仅为该构件计算粘性阻力载荷和压载载荷，假定所有其他载荷分量已包含在势流求解中。

除了上述每个构件的必需输入外，我们还有几个可选输入用于矩形构件更高级的横向阻力建模。这些是 **FDMod**、**VnCOffA**、**VnCOffB**、**FDLoFScA** 和 **FDLoFScB**，如下例所示。对于每个矩形构件（**MSecGeom** = 2），用户可以一起省略所有这些可选输入，在这种情况下将使用简单的默认阻力公式，或者提供所有五个可选输入以启用更高级的阻力公式。不允许仅提供这些可选输入的一个子集而省略其他。这些输入与圆形截面构件（**MSecGeom** = 1）无关，应在这些构件中省略。如果为圆形构件提供这些可选输入，HydroDyn 将直接忽略它们，并在仿真开始时显示警告。

第一个可选输入 **FDMod** 可以是 0、1 或 2。将 **FDMod** 设置为 0 会使用矩形构件的默认横向阻力公式。垂直于 A 边和垂直于 B 边的分布横向阻力分量都使用沿构件轴线/中心线的流体和结构速度，基于先前定义的 **CdA** 和 **CdB** 计算。这称为基于中心线的公式。与圆柱形构件的横向阻力一致，两个方向的阻力表达式中都使用 1/2 的前置系数。

当 **FDMod** 设置为 1 时，使用基于面的阻力公式。在这种情况下，使用矩形截面四个边中点处的流体和结构速度（而不是中心线处的速度）计算四个法向边阻力分量。在每个边上，仅使用流体和结构速度的法向分量来计算阻力。平行于边的分量被忽略。这类似于将 **AxFdMod** 设置为 0 时节点处构件端板上阻力的建模，如果我们将矩形构件的四个侧壁中的每一个解释为沿构件长度放置的端板阵列的话。同样与端板阻力类似，计算每个边上的阻力时使用 1/4 而不是 1/2 的前置系数。这是因为现在我们在垂直于 A 边的一对边上有两个阻力分量，在垂直于 B 边的另一对边上有两个阻力分量。前置系数的这种变化确保了与 **FDMod** = 0 的默认模型的一定程度的一致性。

将 **FDMod** 设置为 2 也会使用基于面的阻力公式。但是，阻力仅施加在相对流背离结构的边上，即预计会发生流动分离的吸力侧，而不施加在相对流冲击的边上（那里不太可能发生流动分离）。这再次类似于将 **AxFdMod** 设置为 1 时节点处端板阻力的建模。这种仅吸力侧的公式预计更适合采用势流理论建模的混合构件。请注意，当 **FDMod** 设置为 2 时，每个边再次使用 1/2 而不是 1/4 的前置系数。这是因为对于每对平行边，通常只有一个边（吸力侧）会有非零阻力，而不是两个都有。前置系数的这种变化同样是为了确保与其他两种阻力公式的一定程度的一致性。

当 **FDMod** 设置为 1 或 2 时，用户可以选择在计算横向阻力时启用相对流速的高通滤波。高通滤波器的截止频率可以通过 **VnCOffA**（用于垂直于 A 边的阻力分量）和 **VnCOffB**（用于垂直于 B 边的阻力分量）设置。这些输入类似于节点处端板阻力的 **AxVnCOff**。两个加权因子 **FDLoFScA**（用于垂直于 A 边的阻力分量）和 **FDLoFScB**（用于垂直于 B 边的阻力分量）控制使用未滤波相对流速计算的阻力比例。这两个输入都应介于 0 和 1 之间。当设置为 1 时，阻力完全基于未滤波的相对流速计算，相当于没有速度滤波。当设置为 0 时，阻力完全基于高通滤波后的相对流速计算。同样，这些输入类似于节点处构件端板阻力的 **AxFDLoFSc**。速度滤波允许用户衰减对低频运动的阻力响应。当应用于矩形浮筒的阻力时，如果调整得当，此选项可以帮助改进浮体低频垂荡和纵摇共振运动的预测。要禁用速度滤波，用户可以将 **FDLoFScA** 和 **FDLoFScB** 设置为 1，或者将 **VnCOffA** 和 **VnCOffB** 设置为等于或小于零的数。基于中心线的方法不支持速度滤波，如果 **FDMod** = 0，相关输入将被忽略。

如果矩形构件省略了可选输入，将使用 **FDMod** = 0 的默认基于中心线的阻力公式，并且不会应用速度滤波。无论选择何种 **FDMod** 和速度滤波设置，构件阻力系数都可以使用三个 **MCoefMod** 选项中的任意一个，没有任何额外限制。最后，请注意，这些可选输入仅影响垂直于构件轴线的分布横向阻力的计算。它们不影响沿构件轴线的分布轴向阻力。

充液构件
--------------
构件——无论是否采用势流建模——都可以是充液的，意味着它们进水和/或被压载。内部流体在进水/压载构件的内壁上施加静水压力。它还会增加构件的质量和转动惯量。沿构件的分布载荷和节点/端板处的集中载荷都会被施加。

进水构件中的流体体积由构件的外径/边长、壁厚和充液液位得出。如果充液液位在构件中部，则构件从下端节点到充液液位部分进水；如果充液液位高于构件顶端节点，则构件完全进水。在这两种情况下，都假定垂直于构件中心线的水密舱壁在两端界定构件的充液段，因此没有内部自由表面，也没有晃荡。此外，假定构件中的流体是分隔的，因此在计算构件的惯性载荷时，流体以刚体方式随构件运动。但是，在计算内部静水压力时，我们不假定分隔是水密的。因此，构件的整个充液体积共享一个连续的静水压力场。例如，这种建模假设的一个结果是，完全垂直、无锥度的单桩浮体内部的所有压载水重量将完全作用在浮体的底端板上，而不是沿浮体分布。

此外，我们引入充液构件组的概念，每个组可能包含多个构件。属于同一充液构件组的所有构件的内部进水体积被视为相互连通的，因此共享相同的连续静水压力场。每个充液构件组分为开式或闭式。如果给定充液构件组中至少有一个构件部分埋入海床，例如单桩，我们将该组视为通过部分埋入构件的底部开口和多孔海床与外部海水连通。在这种情况下，内部流体的静水压力与外部水体平衡，外部静水位处的静水压力为零。此外，开式充液构件组的充液液位不能高于外部静水位，且内部流体的密度必须与外部水的密度完全匹配。请注意，任何部分埋入海床的构件都被视为具有开放底部，因此构件底端上既没有外部静水压力，也没有内部静水压力。如果充液构件组中没有构件穿过海床，则该充液构件组被视为与外部水体封闭隔离，例如浮式平台的压载舱。在这种情况下，每个时间步，内部静水压力在该组所有构件的内部充液体积的瞬时最高点处为零。

在该输入部分中，**NFillGroups** 指定充液构件组的数量，决定后续表格的行数。**FillNumM** 指定充液组中的构件数量。**FillMList** 是 **FillNumM** 个由空格分隔的 **MemberID** 列表。**FillFSLoc** 指定充液液位的 *Z* 高度（0 表示平均海平面 MSL）。**FillDens** 是流体的密度。如果 **FillDens** = DEFAULT，则 **FillDens** = **WtrDens**。此选项对于开式充液构件组非常方便，因为这类组要求内部流体密度与外部水密度完全匹配。

海洋生物附着
-------------
未采用势流理论建模的构件可以考虑海洋生物附着。海洋生物附着有三个影响。首先，海洋生物附着会给构件带来静态重量和质量，作为沿构件的分布载荷施加。其次，海洋生物附着会增加构件的外径，从而影响粘性阻力、附加质量、流体惯性和静水浮力载荷计算中使用的直径。第三，粘性阻力、附加质量和动压力的水动力系数针对海洋生物附着有单独指定。海洋生物附着的转动惯量被忽略，且海洋生物附着不会添加到构件端部。

海洋生物附着使用具有 **NMGDepths** 行的基于深度的表指定。该表必须恰好为零行或至少 2 行。表中的列包括局部深度 **MGDpth**、海洋生物附着厚度 **MGThck** 和海洋生物附着密度 **MGDens**。子结构几何中特定位置的海洋生物附着通过在海洋生物附着表条目之间线性插值得到。**MGDpth** 的最小值和最大值定义了海洋生物附着区域。在该区域之外，海洋生物附着厚度设置为零。如果希望在这些范围内有海洋生物附着厚度为零的子区域，必须生成显式将 **MGThck** 设置为零的深度条目。水动力系数表包含有和没有海洋生物附着的系数。如果特定节点的 **MGThck** = 0，则使用与海洋生物附着无关的系数。

.. _hd-member-output-list:

构件输出列表
------------------
HydroDyn 可以在最多 9 个不同构件的最多 9 个位置输出分布载荷和波浪运动量，总共最多 81 个可能的局部构件输出位置。**NMOutputs** 指定构件的数量。必须为每个请求的构件创建一个表条目。在表条目中，**MemberID** 是“构件”表中指定的 ID，**NOutLoc** 指定为该构件生成的输出位置数量。**NodeLocs** 将这些位置指定为从构件起始节点（0.0）到结束节点（1.0）的归一化距离。如果所选位置与计算节点不重合，将对两个周围节点的结果进行线性插值。:ref:`hd-output-channels` 中指定的输出决定了在这些位置实际输出哪些量。

.. _hd-joint-output-list:

节点输出列表
-----------------
HydroDyn 可以在最多 9 个不同节点输出集中载荷和波浪运动量。**JOutLst** 包含 **NJOutputs** 个 **JointID** 的列表。:ref:`hd-output-channels` 中指定的输出决定了在这些节点实际输出哪些量。

输出
------
将 **HDSum** 指定为 TRUE 会使 HydroDyn 生成一个名为 **OutRootName**.HD.sum 的摘要文件。**OutRootName** 在独立运行 HydroDyn 时由驱动输入文件的 HYDRODYN 部分指定，在运行耦合仿真时由 OpenFAST 程序指定。有关摘要文件的详细信息，请参见 :numref:`hd-summary-file`。

对于此版本，**OutAll** 必须设置为 FALSE。在未来版本中，将 **OutAll** 设置为 TRUE 将使 HydroDyn 自动生成输入文件中每个节点和构件的输出。

如果 **OutSwtch** 设置为 1，输出将发送到名为 OutRootName.HD.out 的文件。如果 **OutSwtch** 设置为 2，输出将发送到调用程序（OpenFAST）进行写入。如果 **OutSwtch** 设置为 3，则同时进行两种文件输出。在独立模式下，将 **OutSwitch** 设置为 2 不会生成任何输出文件。

**OutFmt** 和 **OutSFmt** 参数分别控制输出数据和通道标题的格式。HydroDyn 目前不检查这些格式字符串的有效性。它们需要是有效的 Fortran 格式字符串。由于 **OutSFmt** 用于列标题，**OutFmt** 用于通道数据，为了使标题和通道数据正确对齐，宽度规格应该匹配。例如：

.. 代码块:: fortran

      "ES11.4" OutFmt
      "A11" OutSFmt

输出通道
---------------
该部分控制 HydroDyn 生成的输出量。输入一行或多行包含引号的字符串，字符串中包含一个或多个输出参数名称。输出参数名称可以用逗号、分号、空格和/或制表符的任意组合分隔。如果在参数名称前加上减号“-”、下划线“_”或字符“m”或“M”，HydroDyn 在写入数据前会将该通道的值乘以 -1。参数不一定按照输入文件中列出的顺序写入。HydroDyn 允许使用多行，以便将列表分成有意义的组，并使行更短。可以在任何行的右引号后输入注释。如果输入的行以字符串“END”开头，或者以行首的引号字符串开头为“END”，HydroDyn 将停止扫描更多通道名称行。构件和节点相关的量是为请求的 :ref:`hd-member-output-list` 和 :ref:`hd-joint-output-list` 生成的。如果 HydroDyn 遇到未知/无效的通道名称，它会警告用户，但会从输出文件中移除可疑通道。有关可能的输出参数的完整列表，请参见附录 C。
